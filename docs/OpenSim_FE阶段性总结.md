## 2. 已完成的工作（按阶段）

### 2.A 方向 C（借 THUMS 跟骨）——✅ 封档，未复现绝对高度
- 抽取 THUMS 右跟骨（SPON+CORT）→ 解剖配准 → 双材料 FE → 38 高度扫描（**38/38 rc=0**）。
- **a=0 首次骨折 ≈ 2.0–3 m**；[Y25] 7–9 m **未复现（偏高 ~3–4×）**。残余差距锁定在 **BC 层面**。

### 2.B S3.D：跖面 BC 诊断 + 次级因素排除（✅ 完成）
- **跖面 BC 实验**：三向全固定 → 三向 Winkler 弹簧（k≈1e3）后 gauge **186.8 → 142.7 MPa（降 24%）**、
  峰值离开跖面棱边，首折外推 **2.11 → 5.43 m**（**向 7–9 m 靠近但未到达**）。
  **机制修正**：虚高来自**法向支承刚度**，不是"三向/切向"（真放开切向反而 +14%）。
- **③** 距下载荷表示（均匀/梯度/节点）**±10% 内且方向敏感**；**STATIC 充分**（DYNAMIC 仅 +1.1%）。
- **④a** 多体 77 kg 校准 → F_subt **+1.3%**（首折 2.02→1.99 m，可忽略）；**④b** 跖腱膜固定下为 0、弹性下 +0.28%@5 kN。
- **⇒ 结论**：残余差距主因**唯一指向跖面法向刚度固定端奇异**；修到最好仍 5.43 m < 7–9 m → 属**范式差**。

### 2.C 坑①：gmsh 尺寸控制（✅ 解决）
- **根因**：`meshing._gmsh_tet_remesh` 用 `classifySurfaces(angle)` 的**默认 `forReparametrization=False`**，
  把输入面片钉成强制几何实体 → `Mesh.MeshSizeMax` 只封顶、够不着。
- **修法**：`classifySurfaces(ang, True, True)` + 关点/边界/曲率尺寸源（gmsh t10 recipe）。
- **结果**：胫骨 cl=4 → **27670 tet / `J<0.3` 3.66% / 体积误差 1.11%**（体素路径为 17.4%）。
  新 helper `scripts/opensim_fe/part_meshing.py`（mm-native，**未改 `meshing.py`**）。

### 2.D 坑②：皮质壳缺失（✅ 解决，三步）
- **步① 侦察**：THUMS 壳 **452920** 条 / 665 PID；皮质厚度在 **`*SECTION_SHELL`**（非 `*ELEMENT_SHELL_THICKNESS`）；
  **壳节点与同骨 SPON 实体 100% 共享**（可直接共节点，**无需 tie**）；骨盆 9 变体是**分区铺满**（须全取，只取一个仅盖 42%）。
- **步② L3 验证**：pyfebio `ShellDomain` 共节点**端到端跑通**（FEBio 4.13 rc=0）；
  **去壳后松质 σ_vm 升 16–27×** ⇒ 纯松质严重失真、**坑② 必须解决**。
- **步③ 泛化 builder**：`scripts/opensim_fe/bone_feb.py` —— 任意骨 = 1..n 实体域（**按 PID 读 `*MAT_*`**）+ 0..n 壳域。
  **4 骨 rc=0**（L3 / tibia[0壳] / parietal[2壳] / R_HIPBONE[9变厚壳]）。**关键发现**：`*ELEMENT_SOLID` **混塌缩 tet4
  与真 hex8**（须按 distinct 节点数分类）。**材料解析已独立核对**（甲板 card1 原文一致）。

### 2.E 各关节反力（✅ 完成，并修掉一个既有 bug）
- 新模块 `src/climbing/coupling/joint_reactions.py`：自由体法泛化到 **踝/膝/髋/脊柱**；每关节 **T2 残差 ~1e-12**。
- **@5 m 峰值**：subtalar 25.4 / ankle 25.3 / knee 22.4 / **hip 15.5** / **lumbar 22.2 kN**。
- ⚠️ **修正既有 bug**：`_realized_states` 从不写 state 时间（`time==0`）→ `PrescribedForce` 恒用 GRF(0)。
  **lumbar 旧值 1.5 kN 是错的**（修正 22.2）；subtalar 26.38 → **25.38 kN（−4%，不改①-④结论）**。
- ⚠️ **刚性腿伪影**：近端 |F| 反低于远端（惯性抵消），非活体趋势。

### 2.F 50×9 骨折矩阵骨架（✅ 成形，⚠️ 结果尚不可用）

### 2.G FE 网格质量修复（✅ 完成，并**证伪了"退化 tet 是主因"**）
- 4 骨换成 `part_meshing` gmsh-reparam 干净网格（min_jac 0.017–0.071、体积误差 0.45–2.47%）。
- **结论**：σ 虚高**主因不是退化 tet，而是 BC** —— 证据：同载荷 tibia 新 p95 **反而更高**（细网格把奇异解更尖）、
  **median 已物理**（0.1–0.6× 名义）、**PCA 轴向后 p95 大降**（tibia 94.6×→26.2×、femur 59.8×→16.9×、跟骨 **1.5×**）。
  跟骨首折 **1 m → 32 m**；tibia/femur 仍 1 m（BC 主导）；**fibula 屈曲发散**。
- **⇒ 病根定位到 FE 的加载方式**（斜置骨沿 bbox 轴加载 → 弯曲；端部夹持 + 点载荷 → 奇异）。

### 2.H BC-健壮性交叉验证（✅ 完成，**结论=矩阵不可信**）
- 两条独立路线复核矩阵**相对**排序：**Route 1**（无 FE 的 1D 名义应力 `F_joint/(A·σ_c)`）+ **Route 2**（端带剔除 + 体积加权，复用现有 hdf5，不重跑）。
- **证伪端部夹持假设**：剔除顶/底 30% 夹持带后 **p95 反而升高**（`tibia` 2224→4308 MPa）→ 热点在**中段弯曲**（斜向加载），不是端部奇异。
- **抓到真 bug**：`fracture_matrix.py:570/576` 对 3 根降载骨未乘回 `load_reduction_factor`（tibia **5.05×** / fibula **25.27×** / T6 **2.21×**）→ 矩阵混入不同载荷应力、利用率/排序被扭曲；报告正文却称已折算（**报告≠代码**）。已核实。
- **verdict**：Route 1 vs 矩阵 p95 仅 **ρ=0.22**，跨路线排序显著翻转 → **50×9 矩阵相对排序不可信、必须重做**；S4 最不坏输入 = Route 1 的 1D `risk(h)`（但其未建模胫/腓载荷分配）。

## 6. 永久边界（不因改造消失）

- **范式差**：单骨截断 vs 全身显式 —— 全身动量/关节传导/其它骨耦联**永久缺失**，无法靠调参消除。
- **绝对高度永久不可移植**：正确产出是**报告偏移量**（"我们相对 [Y25] 偏高 ~3–4×"），**不是**标定到 7 m。
- **能对齐的是相对模式与定性方向**（部位排序 / 聚类边界 / 双路径 / OR）；这需要先补齐矩阵（§5）。
- 约模型限制：刚性腿 + 无肌肉 + 材料弹性近似（塑性/损伤被忽略）+ 判据用材料强度。
