# 非垂直落地扩展方案（S1–S4 已实现 / S5 计划）

> **状态（2026-10-05）：S1 ✅ S2 ✅ S3 ✅ S4 ✅ 已实现并回归（默认逐位不变）；S5 📋 计划（见 [`S5接触方案.md`](S5接触方案.md)）。** 本文是路线图；各期结论见 `results/opensim_fe/NONVERTICAL_S*.md` / `NONVERTICAL_S5_SUPINATION_REPORT.md`，状态快照见 [`OpenSim_FE交接.md`](OpenSim_FE交接.md) §7。
>
> **承接**：当前 OpenSim→FEBio 管线只覆盖 **竖直 + 对称双足 + 腿绷直** 的落地（继承 [Y25] 的"成人直立位双足坠地"）。本文是把管线推广到 **斜向、单脚、带水平速度 / 力矩** 落地的扩展计划。
>
> **交叉引用**：`docs/OpenSim_FE复现方案.md`（主方案）、`docs/OpenSim_FE交接.md`（执行状态快照）。本文是**超出方向 C** 的新方向，见 §8。

## 0 背景与动机

当前管线是一条三段式链路：

```
GRF(pad.py) → OpenSim 正动力学(关节反力) → load_transfer(关节 wrench → FE BC)
            → FEBio 单骨 von Mises → 50×9 骨折矩阵
```

这条链路从 S1 到方向 C 都**只跑一种撞击边界**：竖直方向、左右对称、双腿绷直。真实抱石坠落里，这三条几乎从不成立：落点偏斜会让躯干倾斜并带来水平速度；抱石最常见的是**单脚先落**；垫边 / 失稳会造成偏心加载（CoP 偏离）与绕接触点的角动量。这些场景目前的模型**表达不出来**，不是精度问题，是**自由度缺失**。

### 关键洞察：中段已经是 3D，卡住的是两端

全文最重要的一条，先点明：

- **中段是 3D 的。** `joint_loads.subtalar_reaction` 返回的是完整的 **3D 力 `force_n`(N,3) + 3D 力矩 `moment_nm`(N,3)**，牛顿自由体已经支持任意方向载荷。
- **两端被写死成一维。** 上游 `pad.py` / `opensim_grf.ground_reaction` 只产出**标量竖直力**；下游 `opensim_fall._add_foot_force` 只把力写成**竖直分量**、且作用在距下中心（**无力矩**）。

所以扩展的难点**不在多体到 FE 的物理，而在把两端的一维接口升级到三维，并让中间的 3D wrench 一路透传到 FE**。这条洞察决定了分期顺序（§4）：先打通两端的**矢量通路**，再补物理复杂度。

⚠️ 本文所有判断都是**提案**，其中方向 / 数值上界的引用仅限"已核实的现状事实"（见 §1），**不含任何新标定或新结论**。

## 1 当前假设清单

下表是"现状把什么假设写死了、写在哪、代价是什么"。逐条对应 §2 的自由度与 §3 的改造层。

| # | 当前假设 | 代码里的兑现方式 | 文件 / 函数 | 局限 |
|---|---|---|---|---|
| A1 | 撞击**只有竖直方向** | 初速度只设 `pelvis_ty`（竖直），无水平分量 | `opensim_fall.run_dead_drop`、`PELVIS_TY_SPEED_STATE` | 水平速度 / 斜向冲量无法进入 |
| A2 | GRF 是 **1D 标量竖直力** | `pad.py` 是 **1D 双质点**模型，`pad_force_n` 是标量，向上为正 | `pad.simulate_boulder_fall`、`BoulderFallResult.pad_force_n` | 力没有方向，没有 CoP |
| A3 | GRF **只竖直、作用于距下中心** | `setForceFunctions(Constant(0), _pwl(t,f), Constant(0))`；`setPointFunctions(0,0,0)` | `opensim_fall._add_foot_force` | 力作用在 calcn 原点（=距下中心）**无力矩**，剪切分量缺失 |
| A4 | **左右对称** | `split=(0.5, 0.5)` 固定，左右各半 | `opensim_grf.ground_reaction`、`GroundReaction.split` | 单脚 / 不对称落地无法表达 |
| A5 | **腿近似刚性** | `LEG_JOINTS` 全锁死 | `opensim_fall.LEG_JOINTS` | 无姿势（躯干倾、膝 / 髋屈），无屈曲缓冲 |
| A6 | 3D wrench **被 scalarize** | 传 FE 的只有 `subtalar_n`（标量）× 固定方向 `SUBTALAR_DIR` | `load_transfer.transfer`、`FeLoadSpec`、`SUBTALAR_DIR` | 力偶被丢弃，切向 / 偏心力矩丢失 |
| A7 | FE **跖面三向全固定** | `BCZeroDisplacement(node_set="plantar", x=y=z=1)` | `febio_model.build_calcaneus_feb`、`thums_feb.build_thums_feb` | 固定端产生**边缘奇异**；这正是当前 `~2 到 3 m` 与 [Y25] `7 到 9 m` 差距的 **BC 根因** |
| A8 | 距下 **均匀压力** | `PressureLoad p=F/A` | `febio_model.build_calcaneus_feb` | 无偏心、无梯度，等于是**无力矩**的加载 |

**为什么要写全这张表**：A7 的"跖面全固定"已经是**独立于落地方向**的已知缺陷（方向 C 的交待文档已把它列为"真正嫌疑"）。非垂直落地会**同时**放大 A2、A3、A6 的问题，因此扩展方案必须把 BC 与载荷方向**一起**修，不能只改一端。

### 关于 A5：为什么不能简单"解锁关节"

`LEG_JOINTS` 是**故意锁死**的，且不能靠"解锁"解决：

- OpenSim 的关节是**理想无摩擦铰链，零被动刚度**；`dead-drop` 又关闭了激活动力学（肌肉激活 = 0）。
- 一旦解锁，26 kN 量级的足底冲击会把小腿"甩"起来：实测**踝关节冲到 −4.4 rad**（关节范围只有 `[−0.7, 0.52]`），膝关节 −1.55 rad，**整个模型四肢乱飞**。
- 这不是物理，是"零刚度关节 + 无肌肉"的模型缺陷。

⇒ 要让姿势可变，必须**同时**补上**被动刚度 / 肌肉**，否则只是把"刚性腿"换成了"失控腿"。这也决定了 §4 里姿势阶段（S3）比方向阶段（S1）贵得多。

## 2 把"非垂直"拆成 6 个正交自由度

"非垂直落地"不是一件事，是 6 个可以**独立开关**的自由度。逐项标现状。

| # | 自由度 | 含义 | 现状 | 主要触点 |
|---|---|---|---|---|
| ① | **撞击速度方向** | 初速度带**水平分量** `v⃗ = (v_x, v_y, v_z)`，不再是纯竖直 `pelvis_ty` | ❌ | `opensim_fall.run_dead_drop`（初速度）、`opensim_grf`（GRF 方向） |
| ② | **地面 / 垫面倾角** | 接触面法向 `n̂` 不垂直，斜接触 | ❌ | `pad.py`（接触几何）、`febio_model`（BC 面法向） |
| ③ | **姿势** | 躯干倾角、膝 / 髋屈曲、单腿站姿 | ❌ | `opensim_fall.LEG_JOINTS`（锁 → 非中立值 / 解锁）、`opensim_fall._add_foot_force` |
| ④ | **左右不对称（单脚）** | 只有一只脚承力，或左右力不等 | ❌ | `opensim_grf.ground_reaction`（`split`）、`opensim_fall`（每条脚独立时程） |
| ⑤ | **着力点 / CoP 偏移** | 力不作用于距下中心，产生**力矩** | ❌ | `opensim_fall._add_foot_force`（作用点）、`load_transfer`、`febio_model` |
| ⑥ | **撞击角动量** | 绕接触点 / 全身的初始角速度 `ω⃗` | ❌ | `opensim_fall.run_dead_drop`（状态初值） |

**正交性说明**：这 6 项可以分别实现、分别验证。例如 ①（方向）不需要 ③（姿势）就能先跑通（腿仍锁死、两脚仍对称）；④（单脚）不需要 ⑥（角动量）。分期（§4）正是按这个正交性排的。

## 3 分层改造 L1 到 L5

五层自上而下（接触物理 → 多体 → 载荷传递 → FE 边界 → 场景编排）。每层给出**文件 + 函数触点**。

### L1 GRF 物理（`pad.py` + `opensim_grf.py`）

现状：`pad.simulate_boulder_fall` 输出**标量竖直力**；`ground_reaction` 直接把它拆成 `split=(0.5,0.5)` 的两条固定时程。

- **标量 → 每脚 3D 力向量** `F⃗(t)`（+ 每脚 CoP）：
  - **最小版**：沿用现有标量大小 `f(t)` 作为**法向**大小，方向取 `n̂`（地面 / 垫面法向），切向按摩擦 μ 给一个分量。这是"方向化"而不改接触物理，代价最小。
  - **完全版**：2D / 3D **斜接触面 + Coulomb 摩擦**，法向力由接触本构给、切向力受摩擦锥约束。这是**接触物理重写**（见 §6 风险 ①）。
- **`split` 泛化为两条独立时程**：`split: tuple[float,float]` → `f_left(t)`、`f_right(t)` 两条各自独立的时程（允许一足为零 = 单脚）。
- 触点：`pad.simulate_boulder_fall`（输出结构）、`pad.BoulderFallResult`（新增向量字段）、`opensim_grf.ground_reaction`、`opensim_grf.GroundReaction`（`f_*_n` → 向量 + CoP）。

### L2 OpenSim（`opensim_fall.py`）

现状：`_add_foot_force` 只写竖直分量、作用点固定在原点；初速度只设 `pelvis_ty`。

- **`_add_foot_force` 三分量**：`setForceFunctions` 从 `(Constant(0), _pwl(t,f), Constant(0))` 改为三轴各有 `_pwl`。
- **CoP 作用点**：`setPointFunctions` 从 `(0,0,0)` 改为给 CoP 的时程（由 L1 提供），**可选**加 `setTorqueFunctions` 直接施加力偶。
- **初速度加水平分量**：除 `pelvis_ty` 外，把 `pelvis_tx` / `pelvis_tz`（及相应转动，若做 ⑥）设非零。
- **姿势**两条路：
  - (a) **锁关节到非中立值**：仍 `set_locked(True)`，但锁在目标姿势（躯干倾、膝 / 髋屈）对应的坐标值。**便宜，先打通**。
  - (b) **解锁 + 被动刚度 / 肌肉**：给 `LEG_JOINTS` 补被动刚度或恢复肌肉，才能让关节在冲击下有限地动。**贵，放 S3**（见 §1 A5）。
- 触点：`opensim_fall._add_foot_force`、`opensim_fall.run_dead_drop`、`opensim_fall.LEG_JOINTS`。

### L3 载荷传递（`load_transfer.py`）

现状：`transfer()` 把 3D wrench **scalarize** 成 `subtalar_n`（标量）× 固定方向 `SUBTALAR_DIR=(0,-1,0)`，力偶被丢弃。

- **`FeLoadSpec` 升级**：`subtalar_n: float` + `subtalar_dir` → **`subtalar_force: Vec3`（+ `moment: Vec3`）**，即保留完整 3D 力与力矩。
- **分解**：把载荷分成**法向压力 / 切向牵引 / 偏心力矩**三类，分别映射到 FE 的加载方式（L4）。
- 触点：`load_transfer.FeLoadSpec`、`load_transfer.transfer`、`load_transfer.SUBTALAR_DIR`（固定方向 → 由 L2 的时程给出）。

### L4 FE 边界（`febio_model.py` / `thums_feb.py`）

现状：跖面三向全固定 + 距下 `PressureLoad p=F/A`。

- **替换"跖面三向全固定"** 为**弹性支撑 / 接触 + 摩擦**。这一条**同时**（a）让非垂直载荷有合理的反力面，和（b）**消除固定端边缘奇异**（即 A7，是 `~2 到 3 m` 差距的 BC 根因）。
- **力矩两条路**：
  - (a) **关节面线性压力梯度** `p(x) = p0 + g·x`：用非均匀面压表达偏心力矩，改动最小。
  - (b) **幽灵刚体**：复用已有 `use_rigid=True` 路径（`RigidFixed` + `RigidForceLoad`），扩展 `RigidMomentLoad` 施加力矩。目前代码只写了 `RigidForceLoad`（力），刚体接口本身**可承载力矩**，需补上力矩载荷项。
- 触点：`febio_model.build_calcaneus_feb`（`BCZeroDisplacement(plantar,...)`、`use_rigid` 分支）、`thums_feb.build_thums_feb`（同构路径）、`febio_model.DEFAULT_JOINT_FACE`。

### L5 场景编排

- **场景对象**：`Scenario = {height, v⃗, ground_tilt, foot_mode, posture, ω}`，把 §2 的 6 个自由度收进一个结构。
- **扫描维度**：`(高度 × 场景 × 9 部位)`。现有扫描是"50 高度 × 9 部位"；扩展后场景成为新的扫描轴。
- 触点（新建，非现有文件）：场景编排脚本 / 扫描脚本。

## 4 推荐分期 S1 到 S5

按"先通矢量、再补物理、最后上 FE"排序。每一期都保持**轴向 case 可回归**（§7）。

| 阶段 | 做什么 | 代价 | 收益 |
|---|---|---|---|
| **S1 斜向落地方向** | GRF 矢量 + 初速度矢量。两脚、仍近似刚性腿。只动 3 处：`ground_reaction` 加方向、`_add_foot_force` 改三分量、`load_transfer` 保矢量 | **小** | 打通 ①（速度方向）与 ②（地面倾角）的矢量通路；**不破坏现有轴向回归** |
| **S2 单脚 / 不对称** | `split` 泛化为两条独立时程 + 单脚 CoP | **中** | 打通 ④（单脚）；**抱石最常见**的场景 |
| **S3 姿势** | ✅ **已实现**（见 `results/opensim_fe/NONVERTICAL_S3_POSTURE_REPORT.md`）：锁姿势 (a) + 解锁+被动刚度 (b)；结论：被动刚度**必要不充分**（20 ms 冲击内只屈 ~2°），真吸能需主动肌肉 | **中到大** | 打通 ③（姿势）；是 A5 的正确解法 |
| **S4 完整 wrench 上 FE** | 偏心压力 / 力矩 + 跖面改弹性支撑 | **中** | 打通 ⑤（CoP / 力矩）；**引入跟骨弯曲模态 + 治跖面奇异**（顺带触碰 A7） |
| **S5 FE 内脚-垫接触** | 在 FE 里做脚与垫的接触 + 摩擦 | **大** | 最完整的接触表达；**仅必要时做** |

**排序理由**：S1 只动 3 处且不破坏现有回归，是"证明矢量通路可行"的最小步；S2 复用 S1 的矢量框架；S3 昂贵（要碰零刚度关节问题）所以放后；S4 才把力矩送上 FE，且**顺便**处理已知的跖面奇异；S5 只在 S1 到 S4 仍不够时才做。

| 不变的资产 | 说明 |

## 6 硬骨头与风险

| # | 硬骨头 | 说明 |
|---|---|---|
| ① | **`pad.py` 1D → 2D/3D 是接触物理重写** | 现有是 1D 双质点，接触面积 / 法向 / 摩擦都在一维里隐含。要做斜接触 + 摩擦，等于重写接触本构，不是加参数 |
| ② | **解锁关节会重开"零刚度关节"问题** | 见 §1 A5：OpenSim 关节零被动刚度，dead-drop 又关肌肉，解锁会让腿飞（踝冲到 −4.4 rad）。**必须配被动刚度 / 肌肉，别只解锁** |
| ③ | **没有数据标定一般 GRF（水平 / 摩擦）** | 现有 `hard_surface` 的刚度标定本就是全模型最弱项；水平力与摩擦系数更是**没有对标数据**。非垂直场景的**验证**比轴向难得多 |
| ④ | **单脚会把局部载荷翻倍，剪切 + 力矩引入弯曲** | 单脚承全部冲量，局部载荷翻倍；剪切与力矩引入**弯曲模态**（现有轴向加载没有），可能**改变骨折排序**（不只是数值大小） |

## 7 验证策略

扩展不能只加功能，必须能证明"没把已经对的东西弄坏"。

| 项 | 做法 |
|---|---|
| **轴向回归（硬门槛）** | 把速度 / 倾角 / 单脚 / 力矩**全部置零**时，结果必须**数值复现现有轴向结果**（同 h 下 T1、T2、距下峰值一致到数值误差内）。这是每期的准入条件 |
| **T1 冲量推广到矢量** | 标量不变量 `∫F dt ≈ m√(2gh)` 推广为**矢量** `∫F⃗ dt ≈ m·v⃗₀ + m·g⃗·t`（含水平分量） |
| **摩擦约束** | 切向力必须满足 `|F_t| ≤ μ·F_n`，任何时刻不得越出摩擦锥 |
| **敏感性分析** | 对新增的自由度（倾角、CoP 偏移、μ、ω）做敏感性扫描，确认输出随它**单调 / 有界**，不是数值噪声 |
