## 2. 关键发现（含口径更正）

1. **"文献冲击持续 1–5 ms"是误读**（2026-10-08 更正，已同步 7 个文档）：按冲量-动量，
   77 kg @5 m 于 1–5 ms 卸速需 ≈240 kN（≈3100 g），不成立；文献给的是
   **局部组织峰值时刻 1.8–11.9 ms**（[T22] Table 3 胫骨 11.9/6.5/4.6、韧带 4.1/2.8/1.8 ms）
   + [Y25] 头部 ≤12.5 ms 判据。settle 窗（【垫】56–67 / 【刚】34–44 ms）只作内部诊断，
   **不再与文献对比**（同口径局部峰对比 = 2–5×，不是 10×）。
2. **峰时必须限冲击窗内取**：刚性地面无接触阻尼 ⇒ settle 事件不触发、轨迹跑满 t_max，
   全程 argmax 被窗后振铃污染（实测假峰 t0+1325 ms）。probe `_peak_rel_ms` /
   `head_branch` / `bone.py` 同款窗口守卫；`tests/test_pad2d.py::TestV8MomentObservable` 锁定该守卫。
3. **k_neck 在刚性口径不饱和**（与垫侧 P4 结论相反）：200→2000 N/mm 头峰 23.0→12.8 ms 持续改善，
   但文献动态轴向刚度上限 2.5 kN/mm（`head_branch.py:115`）⇒ 合法顶格 ≈2500。
   仅靠颈部到不了 V8b（k10000@20m 仍 7.0 ms，且超文献 4×）。
4. **时序与 V2（<7 m 无骨折）通过脉冲形状耦合**：任何链强化抬高峰值力 →
   kf≥1.5 在 5 m 折胫骨、`k_stop="kf"`（止挡不软化）在 6.5 m 折 —— **均破 V2**。
5. **等平台刚化是解**：`kf_mult=2 × x_max=0.015`（k_flex·x_max = 2.2e6×0.015 = 33 kN **与原值
   1.1e6×0.03 完全相同**）⇒ 上升沿翻倍、力包络不变 ⇒ V3 全过且 V2 完整保留。
6. **k_n=1e8 否证**（L3 结论：维持 1e7）：tF@20=2.0 ms 系**弹跳区制伪影** ——
   首分离窗只剩拍击、能量账 resid=0.74；且胫骨载荷读 f_flex（链力）而非拍击 F_pad，
   该"达标"是观测量错觉。k_n=1e7 下 tF 平台 ~14 ms ⇒ V8b 在 1D 链内不可达。
7. **V8 观测量对齐原表**（L4）：[T22] Table 3 报的是胫骨/韧带**应变**峰时（非头峰）。
   主判据 = `t_torso`（f_flex 峰 = 胫骨轴向载荷，T22 第一列同源）；副 = `t_moment`
   （踝内翻力矩 = 韧带序列）；头峰归 V3。判据行已同步
   `docs/methods/方案更新_v2.md:866`、测试注释与 probe 判定。

## 7. 经验教训（A 档，2026-10-08：A1 撕脱阈重标定 / A2 归因 / 测试加速）

### 7.1 跨工况判据标定（A1，`ANKLE_AVULSION_LOAD_N` 300→215）

- **教训**：共享判据常量若按**单一工况的波形**标定，换工况必然失灵。`T=300` 是按【垫】
  波形钉的（69800·0.005≈349 > 300）；【刚】冲击窗更短、β 未长大 ⇒ raw F_lig 反而更低
  （50951），(10 m,30°) eff=254.8 < 300 **漏判 15%** ⇒ 刚侧 V6 8/9。
- **修法**：以**文献靶面（刚性地面）**取双工况可行窗**交集**——垫约束 T ≤ 349、
  刚约束 173.2 < T ≤ 254.8 ⇒ 取中 **215**（仍 > ATFL 200 N、文献区间 200–2000 N 内），
  垫/刚两侧所有边界格裕度 16–20%。
- **验收三件套（缺一不可）**：① probe `--part v6` 双列 **9/9**（+flips 结构判据）
  → ② 全测试绿 → ③ **官方产物逐字节 diff**（`fc results\p1_montecarlo.csv` vs 改前备份
  = **零漂移** ⇒ 228/345、22.8%、2.85×、34.5% 等下游文档数字**全部免改**）。
  只改常量不查产物，等于把漂移留给下游文档暴雷。
