## 三、🎯 §3 讨论给出了**完整机理**（这是最大的收获）

原文（`论文 §3 讨论`，重解析后终于完整）：

> 踝关节为屈戌关节，距骨体及滑车前宽后窄，**负重时下胫腓关节有分离趋势**，
> 下胫腓联合前后韧带十分坚韧，能够限制此趋势……**因此下胫腓联合前韧带位移很小**。
> 由于**外踝较内踝较长并靠后**，故**踝轴向后下方成角**，当人体中立位负重时，
> **小腿有外翻趋势**。距下关节的前、中、后三个关节绕同一单轴运动，类似一斜铰链……
> 由于这一斜轴关系，站立位负重时**进一步加重小腿的外翻**，同时小腿亦出现了
> **轻微的内旋**（Liacouras、Marqueen 等：胫骨 **0°～0.5° 内旋**）。
> **因此外侧的跟腓韧带位移小于内侧韧带，胫跟韧带位移大于胫舟韧带。**

**机理链条**：
```
外踝长 + 靠后  →  踝轴斜（后下方向）  →  负重时小腿外翻 + 内旋 0~0.5°
              →  外侧(跟腓) 位移 < 内侧(胫跟/胫舟)；胫跟 > 胫舟
              →  下胫腓最坚韧 ⇒ 位移最小
```

★★ **关键推论**：**排序来自「耦合的外翻 + 内旋」，不是纯轴向压缩。**
而 `DRIVER=disp` + 顶面三自由度全指定（夹持）**恰好禁掉了这个机理本身**
—— 这解释了为什么我算出「胫跟缩短最多」（与吴恺名次颠倒）。

## 五、⚠️ 韧带位移：**量级差 30~40 倍，判定为不可复现**

我的模型（`TRUNC_MM=60`、末帧 ≈360 N、`MATSET=WK`）：

| 韧带 | 口径一 ΔL (mm) | 口径二 \|u\| (mm) | **吴恺 (mm)** |
|---|---|---|---|
| 胫跟 MD2 | **−0.126** | 0.195 | **5.24** |
| 胫舟 MD3 | −0.068 | 0.245 | **5.04** |
| 跟腓 CFL | −0.067 | 0.043 | **2.05** |
| 下胫腓前 SYND | +0.005 | 0.269 | **1.92** |

**两个独立的不符点**：
1. **量级差 30~40 倍**（0.1~0.27 mm vs 1.92~5.24 mm）
2. **排序不符**：两种口径都让 **下胫腓排第一**，而吴恺是**最末**

**为什么认为不是「我的模型太刚」**：
- 我的模型刚度 = 140 N / 0.1472 mm ≈ **950 N/mm**（**生理合理**：600 N 下踝关节压缩约 0.5~1 mm）
- 吴恺 5.24 mm @ 600 N 反推 ≈ **120 N/mm，比生理软约 8 倍**
- 若按 5 mm 压缩 + 软骨 1.4 mm 厚 ⇒ 应变 350%，**物理上不可能**

⇒ **吴恺的「位移（拉伸长度）」数值不宜作为验证靶子**（除非拿到其模型文件）。
**可用的靶子是 3.74 MPa 与 335.5 mm²。**

## 六、🔴 顺带暴露的新阻塞：模型到不了 600 N

`DRIVER=disp DISP_MM=0.60` → **在 t=0.63（0.378 mm）处
`Negative jacobian detected`，14 步后失败**。

- 线性求解每次 **1 次迭代**（**不奇异**，无刚体模态）
- 每步平均 5.8 次平衡迭代（收敛本身不差）
- ⇒ 失败原因是**单元被挤反**（薄软骨 det(J) min = 0.0105）

**⇒ 修好之前，600 N 下的 3.74 MPa / 335.5 mm² 只能在 <360 N 外推对比。**

**修复方向**（按价值）：
1. **薄软骨单元**：t = min(1.5, 0.5×骨间隙) = 0.703 mm（两层合 1.406 mm 生理合理，
   但单层太扁）⇒ 试 **单层合并厚度** 或**提高软骨网格质量**（`CART_QUALITY=1`；
   注意此前判定它为「负面结果」是针对**收敛速度**，此处目标是**防翻转**，目标不同）
2. 接触调参：`two_pass` / `auto_penalty` / `tolerance`（现 0.02）
3. 韧带改 `elastic`（去掉 tension-only 的强非线性）或加 `prestrain`

## 八、✅ 600 N 打通 + 双靶验证结果（2026-10-04）

### 打通的关键：软骨改用 `penta6`（楔形）

原实现把薄软骨（0.703 mm）的 6 节点楔形**拆成 3 个 tet4** ⇒ 细长 sliver
⇒ 末态 det(F) 跌到 **0.523**（tibiotalar_tibia）⇒ 再压就翻负
（`DISP_MM=0.60` 在 t=0.63 / 0.378 mm 处失败）。

改用 `CART_ELEM=prism`（**penta6，不拆**）后：

```
DRIVER=disp TOPFIX=lateral TRUNC_MM=60 FIX_TALUS=all CART_ELEM=prism
TIME_STEPS=30 DISP_MM=1.20
→ rc=0 / 7.4 s / 支反力 645.7 N
```

### 🎯 双靶对照（600 N 档）

| 靶子 | 吴恺 2012 | 本模型（645.7 N） | 偏差 |
|---|---|---|---|
| **最大接触应力** | **3.74 MPa** | 软骨 von Mises max **2.96 MPa**（p99 0.97） | **−21%** |
| **接触面积** | **335.5 mm²** | **287.4 mm²**（间隙阈值 0.20 mm） | **−14%** |

接触面积对阈值的敏感性：0.10 mm → 109.8；**0.20 mm → 287.4**；0.50 mm → 722.9 mm²。

**⇒ 两个靶子都在同一量级、偏差 ~20% 以内**，比此前只比软骨应力 p99 硬得多。

### ⚠️ 遗留：楔形 vs 四面体刚度差 2.2 倍（未解决）

同一位移 `DISP_MM=0.1472`：

| 软骨单元 | 支反力 | 软骨 p99 | 接触面 |
|---|---|---|---|
| **tet4** | **259.3 N** | 0.765 MPa | 148 / 191 |
| **prism** | **116.9 N** | 0.273 MPa | 138 / 171 |

同几何/材料/边界 ⇒ 差异来自**离散格式**：线性 tet4 在 ν=0.4 下体积锁死偏刚、
线性 penta6 偏柔（可能沙漏）。**哪个更接近真值未定，需网格收敛研究**。
在此之前 600 N 档数值只能当量级参考。
