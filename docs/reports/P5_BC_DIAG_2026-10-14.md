# P5.0 探针失败根因诊断报告（2026-10-14）

## 结论摘要

P5.0 探针（髁端接触承载轴向 + 股骨头解剖载荷，femur_r h10）**连续失败于 ERROR TERMINATION / 负 jacobian**。
本轮定位出 **4 个独立缺陷**，前 3 个已修复并代码落盘；第 4 个（判据观测量失效）**未修复，如实记录**。

原归档假设「`bottom_fix_axial_only` 轴向自由导致 z 刚体模态」**证伪**：该参数语义与文档一致，
是有意设计（轴向交给接触承载），不是传参 bug。

---

## 缺陷 1：facet 分隔符（已修复）

- **现象**：FEBio 报 `The surface "bone_top" has 543 invalid facets.`
- **根因**：`p5_head_contact.py:141,143` 的 `_cap_surface_xml` 用 `" ".join()` 输出 facet 节点。
  FEBio 4.13 要求**逗号分隔**（`g4_fe_plate.py:126-127` 已实证；`g4_fe_p1b.inject_surface:168` 亦用逗号）。
- **证据**：同一 `.feb` 内 `plate_bottom` 面片为逗号分隔（`8537,8567,8569,8539`）且不报 invalid；
  `bone_top` 为空格分隔（`127 126 148 147`）且全 543 个 invalid。
- **修复**：`" ".join` → `",".join`。
- **效果**：invalid facets 警告消失。**但求解仍失败** —— 此缺陷非唯一根因。

## 缺陷 2：cap 面选择过宽（已修复）

- **现象**：cap 面片 centroid z 从 92.9 到 233.7 —— 不是「髁端端面」，而是**髁端 30% 带的整个外表面**。
- **根因**：`cap_geom` 判据 `axdiv > 0.0`。股骨髁部为球面，侧面法向只要有一点 +Z 分量即入选。
  实测 542 quad4 中 **365 个 axdiv<0.5**。
- **后果**：这些侧面面片把接触面法向搅乱，接触力带横向分量。
- **修复**：新增 `CAP_AXDIV_MIN = 0.5`。修复后 cap = 178 quad4，A=4039.3 mm²（纯端面）。

## 缺陷 3：压板刚体横向敞开（已修复）

- **现象**：一次「收敛」运行中 `dis_xy_max = 2,431,126.78 mm`（**2.4 公里**）。
- **根因**：`rigid_fixed` 中 `Rx_dof=0, Ry_dof=0`（平移敞开）沿用 g4_fe_plate。
  缺陷 2 的横向接触力分量把压板刚体整体推走。数值上「收敛」，**解无物理意义**。
- **修复**：`Rx_dof`/`Ry_dof` 改 1（锁死），`Rz_dof` 仍 0 由 `rigid_displacement` 驱动。

## 缺陷 4：`R_z_contact` 观测量失效（**未修复，如实记录**）

- **现象**：`R_z_total = -0.000`（严格 0），而平衡要求 `≈ -22923 N`。
- **根因**：FEBio 的 `reaction forces` 节点变量是**逐节点内力**，全域求和按构造恒等于 0
  （telescoping），**不是**外力反力。故 `_load_bear_stats` 的
  `R_z_contact = R_z_total - R_z_anchor` 结构性为 0，无法承载任何判据。
- **附带矛盾**：`lat_support_0`（`z_dof=0`，物理上不可能承轴向）报 `R_z_sum = -18226 N`，
  与 BC 定义直接冲突 —— 再次印证该变量不是反力。
- **替代量尝试与失败**：截面轴力积分 `Σ σ_zz·V/Δz`，得 −500~−1800 N（≠ 22923 N）。
  但该法自建的 hex8 体积计算退化（min=0.000 mm³，总和 10166.8 mm³，vs 皮质骨应有量级
  ~36600 mm³），**该数字本身不可信**，不能作为判据。
- **后果**：**P5 能力主判据（`|R_z_contact|≈load_n` ±20%）当前无法裁定**。
  收敛运行不能判定「接触承压能力成立」。

## 对照实验矩阵（关键证据链）

| 对照 | 配置 | 结果 | 结论 |
|---|---|---|---|
| v3 分离 | 纯骨 + p5 BC + head 载荷，无 plate/ghost/接触 | ERROR（负 jac） | 失败与接触无关 |
| 无接触 | 完整注入 − Contact 块 | FAIL（5,8,3,4,10,7） | **排除接触配方** |
| plate 抬高 | z_wall = a_max+10（消除 3.8mm 重叠） | FAIL（5439…） | **排除空间重叠** |
| z 固定 | z_dof 0→1 | FAIL（7697…） | **排除轴向自由语义** |
| 无注入+zfix | 仅 3 节点 anchor、z 全固定 | CONVERGED | lateral_support 缺失是必要条件 |
| E6 | P4 原配方（bot 带 bottom_fix + lat） | FAIL | 载荷与固定端同侧 |
| E7 | P4 配方 + 3 节点 anchor | CONVERGED | 顶带锚点位置有效 |
| gap0=−0.3 | 板初始即穿透，接触 t=0 激活 | **CONVERGED** | t=0 需接触已激活 |
| gap0=+0.2 | 初始有间隙 | FAIL | t=0 奇异（z 向 1 刚体模态） |

节点集对照（决定性）：

| | bottom_fix | lat_support | 结果 |
|---|---|---|---|
| P4h50（成功基线） | 3995（顶带） | 7032 | 收敛 |
| E6 | 2451（bot 带） | 7032 | FAIL |
| E7 | 3（顶带） | 7032 | 收敛 |
| p5_pen（原始） | 3 | **无** | FAIL |

**`lateral_support=None` 是 p5 探针的必要缺失项**：p5 全部变体都缺横向导向，
3 节点锚点不足以替代（E7 显示补上 lateral_support 后同一 3 节点 anchor 即可收敛）。

## 修复后可达状态

`gap0=−0.3, penalty=500, lateral_support=[(0.05,0.95)], CAP_AXDIV_MIN=0.5, 板锁 Rx/Ry`
→ CONVERGED，shaft=34.20 MPa，dis_xy=0.522 mm，dis_z=2.511 mm。

**但**：此配置的判据无法裁定（缺陷 4）。且 `anchor_z%` 在 ramp0=0/0.5 两档为 24.1%/0.083%，
差异极大，提示锚点仍参与轴向分担，与「轴向 100% 走接触」的设计意图冲突，需进一步核查。

## 已修改文件

- `scripts/opensim_fe/p5_head_contact.py`
  - `_cap_surface_xml`：facet 分隔符 空格→逗号（缺陷 1）
  - `cap_geom` + `CAP_AXDIV_MIN`：cap 面阈值 0.0→0.5（缺陷 2）
  - `_inject_plate_contact`：`rigid_fixed` Rx/Ry 0→1（缺陷 3）

**未落盘为默认**：`_build_one` 仍传 `lateral_support=None`、`GAP_MM=0.2`、`PLATE_DISP_MM=0.5`、
`penalty` 按变体 0.1/50.0。这些属预注册冻结参数，**需用户拍板后**才改。

## 遗留 / 待决

1. **观测量修复**（阻塞项）：`R_z_contact` 口径失效。可选路径：
   (a) 改用压板刚体反力（ghost rigid body 的 reaction）——需确认 FEBio 是否输出；
   (b) 用 ghost 节点的 reaction 差分求接触力；
   (c) 修正截面轴力积分的 hex8 体积实现后作为独立观测量。
2. `anchor_z%` 24.1% vs 0.083% 的 ramp 依赖性待查。
3. `lateral_support` 是否进正式配方、`penalty` 与 `gap` 是否重定，需用户拍板（预注册红线）。
