# P5.0 探针失败根因诊断报告（2026-10-14）

## 结论摘要

P5.0 探针（髁端接触承载轴向 + 股骨头解剖载荷，femur_r h10）**连续失败于 ERROR TERMINATION / 负 jacobian**。
本轮定位出 **4 个独立缺陷**，前 3 个已修复并代码落盘；第 4 个（判据观测量失效）**未修复，如实记录**。

原归档假设「`bottom_fix_axial_only` 轴向自由导致 z 刚体模态」**证伪**：该参数语义与文档一致，
是有意设计（轴向交给接触承载），不是传参 bug。

---

## 缺陷 1：facet 分隔符（已修复）

- **现象**：FEBio 报 `The surface "bone_top" has 543 invalid facets.`
- **根因**：`p5_head_contact.py:141,143` 的 `_cap_surface_xml` 用 `" ".join()` 输出 facet 节点。
  FEBio 4.13 要求**逗号分隔**（`g4_fe_plate.py:126-127` 已实证；`g4_fe_p1b.inject_surface:168` 亦用逗号）。
- **证据**：同一 `.feb` 内 `plate_bottom` 面片为逗号分隔（`8537,8567,8569,8539`）且不报 invalid；
  `bone_top` 为空格分隔（`127 126 148 147`）且全 543 个 invalid。
- **修复**：`" ".join` → `",".join`。
- **效果**：invalid facets 警告消失。**但求解仍失败** —— 此缺陷非唯一根因。

## 缺陷 2：cap 面选择过宽（已修复）

- **现象**：cap 面片 centroid z 从 92.9 到 233.7 —— 不是「髁端端面」，而是**髁端 30% 带的整个外表面**。
- **根因**：`cap_geom` 判据 `axdiv > 0.0`。股骨髁部为球面，侧面法向只要有一点 +Z 分量即入选。
  实测 542 quad4 中 **365 个 axdiv<0.5**。
- **后果**：这些侧面面片把接触面法向搅乱，接触力带横向分量。
- **修复**：新增 `CAP_AXDIV_MIN = 0.5`。修复后 cap = 178 quad4，A=4039.3 mm²（纯端面）。

## 缺陷 3：压板刚体横向敞开（已修复）

- **现象**：一次「收敛」运行中 `dis_xy_max = 2,431,126.78 mm`（**2.4 公里**）。
- **根因**：`rigid_fixed` 中 `Rx_dof=0, Ry_dof=0`（平移敞开）沿用 g4_fe_plate。
  缺陷 2 的横向接触力分量把压板刚体整体推走。数值上「收敛」，**解无物理意义**。
- **修复**：`Rx_dof`/`Ry_dof` 改 1（锁死），`Rz_dof` 仍 0 由 `rigid_displacement` 驱动。

## 缺陷 4：`R_z_contact` 观测量失效 —— **已修复并验证** ✅

- **现象**：`R_z_total = -0.000`（严格 0），而平衡要求 `≈ -22923 N`。
- **根因**：FEBio 的 `reaction forces` 节点变量是**逐节点内力**，全域求和按构造恒等于 0
  （telescoping），**不是**外力反力。故 `_load_bear_stats` 的
  `R_z_contact = R_z_total - R_z_anchor` 结构性为 0，无法承载任何判据。
- **附带矛盾**：`lat_support_0`（`z_dof=0`，物理上不可能承轴向）报 `R_z_sum = -18226 N`，
  与 BC 定义直接冲突 —— 印证该变量不是反力。
- **修复**：改用 FEBio **原生 contact force 输出**（`<var type="contact force"/>`
  → `states/{sid}/surface_data/contact force`）。
  ⚠️ **读法要点**：`bone_top` 与 `plate_bottom` 是同一对接触的两个面，值互为相反数，
  **两面相加恒为 0**（牛顿第三定律，与上面 reaction 陷阱同构）—— 只可取**单面**值。
- **验证（三条独立证据）**：
  1. **数值精确**：末态 `bone_top` 接触力 z = **−22923.18 N** vs 载荷 **22923.15 N**，
     相对偏差 **1.19e-06**。
  2. **牛顿第三定律自检**：两面之和残差 = **0.00e+00 N**。
  3. **区分力预验（正对照）**：单次运行内 4 个时间点，由接触力反推的 t =
     **0.0997 / 0.3800 / 0.8040 / 1.0000**，与求解器实际时间步（0.1 / 0.38 / 0.804 / 1.0）
     逐点吻合 ⇒ 观测量**随载荷水平正确响应**（旧口径在全部工况恒为 0，无区分力）。
- **附带产物尝试（失败，已弃）**：截面轴力积分 `Σ σ_zz·V/Δz` 得 −500~−1800 N（≠22923 N），
  但该法自建 hex8 体积计算退化（min=0.000 mm³，总和 10166.8 mm³，vs 皮质骨应有量级
  ~36600 mm³ —— 仓库已有正确的 `bone_feb._hex8_signed_volumes` 共享对角线实现，
  我上轮自建六面体分解是错的）。**该路线已弃，改用原生输出。**

## 能力判据的裁定（观测量修复后）

**主判据现可裁定**：在接触于 t=0 即激活的配置下（`gap0=−0.3`），
接触承载 **100.0001%** 的轴向载荷 ⇒ **P5 的设计意图（髁端接触承载轴向）物理上可实现** ✅

**但冻结参数化不收敛**：`GAP_MM=+0.2` + `ramp 起点 0.5` 的组合下，
t=0 时板位移仅 −0.25mm **只够闭合 0.2mm 间隙**、接触尚未激活，
而载荷已到 50%（11.5 kN），骨轴向完全自由 ⇒ z 向 1 个刚体模态 ⇒ 奇异/负 jacobian。

⇒ **结论**：P5 不是设计不可行，而是**冻结的加载时序含一个 t=0 奇异**。
修正只需让接触在 t=0 已激活（板初始即预穿透，或 ramp 起点与间隙联动）。
这属**加载时序/间隙参数**，触及预注册冻结项，**待用户拍板**。

## 复用教训（本轮）

- **`reaction` / 接触力两面求和都是「按构造恒为 0」的量** —— 前者是内力 telescoping，
  后者是牛顿第三定律。**凡「求和后应与载荷相等」的观测量，先确认它不是这类恒零量。**
- **优先找 FEBio 原生输出**，而不是自建后处理实现：本轮自建 hex8 体积退化（因子 ~3.6），
  而原生 `contact force` 一开即准（1e-06）。仓库已有正确实现（`_hex8_signed_volumes`）时
  也应优先复用而非重写。
- **观测量必须有「区分力正对照」**：旧口径在全部工况恒 0（无区分力），
  新口径在单次运行内随载荷 4 点正确变化 —— 这才是可用的判据。
- **cmd 不支持 heredoc**（`git commit -F- <<EOF` 报 `<< was unexpected`）⇒ 先写
  `temp/gitmsg_*.txt` 再 `git commit -F`。**每条 shell 命令是新子进程** ⇒
  `git add` 与 `git commit` 必须同一条命令内串联。
- cmd **无 `tail`** ⇒ 用 `more +0`。
