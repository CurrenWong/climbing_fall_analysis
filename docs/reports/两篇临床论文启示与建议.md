## 0. 一句话

两篇论文提供了本项目缺的三样东西：**验证靶（损伤分布）**、**真实场景轴（跌倒运动学）**、**关键机制（脚沉垫→踝旋后）**；且 [Beurienne2025] 在结论里**明确呼吁用有限元数值重建跌倒场景并评估垫子设计**——**正是本项目**。

## 1. 论文数据摘要（可直接引用）

### [Heck2024 / Müller2022]（急诊，430 人 / 447 伤）
- **机制**：跌倒 **67.8%**、扭伤 8.1%、撞墙 4.5%、过用 5.6%。
- **区域**：下肢 **61.1%** > 上肢 26.6%；**踝 36.7%**、膝 16.8%、肘 12.3%、脊柱 7.2%、肩 6.3%（合计 79.2%）。
- **类型**：扭伤 **53.0%**、骨折 22.8%、脱位 11.9%。
- **踝**：扭伤 71.3%、**骨折 27.4%**（≈一般踝急诊 28.3%，Debieux）。
- **高度（反直觉）**：**<2 m 跌倒 → 下肢伤更多（79.1% vs 58.3%）**（§4.3.3）。
- **严重度**：UIAA 2 占 55.3%、3 占 29.5%、1 占 15.2%；入院 10.1%；手术 20%。

### [Beurienne2025]（问卷，245 人 / 301 伤）
- 下肢 67%；**踝扭伤 #1（28%）**、踝骨折 8%。
- 85% 非自主；62% **直立起始**；62% **有旋转**；74% **足先落地**。
- 墙：直立 45%、斜面 29%；顶 47%、中 32%。
- **7 运动学**；前 3（占 42%）：
  1. **直立 / 无旋转 / 站姿足落 → 下肢**（踝扭伤/骨折、膝）（17%）
  2. **直立 / 纵旋 / 前倾足落 → 下肢**（14%）
  3. **后倾起始 / 旋转 / 前倾足落 → 上肢**（肘）（11%）
- 结论（原文）："reconstructing complete fall scenarios using **finite element numerical modelling** … assess the influence of different **pad designs** on injury outcomes."

## 2. 暴露出的缺口

1. **机制缺口（最重要）**：两篇都描述"脚沉入垫子 → 踝**旋后/内翻** → 达垫子模量后载荷上升 → 韧带/骨失效"。**我们的模型是轴向的**，缺"旋后"这条轴。→ 可能正是我们"**腓骨异常敏感**"的现实对应（外踝=腓骨远端）。
2. **场景缺口**：我们自造的 tilt/单脚/垫子场景，未对齐真实运动学轴（起始×旋转×落地）。
3. **验证缺口**：从未和临床分布对照。
4. **结构缺口**：**#1 临床伤是踝扭伤（韧带）**，我们的骨模型不覆盖韧带（只能对应踝/外踝**骨折** 27.4%）。

---

## 3. 建议（按价值排序）

- **R1 补踝旋后/内翻载荷（最高价值）**：加**冠状面（frontal）倾斜** + 横向力/内翻力矩 → 外踝（腓骨远端）侧向载荷。既补机制缺口，又能解释/校正我们"腓骨敏感"的结果。
- **R2 用真实场景轴重建场景矩阵**：起始×旋转×落地 → 模型参数，对齐 [Beurienne2025] 的 7 运动学。
- **R3 临床分布对照**：把我们的区域标志和 §1 的表对照。
- **R4 垫子刚度 × 旋后权衡**：[Beurienne2025] 明确点出 rigidity 的两难（防旋后 vs 高能量更糟）。
- **R5 解释"低坠→更多下肢伤"**：落地姿势随高度分布（低坠仍直立→足先→踝；高坠→更多旋转→上肢/头）。

## 5. 执行结果（R1 / R2 已完成）

### R1 踝旋后/内翻载荷 ✅ —— `results/opensim_fe/NONVERTICAL_S5_SUPINATION_REPORT.md`
- 默认回归 **0.00e+00**；新增 **opt-in** `ground_reaction(roll_deg=)`（冠状倾角）+ 模块 `ankle_supination`（显式旋后角/`F_lat`/`M_inv`/`fibula_lateral_risk`/`critical_inversion_angle_deg`）。
- **结论**：纯轴向腓骨两端 **7 m 才越阈**（真实高度全安全）；叠加 **旋后 15–30°** → **同一条腓骨在 2–4.5 m 即越阈**。
- 临界旋后角 β_c < 2°（**上界式 1D**，绝对值不可引用；真实外伤角 15–30° 远高于此）→ **只看"是否越阈/相对"**。软垫降低 F_lat（吸能）。

### R2 真实场景矩阵 ✅ —— `results/opensim_fe/SCENARIO_FIELD_MATRIX_REPORT.md`
- 只建新文件、无核心改动；默认回归通过；新增测试 15 passed。
- 7 运动学 → 现有旋钮（`tilt_deg`/`split`/`vx0`）；头先/臀先标 PROXY（不可由足端链表示）。
- 模型**下肢旗标 100%** vs 临床 61–67%（**过度**，纯轴向 + 无上肢/软组织通路）；**踝桶 2/4 场景被旗标，且腓骨最先**。
- R5：单次跌倒物理**复现不了**；用现场运动学的高度分布投影 → **与临床同向（decreasing）**。

### R4 垫子刚度 × 旋后权衡 ✅ —— `results/opensim_fe/PAD_SUPINATION_TRADEOFF_REPORT.md`
- 耦合 S1 的实测折减 R(k) + R1 的旋后模型；新模块 `src/climbing/coupling/pad_supination.py`（opt-in）。
- **模型结论：无内部最优**——`total_risk(k)` 对 k **单调递减**，**k\* → 刚性极限**；`L_roll∈{25,40,60}mm` 三档稳健。
- **关键张力**：**软垫省下的轴向（S1 实测最多 −23.6%）远抵不过它因脚沉入垫（δ=F/k）引起的额外旋后侧弯**（O(10) 倍）→ 在旋后轴上"软垫更安全"的直觉**不成立**。
- 安全余量随高度收缩：刚性下 `total_risk` 0.659(2m)→0.779(4.5m)（高能量下"无垫可救"，呼应 [Beurienne2025] "rigidity may be ineffective for high energy"）。

## 6. 综合结论（关键）

1. **两条独立路线收敛到腓骨/外踝**：R2（纯轴向）场景矩阵中**腓骨最先越阈**；R1 补上现场 #1 机制（旋后）后**腓骨远端在真实高度即越阈**。→ 我们此前"**腓骨异常敏感**"的疑点，**被现场机制解释**，且**与临床踝伤 #1 对应**。
2. **方向对齐、数值偏高**：模型下肢 100% vs 临床 61–67% → 纯轴向**过度旗标**下肢；缺上肢/软组织通路（复现不了"踝扭伤 #1"，只能对应**踝骨折 27%**）。
3. **R5 = 落地姿态分布效应**（非单次物理）：低坠行程短→来不及旋转→足先→下肢；高坠→旋转→上肢/头。姿态投影与临床同向。
4. **R4 垫子刚度两难（已量化）**：S1 轴向说"软垫更安全"，但**加上旋后后结论反转**——本模型下 `total_risk` 随 k **单调递减（刚性最优）**，因为**软垫的轴向收益（−23.6%）远小于它带来的旋后侧弯**（O(10)×）。**数值依赖上界式侧向模型**，但"**两轴方向相反**"的张力是稳健的。
