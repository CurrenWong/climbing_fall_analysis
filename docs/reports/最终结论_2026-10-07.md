## 一、对总目标的回答

总目标（`docs/总体进度.md:56`）：回答「抱石摔落时各部位骨骼承受多少应力、会不会骨折」。分三层答：

- **(a) 应力绝对值：答不了。** 两个独立原因。① **绝对量不可移植** —— 同一根跟骨的"首次骨折高度"
  随建模选择飘 **3–4 倍**（粗体素 "7.0 m"（已判为伪影）/ 平滑 gmsh 26.5 m / 真 AM50 跟骨 ≈2.0–3.0 m /
  弹性跖面 5.43 m；`docs/总体进度.md:216-229`）。② **工况错配（regime mismatch）** ——
  本模型是**软垫** 2–5 m，文献 [Y25]/[T22] 是**刚性地面** 5–20 m，冲击窗 **56–67 ms** vs 1–5 ms
  （`docs/P2_踝结论_2026-10-07.md:251-262`）。所以既不报应力、也不报骨折率。
- **(b) 会不会骨折（相对 / 机制层面）：能答一部分。** 四条（§二）：滑动/卡住是几何相变、
  内翻轻于外翻、峰值时刻随高度单调提前、踝单项量级对得上。这四条**对绝对量程不敏感** ——
  它们是排序与结构关系，换标定不翻。
- **(c) 部位分布：只能答踝一项。** 1000 次 MC 里 7 个骨部位**全 0 骨折**（最高利用率 0.72，`tibia_distal`），
  踝是**唯一非空项**（34.5%；`results/p1_montecarlo.txt:184-198`）。"踝第一大"在本模型内属**平凡成立**
  （其余全零），**不是比较出来的**。

**边界一句话**：相对（排序 / 机制 / 单项量级）可用；绝对（N / MPa / % / 峰值时刻）不可用。

## 二、站得住的四条结论

1. **滑动 vs 卡住是几何相变，与高度无关。** 判据 `|sin β| > mu_slide`（`src/climbing/pad2d.py:253`；
   推导 `:46-49`）。β ∈ {10°,20°,30°} 时 `|sinβ|` ≈ 0.174 / 0.342 / 0.500，`mu_slide=0.4`
   （`scripts/phase_p1_montecarlo.py:143-148`）⇒ 10°/20° 卡住、30° 滑动。由此复现 [T22] Table 4 四条结构：
   `(5m,10°)` 骨折、`(5m,20°)` 骨折、**(5m,30°) 足滑动无骨折**、`(10m,*)`/`(20m,*)` 全骨折，
   且存在「角度—高度」转变曲线（`paper/_text/TFSR_7_1875582.txt:233-243`；
   测试 `tests/test_pad2d.py::TestP2bV6Table4`（`:865`）；判据 `docs/方案更新_v2.md:817-822`）。
   ⇒ **落地姿势角度是与高度同等重要的自变量**。**对绝对量程不敏感**：滑动/卡住只由 `sinβ` 与
   `mu_slide` 之比决定，与 `f_pad` 的绝对标定无关。

2. **内翻损伤轻于外翻（反直觉，复现 [T22]）。** 同 |β|、同高度下，外翻（β<0）的
   `peak_ligament_strain` 与 `ankle_bone_utilization` 均 **>** 内翻（β>0），跨 3 高度稳定（P2b）。
   机制 = 力臂按 β 符号在 `ankle_d_medial_m=0.045` / `ankle_d_lateral_m=0.030` 间切换
   （`src/climbing/pad2d.py:236-237`；`scripts/phase_p1_montecarlo.py:149-150`）。
   文献：`paper/_text/TFSR_7_1875582.txt:153-158, 230-232`；测试 `tests/test_pad2d.py::TestP2bV9`（`:918`）。
   **对绝对量程不敏感**：是同一 β 下两条力臂的相对关系。

3. **头颈峰值时刻随高度单调提前。** 实测 2 m **37.0** / 3 m **33.8** / 5 m **31.2** / 10 m **28.8** /
   20 m **26.6** ms，严格单调（`src/climbing/head_branch.py:406-412`；实测表 `docs/P2_踝结论_2026-10-07.md:232-244`；
   测试 `tests/test_head_branch.py::TestV8PeakTimeMonotoneWithHeight`（`:187`））。
   对标 [T22] Table 3（峰值随高度提前，`paper/_text/TFSR_7_1875582.txt:210-212, 220-226`）
   与 V8 判据（`docs/方案更新_v2.md:866`）。**对绝对量程不敏感**：单调性是序关系；
   刚度扫描 `k_neck` 200→12000 N/mm（60×）只把 2 m 峰值从 37.0 挪到 32.0 ms（**饱和**，
   `docs/P2_踝结论_2026-10-07.md:246-249`），序关系不翻。

4. **踝损伤单项量级可算：34.5% vs 实测 40%（1.16x）。** MC 1000 次：踝（扭伤或骨折）
   **345 / 1000 = 34.5%**（`results/p1_montecarlo.txt:185`），对 [B25] 实测 40.0%
   （`paper/_text/fspor-7-1609133.txt:207`）。其中踝扭伤 345/1000 = 34.5% vs 28.0%（1.23x）；
   踝骨折 228/1000 = 22.8% vs 8.0%（**2.85x 偏高，见 §三**）。`rotation='without'` 子集踝
   **0/321 = 0.0%**，是**正确结构性对照**（该子集无踝自由度，`results/p1_montecarlo.txt:200-203`）。
   **对绝对量程不敏感**：这是踝单项在给定场景权重下的频率量级，不是某一绝对力值。

## 三、站不住的三条 + 统一根因

| 靶子 | 判据 | 模型实测 | 文献 | 判定 |
|---|---|---|---|---|
| **V5 分布形状** | [B25] 损伤部位分布（下肢 67%、膝 15%、肘 16%） | 7 骨部位全 0；无膝/肘/上肢自由度 | 下肢 67%（`fspor-7-1609133.txt:172`）、膝 15%（`:208`） | ❌ 分布形状未复现 |
| **V3 绝对时刻** | 头部应力峰值 ≤ 0.0125 s | **26.6–37 ms** | [Y25] ≤12.5 ms（`docs/方案更新_v2.md:861`） | ❌ |
| **V8 绝对时刻** | 20 m 时 ≤ 5 ms | **26.6 ms** | [T22] Table 3（`TFSR_7_1875582.txt:220-226`） | ❌ |
| **踝骨折拆分** | ≈ [B25] 8% | **22.8%** | 8.0%（`fspor-7-1609133.txt:204`） | ❌ **2.85x 偏高** |

统一根因 = **工况错配（regime mismatch）**：

| | [Y25] / [T22] | 本模型 |
|---|---|---|
| 落地面 | **刚性地面** | **软垫** |
| 高度 | 5–20 m | 2–5 m |
| 冲击持续 | 1–5 ms | **56–67 ms**（冲击窗实测） |
| 躯干峰值加速度时刻 | ≤ 12.5 ms | **23.6–32.0 ms**（冲击窗内 t−t0 实测） |

（表来源 `docs/P2_踝结论_2026-10-07.md:251-262`。）

**垫子把冲击摊到 60 ms 量级 ⇒ 任何峰值都不可能落在 12.5 ms 内。** 这不是颈部刚度问题：
`k_neck` 从 200 → 12000 N/mm（60×），2 m 峰值只从 37.0 → 32.0 ms，**饱和**
（`docs/P2_踝结论_2026-10-07.md:246-249`）。

踝骨折拆分同样修不动，且是**结构性**的。撕脱阈值 `ANKLE_AVULSION_LOAD_N = 300 N` 被 V6 校准钉死
（`(5m,30°)` sliding `F_lig_eff ≈ 154 N < 300`；（10m/20m,30°）`349/655 N > 300`；
`src/climbing/pad2d.py:162-168`），故 `T ≤ 349`。而在 `share=0.477` 下 stuck 子集**最小**
`F_lig ≈ 902 N ≫ 300` ⇒ **stuck 全部饱和**，fracture 率 = stuck 比例（228/345 ≈ 2/3），
**与 `share` 无关**（`docs/P2_踝结论_2026-10-07.md:149-165`）。stuck 比例又被 V6 反锁：
要复现 [T22] Table 4，必须 `mu_slide ∈ [sin20°, sin30°) = [0.342, 0.5)`；此区间内
{10°,20°} 卡住 / {30°} 滑动 ⇒ stuck 比例恒为 **2/3**。

**结论：这三条不是调参能解决的。** V3/V8 的绝对时刻、V5 的分布形状、踝骨折拆分的偏差，
根都是同一个：文献量与模型量分属两种工况。**唯一出路是补垫子物理 / 工况对齐（= P5 抱石专用标定），
不是继续调 P2/P4 参数。**

## 四、精度声明

- **相对可用**（排序 / 机制 / 单项量级，对绝对量程不敏感）：§二四条结论 + regime mismatch 论证本身。
- **绝对不可用**：任何以 **N / MPa / %** 给出的绝对值；踝骨折率（22.8%）；峰值时刻（26.6–37 ms）；
  应力绝对值。
- **包线**：**2–5 m**、`beta0 ∈ {10°,20°,30°}`、`mu_slide=0.4`、`ankle_d_lateral_m=0.030`、
  `ankle_d_medial_m=0.045`、`ankle_load_share=0.477`（`scripts/phase_p1_montecarlo.py:143-152`）。
- **超出包线无效**：**>10 m 或 beta0 > 30°** 外推无效（`docs/P2_踝结论_2026-10-07.md:167-169`）。
- **与既有立场一致**：绝对骨折高度不可移植（同骨不同建模飘 3–4×，`docs/总体进度.md:216-229`），
  本结论不与之冲突。
