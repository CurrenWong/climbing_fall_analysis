# 目标重构 · 刚性验证 → 垫上推断

> **一句话**：项目收束为**两阶段** ——
> **阶段一** 用刚性地面文献数据（[Y25] 袁红敏 2025 / [T22] Li 2021 + 模块级尸体实验）**证明模型有效**；
> **阶段二** 用验证过的模型**推断抱石摔垫**（GRF、踝损伤、骨折率、头颈时序、垫参数敏感性）。
>
> 本文是**目标层权威件**（为什么做 / 做到什么算够 / 推断怎么合法）；执行细节仍归各专项文档（见 §七）。

---

## 〇、为什么要重构目标

此前的目标形态是「两条线 + 15 个 V/A 靶平铺」，带来三个问题：

1. **验证与推断混在一起**。垫侧直接拿临床分布 [B25] 当验证靶（V5），而垫上**没有实测跌落数据**（P5 缺口：文献里没有抱石专用跌落数据）⇒ 垫侧永远无法直接验证、只能推断。把"推断输出"当"验证靶"，4 个 ❌ 里混入两类根因（工况错配 / 模型范围），长期扯不清。
2. **可信度来源错位**。能验证的工况是**刚性地面**（[Y25] 5–20 m 直立双足、[T22] THUMS 5 m 死落、Anderson/Tochigi/Funk/吴恺 模块级实验），不能验证的工况是**软垫**。按 V&V 惯例（validation hierarchy），可信度必须在可验证工况上挣得，再以**误差传递**的形式带入推断。
3. **模型改动缺优先级**。缺口平铺（G1–G7，见 §三）时看不出"改哪个才解锁推断"。以**推断目标量反推缺口**，结构改动才有最小集。

**重构后的逻辑链**：

```
刚性文献数据 ──验证──► 模型（模块冻结）──推断──► 垫上工况输出
   硬靶 V/A                    │                 点估计 + 区间 + 工况标签【垫】
   模块级实验                  唯一自由度 =        垫侧临床数据只做后验检查
                               接触层垫本构 + 工况参数
```

## 一、两阶段目标定义

### 1.1 阶段一（验证）：刚性地面工况，证明模型有效

**验证数据源**（全部为刚性地面或模块级实验，无一条来自垫工况）：

| 层 | 数据源 | 验证什么 |
|---|---|---|
| 系统级 · 时序/机理 | [Y25] 袁红敏 2025（直立双足 5–20 m） | V1 V2 V4 V7 + 相对模式 A1–A4 |
| 系统级 · 时序 | [T22] Li 2021（THUMS 5 m 死落，Table 3） | V3 V8 V9 |
| 模块级 | Anderson 2006/2007（软骨厚度/接触）、Tochigi 2006（韧带）、Funk 2002（踝耐受）、吴恺 2012（600 N 双靶） | 踝 FE 子模块量级 |

**"有效"的操作定义**（验证充分性判据，不是"全靶全过"）——按四个维度分别判定：

| 维度 | 靶 | 达标线 | 现状（2026-10-10） | 判定 |
|---|---|---|---|---|
| **时序** | V3 ≤12.5 ms、V8a 峰时随高单调 | 全过 | ✅ V3 = 11.4→9.0 ms（k_neck=2500）、V8a = 18.8→14.0 ms | **有效**（V8b 残余 3.0× 作已知偏差入账，见 §二） |
| **机理** | V4 两端先于骨干、V6 Table 4 结构、V9 内翻<外翻 | 全过 | ✅ 4/6/9 命中（V6 双工况 9/9、V9 6/6） | **有效**（V7 阶跃/渐进留缺口） |
| **幅值** | V1 首折高度 6–9 m、V2 <7 m 无骨折 | V2 过；V1 只报偏移 | ✅ V2（胫远 12 m、股骨颈 16 m）；V1 偏高 3–4×（D5） | **条件有效**（只做相对量/比值） |
| **统计** | A1 聚类边界 7/16、A2 阶跃集合、A3 OR、A4 双路径 | ≥3/4 | ❌ 0/4（A3/A4 结构性失败） | **未达标**（结构缺口 G3/G4，见 §三） |

⇒ **阶段性有效性声明（可原话进论文）**：

> 模型在刚性地面工况下，**时序与踝失效机理维度已被文献数据验证**；幅值维度限于相对量；统计维度（人群分布类结论）**尚未验证**，相关垫侧输出按"量级 + 方向"降级引用。

### 1.2 阶段二（推断）：软垫工况，输出预测

**推断目标量**（垫侧输出清单，按当前可信度分级）：

| # | 推断量 | 现有输出（h=2 m 除非注明） | 支撑模块（已验证） | 可信度 |
|---|---|---|---|---|
| P-1 | GRF 峰值 / 接触窗 / 下沉入 | 34.8 kN / 34 ms / 12.96 cm | 1D 链（能量自洽、逐位回归锁） | **高**（绝对量，`S5_QUOTABLE` 口径） |
| P-2 | 软垫 vs 刚性同高对照 | 峰值 −24%、窗 +139%（"护压伤扭"） | 1D 链双工况 | **高**（相对量） |
| P-3 | 踝损伤率 | 34.5%（对【实】40%，1.16×） | 踝判据 + MC | **中**（量级对、方向对） |
| P-4 | 踝骨折率 | 22.8%（对【实】8%，**2.85× 高估**） | 撕脱/扭伤判据 | **低**（必须带偏差入账，见 §二） |
| P-5 | 头颈峰时 | 26.6–37.0 ms（k_neck=200 发表口径） | 头颈振子 | **低**（刚性 V8b 残余 3.0× 传导） |
| P-6 | 垫参数敏感性（α_pad 扫描） | α_pad≈30 可闭合垫侧 V3，V6/V9 零回归 | 1D 链 | **中**（设计建议用；绝对 α 不可信） |

**推断的合法路径（模块冻结原则）**：

1. 阶段一验证过的模块（1D 动力学、踝判据、头颈、OpenSim→FE 载荷链）**逐字节冻结**（现有回归锁机制沿用）；
2. 进入垫侧时**唯一允许变的自由度** = 接触层（泡沫四分量本构）+ 工况参数（h、β₀、μ_slide、垫厚）；
3. 垫侧临床数据 [B25] **降级为后验合理性检查**（sanity check：踝为第一大部位、下肢主导、34.5%≈40%），**不再是验证靶**；V5 相应转为"范围外"（缺上肢/膝/肘自由度，属模型范围问题）；
4. 一切垫侧数字带**工况标签【垫】+ 包线（H6）+ 不可迁移项声明**（沿用论文 §5 口径）。

## 二、可信度链（validation hierarchy）

每个推断量 ← 依赖模块 ← 验证证据 ← 向垫侧传递的残余误差：

| 推断量 | 依赖模块 | 模块验证证据 | 传递到垫侧的残余误差 |
|---|---|---|---|
| P-1 GRF/接触窗 | 1D 链 + 垫本构 | 刚性侧 V2/V3 时序达标；能量闭环 1.1%（**待复核**：须按修正 sink 13–15 cm 重跑 FE） | 垫本构未标定（α_pad 敏感：10–30× 可达 V3）⇒ 窗长 ±50% 级 |
| P-2 同高对照 | 1D 链双工况 | 同上 | 比值类比绝对量稳；口径差（标定链 vs 发表链）已声明 |
| P-3 踝损伤率 | 踝判据 + 2D | V6 9/9 + V9 6/6（**机理维度已验证**） | 姿态采样依赖 [B25] Table 3 ⇒ ±3 pp（种子稳定性 ≤2.9 pp，Wilson CI [31.6, 37.5]%） |
| P-4 踝骨折率 | 撕脱/扭伤判据 | V6 机理 ✅，但**判据结构**（骨折≡卡住）未在刚性侧独立验证 | **系统性 2.6–3.1× 高估**（跨三种子稳定；对阈值/垫刚度/载荷分享三旋钮全不敏感）⇒ 输出 = **上界**，偏差因子入账，**不伪造校正点估计** |
| P-5 头颈峰时 | 头颈振子 + 1D 加速度 | V3 刚性达标（k_neck=2500 为文献上限） | V8b 刚性残余 **3.0×**（1D 链极限 14.0 vs 4.6 ms）⇒ 垫侧时刻同带 ~3× 界 |
| P-6 垫敏感性 | 1D 链 | P5 前置复核：正对照 6/6 逐位、单调 6/6 | 单调性可信；α_pad 绝对值不可信（α≈30 是情景假设，非真实泡沫物性） |

## 三、残余缺口 → 按"是否阻塞推断"重排

缺口定义 G1–G7 沿用 2026-10-10 分析；详细归因见 `总体进度.md` §五、`rigid_vtarget_2026-10-08.md` §6、`OpenSim_FE复现方案.md` S4。

| 缺口 | 内容 | 阻塞哪个推断 | 需要的结构改动 | 优先级 |
|---|---|---|---|---|
| **G1** | V8b @20 m ≤5 ms 不可达（14.0 vs 4.6 ms，3.0×） | **P-5 时序** | **5–9 段多刚体链**（= P3 二切）+ 局部组织峰观测量；或 1D 应力波杆（更激进） | **P1** |
| **G3** | A3 OR 无定义（确定性二值矩阵完全分离） | **P-4 骨折率** | **被试级变异 MC**：50×9 矩阵改概率语义（σc/截面/质量人群抽样，每格=失败率） | **P2** |
| **G4** | A4 双路径 rank-1（严格线弹性天花板） | **P-4 + 骨折分布形状** | **损伤演化/渐进失效本构** + 关节顺应性/被动肌肉进载荷链 | **P3** |
| **G5** | A1 边界 [5,12] vs [7,16]、A2 漏股骨/胸椎（低高度饱和） | （统计维度） | 解剖端分布载荷 + raw/ℓ 双口径判据（口径级，不改求解结构） | P0（顺手） |
| **G6** | V7 阶跃 vs 渐进分类 | （统计维度） | 同 G4（渐进失效）；骨盆环渐进需整体骨数据 | 随 G4 |
| **G7** | V1 首折 6–9 m、股骨颈 17–34 m | **不阻塞** | **不改**（D5 红线：只报偏移量，不标定） | 不做 |

**最小集判读**：

- 只求「推断 GRF / 同高对照 / 踝损伤率」⇒ **不需要新结构改动**，现有模型即可出 P-1/P-2/P-3（带诚实区间）。
- 求「推断骨折率 / 分布形状」⇒ **必须** G3（概率矩阵）+ G4（非线性本构），否则 P-4 永远停在 2.85× 上界。
- 求「推断时序进 ±2×」⇒ **必须** G1（多段链）。

## 四、明确不做（红线）

1. **不标定绝对骨折高度**到 [Y25] 7–9 m（D5：范式差永久——THUMS 全身显式特有网格/材料/沙漏；只报偏移量）。
2. **不把垫侧临床分布 [B25] 当硬验证靶**（V5 转范围外；缺上肢/膝/肘自由度属模型范围，不是标定问题）。
3. **不调参数凑刚性靶**（A1 b1 卡 2.0 是判据边界；股骨颈 16 m 保持现状待整体骨数据；"不调参凑答案"）。
4. **不造"垫上实测"**：垫侧预测就是预测，永远带推断标签，不与验证混写。
5. **不上全身 THUMS 显式瞬态做绝对对标**（身份层可选项，非本目标必需）。
