# 目标重构 · 刚性验证 → 垫上推断

> **一句话**：项目收束为**两阶段** ——
> **阶段一** 用刚性地面文献数据（[Y25] 袁红敏 2025 / [T22] Li 2021 + 模块级尸体实验）**证明模型有效**；
> **阶段二** 用验证过的模型**推断抱石摔垫**（GRF、踝损伤、骨折率、头颈时序、垫参数敏感性）。
>
> 本文是**目标层权威件**（为什么做 / 做到什么算够 / 推断怎么合法）；执行细节仍归各专项文档（见 §七）。

---

## 〇、为什么要重构目标

此前的目标形态是「两条线 + 15 个 V/A 靶平铺」，带来三个问题：

1. **验证与推断混在一起**。垫侧直接拿临床分布 [B25] 当验证靶（V5），而垫上**没有实测跌落数据**（P5 缺口：文献里没有抱石专用跌落数据）⇒ 垫侧永远无法直接验证、只能推断。把"推断输出"当"验证靶"，4 个 ❌ 里混入两类根因（工况错配 / 模型范围），长期扯不清。
2. **可信度来源错位**。能验证的工况是**刚性地面**（[Y25] 5–20 m 直立双足、[T22] THUMS 5 m 死落、Anderson/Tochigi/Funk/吴恺 模块级实验），不能验证的工况是**软垫**。按 V&V 惯例（validation hierarchy），可信度必须在可验证工况上挣得，再以**误差传递**的形式带入推断。
3. **模型改动缺优先级**。缺口平铺（G1–G7，见 §三）时看不出"改哪个才解锁推断"。以**推断目标量反推缺口**，结构改动才有最小集。

**重构后的逻辑链**：

```
刚性文献数据 ──验证──► 模型（模块冻结）──推断──► 垫上工况输出
   硬靶 V/A                    │                 点估计 + 区间 + 工况标签【垫】
   模块级实验                  唯一自由度 =        垫侧临床数据只做后验检查
                               接触层垫本构 + 工况参数
```

## 四、明确不做（红线）
