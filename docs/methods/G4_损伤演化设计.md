## 0. 一句话目标

在单骨 FE 的 **σ(h) 后处理层**引入**双线性弹塑性（损伤）本构**（并启用既有**载荷链顺应性**路径），打破**严格线弹性**的 rank-1 天花板，使 **A4** 双路径可分（或如实报限）、**A2** 股骨/胸椎恢复区分度、**V7** 阶跃/渐进可分。

---

## 1. 背景与缺口

| 缺口 | 现状 | 需要的结构改动 |
|---|---|---|
| **A4** 双路径 PCA | rank-1（PC2=0.024%）——严格线弹性下每部位 σ ∝ load ⇒ 协方差**数学上必 rank-1**；[Y25] 的双路径（自下而上 / 自上而下）是**传导动力学**属性 | 损伤/渐进失效本构 ⇒ σ(h) 形状分化（饱和/阶跃/渐进） |
| **A2** 缺失股骨/胸椎 | 低高度**饱和为常值 1** ⇒ 无区分度 | 同上（+ 或与 FE 载荷分配缺陷相关） |
| **V7** 阶跃 vs 渐进分类 | 缺失 | 同 G4（阶跃=单元突发失效链；渐进=刚度缓慢退化） |

> 依赖：G4 是 G6（V7）的前提；G4 之前 A4 怎么跑都是 rank-1。

## 2. 关键事实（使 G4 便宜——零 FE 重跑）

1. **σ(h) 矩阵本就是后处理线性缩放**：`fracture_matrix.py:583` `σ_vm(h) = σ_vm_ref · load(h)/load_ref`——骨头 FE **只解一次**，把线性缩放律换成损伤律 ⇒ **零 FE 重跑**。
2. **THUMS 材料卡已含损伤参数**：逐 PID 的屈服 `σ_y`（卡 `nums[4]`）与切线模量 `E_t`（卡 `nums[5]`），但 `read_materials` **当前丢弃** ⇒ 参数**存在、无需新数据、无需调参**。
3. **载荷链已有可选顺应性路径**：`opensim_fall.py:643` 的 `run_dead_drop(..., passive=PassiveStiffness(...))` ⇒ 只需**新驱动调用**，**不改** `coupling/`。
4. **σ(h) 的冻结输入**：`results/opensim_fe/fracture_matrix_bc2.json` 等为**只读冻结件**；G4 产出**新件**，绝不覆盖。

## 4. 本构与诚实风险

**双线性弹塑（降阶，后处理）**：`σ(ε) = E·ε`（若 `ε ≤ σ_y/E`）否则 `σ_y + E_t·(ε − σ_y/E)`。一个 `E_t` 即可跨越**饱和（E_t→0）/ 阶跃（快速软化）/ 渐进（缓降）**三种形状。

**选型对照**：CDM/双线性 = 唯一覆盖 A4+A2+V7 且参数卡内可得 ⇒ **推荐**；crushable foam 只有饱和；单元软化/删除（静态 FEBio 发散、网格依赖）✗；唯象后屈曲线 = CDM 特例。

**诚实风险（必须记录）**：
- 皮质骨 `E_t/E ≈ 0.82` 只给**膝拐**（单调），**非平台**；小梁域 `E_t/E ≈ 0.33`（较强）⇒ 长骨形状分化**可能温和**。
- ⇒ **rank-2 很可能脱离 0.024%**，但 `{腓,骨盆,颅}` vs `{胫,股,脊柱}` 的**强 LP 分离不保证**（见 §5 独立判定 + §7 备选）。
- ⇒ **A2 股骨/胸椎**与腓骨载荷量级缺陷**同根因**（FE 载荷分配），G4 **单独很可能修不好**——预先登记该边界。

## 7. 备选（若 LP 分离失败——禁调参）
