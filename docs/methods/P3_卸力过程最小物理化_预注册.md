## 0. 一句话目标

> 现在模型里 `M = k_θ·θ` 是**单值、无历史**的（`k_θ = 350 N·m/rad` 常数），
> 「卸力的**过程**」只由一个**被动的率相关饱和项**近似 ⇒ **力的量级被唯象项顶上，而不是由物理机制决定**。
> 本件把 `M(θ)` 换成**实测的力-长关系**＋**滞回（加载/卸载不同曲线 = 卸力功）**，
> 检验「弹性/几何项能否成为力的**主导**项」。如实 PASS/FAIL。

## 1. 依据（**两条，均可复核**）

### 1.1 结构缺口（用户提出的）
现模型 = **双腿合并** + **被动率相关上限**；**没有**：
① 主动控制律（预激活 + 离心削峰）② **力-长关系与历史/滞回** ③ 两腿各自自由度。

### 1.2 ★ 可检验的后果（在**本项目自己的数字**里）
两段腿的**弹性（几何屈曲）项全程仅 1.65–2.0 kN**（C1/B2a 窗口分解），
而实测 0.42 m 落箱为 **5.36 BW = 4.2 kN**（`PMC9465758`）
⇒ **几何卸力只解释不到一半 ⇒ 剩下的由唯象率项顶上。**
**⇒ 本件的核心指标就是「弹性项在总力中的占比」—— 目前不是主导，应当成为主导。**

## 2. 设计（改什么）

`pad.py` 的 `TWO_SEG_LEG` 门**再扩**（默认 `None` ⇒ 既有路径逐位不变）：

```python
TWO_SEG_LEG = {..., "m_theta_table": None, "hysteresis_frac": None}
```
- **力-长**：`M(θ)` 由**表格**（θ, M）插值取代 `k_θ·θ`；
- **滞回**：卸载支取 `M_unload(θ) = (1 − hysteresis_frac)·M_load(θ)`，
  ⇒ 单圈耗散功 `W_hys` = `hysteresis_frac·∮M dθ`（**这就是「卸力功」**）。
