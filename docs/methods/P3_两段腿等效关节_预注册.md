# P3 · B2a 件：两段腿「等效单关节」预注册（把线性腿弹簧换成几何屈曲的刚度）

> **状态**：**设计定稿 · 预注册冻结（待用户签 §5/§7）**｜结构照抄 `G1_多段链设计.md` / `FP_STROKE_REPORT.md` 先例
> **上游**：`results/FP_STROKE_REPORT.md`（B1：`k_stop` 是软接触区主控瓶颈；`self`/`stiff` 的 `h*` 不可定）
> **红线**：⛔ 不追 6–9 m；**禁止**以「使判据变绿」为选择标准（§5 B2a-J5）

---

## 0. 一句话目标

> 把 `pad.py` 的**线性**腿弹簧 `f = k_flex·x` 换成**两段腿几何屈曲**的等效轴向力
> `f = k_θ·θ / (l·sin(θ/2))`（`θ` 由腿缩短量反解），使模型**自带**刚度随屈曲角上升的物理；
> 检验它能否修掉「软接触下需靠未标定的 `k_stop` 才有力」这一结构缺陷。如实 PASS/FAIL。

---

## 1. 依据与设计定理

### 1.1 ★★★ 设计定理：两段腿 ≡ 一个**非线性（硬化）弹簧**

两段腿（股/胫各长 `l`）的腿长 `L(θ) = 2l·cos(θ/2)`，缩短量

```
s(θ) = 2l·(1 − cos(θ/2))        ⇒        θ(s) = 2·arccos(1 − s/(2l))
```

关节力矩 `M = k_θ·θ` ⇒ 等效轴向力

```
F(s) = M / (ds/dθ) = k_θ·θ / (l·sin(θ/2))          ← ★ 本件的核心替换
```

**⇒ 关节准静态（`k_θ` 恒定）时，两段腿与单自由度框架**完全等价**，
只需把 `f = k_flex·x` 换成上式 —— 无需新增自由度、无需改 ODE 结构。**

**性质**（用来自检，不是结论）：`s ∝ θ²`（小角）而 `F` 有限 ⇒ **`dF/ds → ∞`**（直腿的抗屈曲刚度无穷大）；
`θ → θ_max` 时 `F` 快速上升 ⇒ **硬化**。这正是线性弹簧缺的物理。

### 1.2 为什么值得做（B1 留下的问题）

B1 证明：**线性弹簧 + 未标定的 `k_stop`** 在实测跟垫口径下，
`stiff`@1 m、`self`@2 m 就被止段顶起 ⇒ `self`/`stiff` 的 `h*` **不可定**。
**⇒ 若几何屈曲自带足够刚度，模型就不必依赖 `k_stop`。**

## 2. 设计（改什么）

1. `pad.py` 新增门（**默认关闭 ⇒ 既有路径逐位不变**）：

   在 `flex_force` 内：门开时用 `F(s) = k_θ·θ/(l·sin(θ/2))` 替换 `k_flex·s`；
   **`k_stop` 段保留但改按 `θ` 判定**（`θ > θ_max` ⇒ 行程耗尽，见 §4）。
2. 新探针 `scripts/leg2seg_probe.py` → `results/leg2seg_probe.json`；判定件 `results/LEG2SEG_REPORT.md`。
3. 单测：门默认 `None` ⇒ 逐位不变；门开 ⇒ `F(s)` 单调且 `dF/ds` 随 `s` 增大（硬化）。

## 9. 诚实边界

1. **`F(θ→0) → 2k_θ/l ≈ 1.65 kN 是有限的**（不是无穷）—— 线性力矩律 `M=k_θθ` 的产物；
   ⇒ 小角段偏「恒力弹簧」，与真实直腿的无穷抗屈曲刚度**不完全一致**（量级正确、极限不对）。
2. **`θ` 是**等效复合**屈曲角**（含踝背屈与髋屈曲），**不是解剖膝关节角** —— 实测 COM 深度反解出的
   86–121° 已在解剖膝的合理上界附近。
3. **准静态假设**：`k_θ` 恒定 ⇒ 忽略肌-腱的力-速依赖（真实离心收缩会更强）。
4. 用 `leg_ext0 = 0.85` 作为 `2l` 是**模型自洽**的选择，不是独立测量。
