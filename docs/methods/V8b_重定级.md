## 2. 为什么「同口径重定义」被撤回（实测，不是推理）

[G5 预注册](G5_跟垫柔顺层纠错_预注册.md) 之前先量的（`temp/g5_tibia_stress.py`）。
`chain2d.py:138` 胫骨段 `tissue_area=320 mm²` / `tissue_modulus=17 GPa` = **皮质骨 + 皮质承载
截面** ⇒ V8b 的 `ε=F/(A·E)` **本来就是骨等效应变**（此前一度误判为软组织应变，已更正）。

若按 [T22] 表注（骨量 = **effective plastic strain**，必在越屈服后才增长）改成
「**首次越屈服**」时刻，实测：

| 屈服候选 | baseline 越阈 | crush 越阈 | vs [T22] 4.6 ms |
|---|---|---|---|
| 50 MPa | 1.613 ms | 0.476 ms | 0.35× / 0.10× |
| **100 MPa**（皮质骨压缩屈服量级） | **2.497 ms** | **0.585 ms** | **0.54× / 0.13×** |
| 150 MPa | 3.314 ms | 0.632 ms | 0.72× / 0.14× |
| 200 MPa | 4.177 ms | 0.668 ms | 0.91× / 0.15× |

⇒ 越阈口径**系统性早于** [T22]（0.13–0.54×），一致性**比原口径的 1.26× 更差**。
**原批准的重定义方案据此撤回**；本项不做。

## 3. 真根因：链载荷段是「纯骨柱」，缺软组织串联柔顺

`chain2d.py:138` 胫骨段 `k_axial=1.3e7 N/m` ≡ `EA/L = 17e9 × 3.2e-4 / 0.426` ——
**纯皮质骨柱，零软组织串联柔顺**；也不含膝屈曲、姿态改变等制动分散机制。

实测后果（20 m / 80 kg）：

| 量 | baseline | crush | 文献/物理基准 |
|---|---|---|---|
| σ_胫骨峰值 | **631.5 MPa** | **1009.8 MPa** | 皮质骨抗压强度 **130–180 MPa** |
| 折算 ε | 3.71e-2 | 5.94e-2 | [T22] EPS 1.69e-2（塑性，非总应变） |
| 制动时标（峰值时刻） | 13.6 ms | 5.8 ms | 使 σ 落在骨强度内需 **≥ 27.5 ms** |

⇒ 模型预测的胫骨应力是骨强度的 **3.5–5.6×**。**这不是接触层问题**（接触层吸能上限
占输入 0.2%，见 [G5 预注册](G5_跟垫柔顺层纠错_预注册.md) §2），而是**载荷路径刚度过高**。

**与 G5 的关系**：G5 修的是**接触层**（跟垫柔顺层，2 MPa → in-vivo 185 kPa）；
本件根因是**载荷段**（`SEGMENTS_6` 的 k_ax）。两者是**不同缺陷**，G5 **不会**修好本件。
G5 的判据 2（σ_胫骨 vs 骨强度）就是**专门用来暴露本项的**。

## 4. 单独立项：根因修复（待排期）

| 项 | 内容 |
|---|---|
| 目标 | 给 `SEGMENTS_6` 载荷段补**软组织串联柔顺**，使制动时标回到骨强度允许的 ≥27.5 ms |
| 触碰 | `SEGMENTS_6` 的 `k_axial_n_per_m`（**跑前冻结的解剖参数**）——必须新预注册 + 字节锁 |
| 锚点来源要求 | 需**下肢段轴向柔顺的 in-vivo 实测**（冲击/落地工况），不得由「让 V8b 变绿」反推 |
| 风险 | 影响峰值力 ⇒ 影响骨折阈值与峰值 kN 等**多条既有线**，需全量复核 |
| 纪律 | 与 G1/G4 同：**预注册冻结 → 跑 → 如实判**；根因项不得复用 G4 已消费的备选 |

## 5. 引用规约（防止下游误用）

引用 V8b 时**必须**同时声明：
1. 原判据下 **FAIL，20 m = 5.8 ms**（这是事实，不是被推翻的结论）；
2. 元判定 **【不可判定】** 及本件理由（观测量换口径会更差 + 模型应力高估 3.5–5.6×）；
3. **不得**引用「5.8 ms 与 [T22] 4.6 ms 仅差 1.26×，属模型类别差内」作为一致性论据
   —— 该 1.26× 是**不同观测量、不同机制**下的**巧合**，§2/§3 已证伪其可比性。
