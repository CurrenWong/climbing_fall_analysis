## 0. 一句话目标

> 把 `flex_force` 里的**无上限粘性阻尼** `c_flex·rate`（`c_flex = 400 N·s/m`，**未标定**）
> 换成 **Hill 型饱和律 + 实测离心力矩上限**：
> `f_muscle = f_ecc_max · rate/(rate + v_ref)`（`rate→∞` 时饱和到 `f_ecc_max`），
> 并检验它能否替代未标定的 `k_stop`（B1/B2a 的共同瓶颈）。如实 PASS/FAIL。

## 1. 依据：为什么这是缺口所在

### 1.1 缺口（B1/B2a 的共同结论）
`stiff` 档在实测跟垫口径下 `h*` **不可定** —— 因为 `θ_max`（或 `x_flex_max`）用尽后
**没有任何物理机制**，只能靠**未标定**的 `k_stop = 3.0e5 N/m` 造力。

### 1.2 ★★ 关键锚：肌肉的离心力**有上限**，而且上限很低
- **实测（Ruas 2023/2024，青年男性膝伸肌）**：**离心 MVC 力矩 270 ± 55 N·m** vs **等长 252 ± 47 N·m**（≈1.07×）。
- 经典文献的离心/等长比更宽（约 **1.3–1.8**）⇒ 取 270 N·m 为**下限锚**，比值作敏感性。
- **⇒ 等效关节的轴向换算** `F = M/(l·sin(θ/2))`（`l = 0.425 m`）：
  | θ | sin(θ/2) | 单腿轴向上限（M=270 N·m） |
  |---|---:|---:|
  | 86.3°（stiff 的 θ_max） | 0.683 | **0.93 kN** |
  | 111.2° | 0.825 | 0.77 kN |
  | 120.8° | 0.866 | 0.73 kN |
  | 小角（θ=30°） | 0.259 | 2.45 kN |

### 1.3 ★★★ 由此得到一个**与靶无关的力学结论**
**双足肌肉离心轴向上限 ≈ 1.5–1.9 kN，而单侧跟骨骨折阈 = 6.2 kN（高 3–4×/单腿）。**
⇒ **「靠肌肉吸能把足部力压到骨折阈以下」在 1 m 及以上**力学上不可能**；**
⇒ 高于肌肉上限的载荷必须走**被动力学路径**（骨性/韧带/软组织）——
这正是「腿绷直」工况的物理内容，也说明**靶 6–9 m 的存活不可能靠肌肉解释**。

## 2. 设计（改什么）

`pad.py` 的 `TWO_SEG_LEG` 门**扩充**（默认 `None` ⇒ 既有路径逐位不变）：

```python
TWO_SEG_LEG = {"k_theta_nm_per_rad": None, "segment_l_m": None, "theta_max_rad": None,
               "f_ecc_max_n": None, "ecc_rate_ref_ms": None}
```

`flex_force` 内：当 `f_ecc_max_n` 给定 ⇒ 把 `f_damp = c_flex·max(0, rate)`
**替换**为

```
f_muscle = f_ecc_max_n · rate / (rate + v_ref)        （rate = 屈曲速率，>0 加载）
```

**性质（自检用）**：`rate→0` ⇒ `f→0`（无粘性小速率行为）；`rate→∞` ⇒ `f→f_ecc_max_n`（**饱和**）；
`df/drate` 恒正 ⇒ 单调。**⇒ 与 `c_flex·rate` 的区别 = 有上限。**

## 9. 诚实边界

1. **`v_ref = 1.0 m/s` 是弱锚**（本件唯一非实测锁定的参数）⇒ 必须做敏感性扫描并据此判「定案/未定」。
2. **`M_ecc_max = 270 N·m` 是膝伸肌单关节**；真实下肢还含踝跖屈（可再加 0–1.5 kN）⇒ 上限可能被低估。
3. **饱和律是唯象形式**（不是 Hill 原文），选它是因为「有上限 + 单调 + 零速归零」三条性质可自检。
4. **`θ` 仍是等效复合屈曲角**（B2a 已声明）。
5. 本件**不改变** V1 判定；**不主张** 6–9 m 可达。
