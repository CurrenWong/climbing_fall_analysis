## 2. 压缩相本构（冻结）

### 2.1 本构形式：弹性 → 平台 → 压实 + 滞回塑性卸载

对**接触软组织层**（跟垫量级：E≈2 MPa、t≈18 mm）定义**单轴压溃本构**：

- **加载（压缩 ξ = comp/t 增加时）**：
  - 弹性段：`σ = E·ξ`，`ξ ≤ ξ_y`（ξ_y = σ_pl / E，屈服应变）
  - 平台段（渐进压溃）：`σ = σ_pl`（恒定平台应力），`ξ_y < ξ ≤ ξ_d`
    —— 开孔结构逐层失稳，应力被平台钳制，能量在此**不可逆**耗散
  - 压实段：`σ = σ_pl + E_d·(ξ − ξ_d)`，`ξ > ξ_d`（孔壁贴死、陡峭线性支撑）
- **卸载（ξ 减少时）**：沿**弹性模量 E** 卸载回到残余应变 `ξ_r`（滞回）：
  - `σ_unload = E·(ξ − ξ_r)`，`ξ_r` = 当前塑性（压溃）应变 = `max(ξ_y, ξ_peak − σ_pl/E)`
  - 即**永久压溃变形 ξ_r 不回弹** ⇒ 滞回面积 = 每个循环吸收的压溃能量
- **重新加载**：沿卸载线到 `σ_pl` 后继续平台/压实（标准弹塑性 + 硬化）。

> 本构参数 `ξ_y`、`ξ_d`、`σ_pl`、`E_d` 全部**跑前冻结**（§3 来源）。
> 卸载 E 与加载弹性段 E 相同（弹性卸载假设，物理标准）。

### 2.2 与既有接触层的叠加（冻结 = 整体替换，§6 决策 3）

- 接触 = **单一压溃本构** `F = A·σ_crush(comp)`（`comp` = 节点穿透量），
  **替换** `_SeriesContact`（`hard_surface` + `TissueLayer` 不再串联）。
- 理由（冻结）：`k1=1e7` 与 `k2=E/t=1.11e8` 串联后 `k_eff≈9.2e6`（k1 主导，
  `hard_surface` 本身就是"人体等效刚度"的占优层）；整体替换 = 压溃本构天然
  包含弹性段（E），物理上"组织压溃"本就包含等效刚度，且**免非线性迭代**、
  数值更稳。
- `hard_surface` / `TissueLayer` / `_SeriesContact` 类**保留不动**（G1 字节锁），
  仅 G4 门控路径使用新本构。

### 2.3 力学性质（冻结断言，实现时用测试锁住）

1. 加载平台期 `dσ/dξ ≈ 0` ⇒ **接触力不随压缩显著增长**（压溃钳制）；
2. 卸载滞回面积 > 0 ⇒ 循环耗能；
3. 全部卸载后 `ξ_r > 0` ⇒ **永久变形不回弹**（整身回弹被吸收）；
4. `σ` 在 ξ=0 处 C⁰ 连续、在弹性/平台/压实交点处 C⁰ 连续（可微不要求）；
5. 平台期面积增长仍由 `Posture.area_at(κ)` 驱动（既有机制不动）。

## 3. 压溃参数（冻结，跑前锁定）

| 参数 | 冻结值 | 来源（非调参） |
|---|---|---|
| `E`（弹性模量） | **2.0e6 Pa** | G1 冻结 `TissueLayer.modulus_pa`（跟垫量级 1-2 MPa，`chain2d.py`） |
| `t`（厚度） | **0.018 m** | G1 冻结 `TissueLayer.thickness_m`（跟垫 14-18 mm，文献） |
| `σ_pl`（平台应力） | **150e3 Pa** | 跟垫 in-vivo 峰值压应力中位 ~145-156 kPa（PMC8925218：141.4/156.3/145.5/145.8/156.5/147.3 kPa）；Gefen 175 kPa 佐证量级 |
| `ξ_y`（屈服应变） | **0.075** | 派生：`ξ_y = σ_pl/E = 150e3/2.0e6`（非自由参数） |
| `ξ_d`（压实应变） | **0.50** | 跟垫可压缩性 loaded/unloaded 0.60-0.69（压缩应变 ~0.31-0.40）+ 冲击余量；取 0.50 代表"组织压实起点" |
| `E_d`（压实模量） | **20e6 Pa** | 压实后刚度 ~10×E（组织压实段量级估计，`CrashPad.bottoming_modulus_pa=5e6` 同量级） |
| `k1`（骨/地面等效） | **1.0e7 Pa/m** | G1 冻结 `hard_surface.k_n_per_m`（`pad.py` 文档化） |

> 全部数值**跑前冻结**；除派生量 `ξ_y` 外无自由旋钮。跑后**不扫参**（除非 §6
> 决策 5 预注册的敏感性检查，那也是跑前声明）。
