> 把 `pad.py` 刚性地面的**有效接触刚度**（实测 **548 kN/m**）换成**实测跟垫值**（in-vivo **100–175 N/mm**），

## 1. 缺口与依据

### 1.1 ★★ 语义发现：`hard_surface` 的 `k_n` **不是**总刚度，而是被**乘了面积**

`CrashPad.force_n(compression, area) = stress_pa(xi) × area`，而 `hard_surface(k_n_per_m=...)` 把该值喂给
`linear_modulus_pa`（**Pa**，`thickness=1`）⇒ **有效总刚度 `k_eff = k_n × A(κ)`**。

**实测（`anchored-stiff` @0.42 m，`temp/v1_contactA_probe.py`）**：
`k_n = 1.0e7` ⇒ `F_pad = 8.625 kN`、`x = 15.728 mm` ⇒ **`k_eff = F/x = 548.4 kN/m`**（`k_eff/k_n = 0.055`）。
⇒ **其 docstring 声称的「1.0e7 N/m 动态人体等效刚度」比实际硬 18×**（实际 548 kN/m）。
⚠️ 该 docstring 自认「`hard_surface` 是全模型标定最弱的参数、无对标实验数据」——**本件正是来补这个标定**。

### 1.2 预探实测（`temp/v1_contactA_scan.py`，只读 + 临时门，已恢复）

@0.42 m 硬地面、80 kg、三档锚定 k（6.3/8.2/18.5 kN/m）：

| `k_n` | **实测 `k_eff`** | `F_pad`/BW soft·self·stiff | J1b soft·self·stiff | `F_flex`/BW soft·self·stiff | J1a |
|---|---:|---|---|---|---|
| **None**（现行） | **548 kN/m** | 10.97 / 10.98 / 10.99 | ❌3.25 / ❌2.97 / ❌2.05 | 2.89 / 2.99 / 3.54 | ✅ / ✅ / **❌0.661** |
| 3.0e6 | **177** | 6.57 / 6.58 / 6.62 | ❌1.95 / ❌1.78 / **✅1.24** | 2.85 / 3.00 / **4.43** | ✅ / ✅ / **✅0.827** |
| 2.1e6 | **128** | 5.71 / 5.72 / 5.77 | ❌1.69 / ❌1.55 / **✅1.08** | 2.83 / 3.11 / 4.31 | ✅ / ✅ / ✅ |
| 1.5e6 | **94** | 5.04 / 5.05 / 5.29 | ❌1.49 / ❌1.37 / **✅0.99** | 2.82 / 3.06 / 4.17 | ✅ / ✅ / ✅ |
| 1.0e6 | **66** | 4.37 / 4.39 / 4.93 | ✅1.29 / ✅1.19 / ✅0.92 | 2.79 / 2.98 / 3.99 | ✅ / ✅ / ✅ |

**`F_pad/F_flex`（结构量）**：None **3.79/3.67/3.10** → 3.0e6 **2.30/2.19/1.49** → 1.0e6 **1.57/1.47/1.24**（单调降）

### ★ 三条预读（构成本件的诊断）
1. **`F_pad` 对接触刚度是**真杠杆**（10.99 → 6.62 → 4.4 BW 平台）⇒ 诊断成立的一半**；
2. **`F_flex` 几乎不随接触刚度变**（soft 2.89→2.79，stiff 3.54→4.43；`k_eff ≫ k_flex` 使其近似解耦）
   ⇒ **J1a 的缺口不是接触层能修的**；
3. **在实测锚带内（`k_eff` 100–175）只有 `stiff` 档两判据都过**；`soft`/`self` 仍 **1.5–1.9×** ——
   而三档**只差 `k_flex`**，真人 soft/self 的差别是**行程/运动学**（COM 深度 **0.43/0.37 vs 0.23 m**）
   ⇒ **这是模型类别不足（缺运动学自由度），属下一件 B。**

## 9. 下一件 B（触发已在预探坐实）

**A 修好了 `stiff` 档（J1b 2.05→1.08–1.24 ✅、J1a 0.66→0.75–0.83 ✅），但 `soft`/`self` 仍偏高 1.5–1.9×**

（Shamaei 2013 膝/踝 ~400 Nm/rad 量级）。**须另行预注册。**

## 10. 诚实边界

1. **`k_eff = k_n × A(κ)` 是「模量×面积」而不是经典接触刚度**；`A(κ)` 用 `Posture.contact_schedule`
   （**未标定**，且是**垫上**的接触面积，非硬地面足跟接触区 ~1000–2000 mm²）⇒ `k_eff` 是**等效量**。
2. **锚带 100–175 N/mm 的口径**：in-vivo 跟垫刚度（Bennett & Ker / Ker 1996）是**整跟垫**的量；
   本件把它当作**地面-足**接触层的等效刚度使用，是**最可辩护的近似**，不是恒等。
3. **三档只差 `k_flex`**（其余字段冻结为 `controlled-drop`）⇒ 与实测 soft/self 的**运动学差**未建模
   ⇒ A-J1 对 soft/self 的 FAIL **不得**读作「接触层无效」（见 §9）。
4. **单高度**（@0.42 m）；未做高度网格。
5. 本件**不改变** V1 判定与 `LEG_K_ANCHOR` 的判定（后者是**门关**口径）。
