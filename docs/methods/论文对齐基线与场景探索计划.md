## 2. 对齐基线（冻结，用于后续场景）

**模型**：`σ_region(h) = F_bone(h) / A_section`（纯轴向 1D）+ 论文表1 **子区域强度**（胫/腓两端 70、股骨颈 80、足 150、骨盆 180、脊柱 150、颅骨 160）。
部位骨折 ⇔ 其弱子区域 σ ≥ 阈值；`F_bone(h)` 由 OpenSim 载荷链 + 载荷分配（胫/腓并联；中轴骨按上方质量）给出。

| 部位 | 弱子区域 σ_c | σ@5m (MPa) | 首折 (m) |
|---|---|---|---|
| 腓骨 | 70 | 57.6 | **7** |
| 足部 | 150 | 117.4 | **8** |
| 胫骨 | 70 | 53.5 | **8** |
| 股骨 | 80 | 37.6 | **19** |
| 胸椎 | 150 | 40.1 | 47 |
| 腰椎/颈椎/骨盆/颅骨 | 150/150/180/160 | — | >50 |

**关键假设**：
- 关节力**沿骨轴**（非"竖向作用于斜骨"——后者的假弯曲把腓骨拉到 1 m）；
- A_section = CORT 体积/骨长（4 长骨 measured；中轴骨 estimated）；
- 线性弹性（σ(h) ∝ load(h)）。

**基线用途**：任何新场景只需重算 **F_bone(h, 场景)**，代入上式即得该场景的**首折高度/部位排序**，与论文/基线对比。

## 3. 已知局限（未对齐，暂列为边界）

1. **颅骨/骨盆渐进损伤**：1D 用**整体截面**算名义压缩，抓不到**枕骨大孔局部应力集中**与**薄壳弯曲**；需**局部模型**（颅底薄壳、骨盆环）才可能复现。
2. **骨干过应力**：单骨把**整条关节反力**压在骨上 → 骨干 1–50m 内仍折；全身/肌肉/弯曲卸载的衰减未建模。
3. **5 群集退化**：矩阵低高度即饱和（下肢 1–8m 全折）→ Jaccard 聚类只得 3 类。
4. **事件内时序（双路径先后）**：9×50 高度矩阵不含时序，只能定性。

## 4. 场景探索计划

**方法**：借用对齐基线 —— 对每个场景重算 `F_bone(h, 场景)`（OpenSim 载荷链 + `plantar_bc`/姿态/体型参数），代入基线得 首折高度/部位序，与论文/刚性地面基线对比。

| 场景 | 变量 | 复用组件 | 产出 |
|---|---|---|---|
| **S1 垫子/地面刚度**（首要） | 跖面 Winkler k（fixed→soft） | `plantar_bc.py`（fixed/roller/spring）+ 载荷链 | k → 首折高度 曲线（抱石垫的核心问题） |
| S2 落地姿态 | 非垂直着地角 | `非垂直落地扩展方案.md` + 关节反力 | 姿态 → 首折部位转移 |
| S3 体型 | 身高/体重（AM50→个体） | `scale_model_mass` | 体型 → 阈值高度 |
| S4 高度量程 | 抱石 ≤4.5m 细扫 | 载荷链 | 量程内风险序 |

**首个场景建议 S1（垫子刚度）**：它是抱石场景的**唯一自变量核心**，且我们**已有** `plantar_bc` 与"法向刚度主导"的机制结论；把"k → 首折高度"做成曲线，即直接回答"垫子多软才安全"。
