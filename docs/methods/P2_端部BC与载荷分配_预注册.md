## §4 **per-part penalty 公式**（#5 —— 规则，不是逐部位调参）

**锚点**：P5.0 **实测 PASS** 配方 = `penalty=50`，对应 `femur_r` 载荷
22 923.2 – 57 941.3 N，`gap=−0.3`、`fric=0`。

**冻结公式**：

```
penalty_part = 50 × ( F_ref(part) / 57 941.3 )
```

其中 `F_ref(part)` = 该部位在本次重解中的**最大载荷**（h=50 处）。

**依据**：接触罚刚度 ∝ penalty，接触承载 ⟺ 罚足够刚使穿透 < `gap`。
P5.0 实测反推罚刚度 ≈ **19 317 N/mm per unit penalty**
（`contact_f_bone_n=[−677.7, 1586.8, −57941.5]`，h50，penalty=50 ⇒ 穿透 ≈ 0.06 mm；
与 penalty=0.1 推得的 ≈29–30 mm 穿透自洽 ⇒ 互为正对照）。
⇒ 罚 ∝ 载荷 是唯一有物理依据的自变量；**公式一次给出全部部位，无自由度可调。**

**结果值**（按 §3 修复后载荷）：

| bone | F_ref N | penalty |
|---|---:|---:|
| `L3` | 22 087.6 | 19.1 |
| `T6` | 13 482.9 | **11.6** |
| `C5` | 4 065.2 | **3.5** |
| `parietal_r` | 3 184.4 | **2.8** |
| `calcaneus_r` | 25 354.4 | 21.9 |
| `tibia_r` | 19 605.5 | 16.9 |
| `femur_r` | 15 227.7 | 13.1 |

⚠️ **低 penalty 风险**：C5/parietal_r 的 penalty < 5，可能重现
`p5_anchor`（penalty=0.1）式的接触形同虚设。⇒ **判据 §5.1 的接触承载项即为此设的闸门**；
若某部位接触承载 < 80%，**如实报该部位不可交付**，**不得回调 penalty**（红线）。

**红线**：**不得逐部位手调 penalty 凑收敛**。公式给出即冻结；
不收敛 = 该部位的**结果**，不是待调参数。

## §5 判据（跑前写死，跑后不回溯）

### §5.1 逐部位能力门（决定「该部位能否交付」）
1. **收敛**：`rc=0` 且 FEBio 报 `NORMAL`（须删旧 `.log` 防误报）。
2. **接触承载**：`|R_z_contact| / load_n` ∈ **[0.80, 1.20]**（承自 P5.0 主判据 ±20%）。
3. **弯曲路径**：`r2_linear ≥ 0.20` **或** `szz_max > 0`（承自 P5.0 次判据）。

### §5.2 目标判定门（决定 A1 / A2）
- **A2 逐部位**：承 §5.1 通过者，按 `median`（官方 Route 乙）口径送
  `paper_alignment.logistic_fit`；阶跃部位 `complete_separation` = 命中、
  `all_zero`/`all_one` = 常值 = ✗；渐进部位 `ok` = 命中。
- **A1 边界 #2**：相变中点须向 [Y25] **16 m** 收敛（口径：相变中点，已声明）。
- **哨兵**（触发即如实报，不调参）：
  - 接触承载 ∉ [0.80, 1.20] → 该部位不可交付
  - `|u|max` > 3× 同载荷 P4-a′ 基准 → 位移剧增
  - 横向滑移 > 5 mm → 板漂移
  - 锚点吸轴 > 20% → 锚点在偷承载

### §5.3 **回落必须单列报告**（§3 连带项的直接后果）
缺陷 B 的方向是**降低**颈椎/颅骨/胫骨的 σ ⇒ **预期会使部分命中部位失命中**。
⇒ 报告**必须**同时给出「修 A 前 / 仅修 B / 修 A+B」三列，
**禁止只报最有利的一列**。
