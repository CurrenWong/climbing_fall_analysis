# A4 时间域双路径度量 · 预注册设计

> **性质**：**预注册** —— 决策冻结即锁定；跑数后**禁止回解**凑靶。
> **上游**：`docs/methods/A4_重定级.md` §4（A4 原判据=【架构不可判定】）+
> `docs/methods/G4_损伤演化设计.md` §7（本度量的**原始出处**）+ `docs/methods/OpenSim_FE复现方案.md:214`。
> **本件不修改** A4 原判据，也**不回溯改判**；它是 A4 的**替代操作性定义**，独立判定。

---

## 0. 一句话目标

把 [Y25] 的「**双路径**」（自下而上传导 vs 自上而下惯性）从**空间** σ(h) 矩阵
（已被证明**无法表示**，见 `A4_重定级.md` §2）改为**时间域**度量：
**测「足路径」与「头惯量路径」到达脊柱的到达时差，并检验它是否随坠落高度变号。**

---

## 1. 为什么必须换到时间域（前置事实）

| 事实 | 来源 |
|---|---|
| 空间 50×9 σ(h) 的 PCA 在**任何**后处理本构下 PC2 ≤ **11.42%** < 全部候选 null | `A4_ARCHITECTURE_PROBE_REPORT.md` §4 |
| 真因：所有部件 σ_i(h) = c_i·load(h) ⇒ 由**单一标量**参数化 ⇒ 一维轨迹 | 同上 §2/§5 |
| 本项目自己已写明「**双路径是耦合属性，不是单纯 FE 能给的**」 | `OpenSim_FE复现方案.md:214` |
| 「空间 50×9 矩阵**无法表示**」 | `G4_损伤演化设计.md` §7 |

⇒ **双路径是传导动力学的时间属性**，必须在**时间域**测。

## 2. 观测量定义（冻结）

### 2.1 链路与数据源

沿用**唯一冻结预设**的顺应链（与 `g4_load_chain_compliant.py` **同一链、同一预设**，不新增旋钮）：

```
ground_reaction(h, 75.337) → run_dead_drop(grf, passive=PassiveStiffness.nominal_landing())
    → joint_reaction(fall, grf, joint=j) → 取【时域】纵向力 F_j(t)
```

**本度量的唯一改动 = 取 `F_j(t)` 的到达时刻，而非只取 `peak_vertical_n`。**
关节集合 **J = {ankle_r（足路径）→ knee_r → hip_r → 脊柱}**（脊柱关节名以实现时确认并冻结）。

### 2.2 到达时刻 `t_arr(j, h)`（冻结定义）

对每高度 h、每关节 j：

```
t_arr(j,h) = min{ t : |F_j(t)| ≥ α · max_t |F_j(t)| }        α = 0.05（冻结）
```

**理由**：`peak` 时刻受波形形状与截断影响；**首达时刻**才是「信号到达」的物理量。
α = 0.05 冻结（与峰值比 20:1，在数值噪声之上、又不至于只抓第一个采样点）。
> **敏感性（报告，不判）**：另报 α = 0.02 / 0.10 两档，作为口径稳健性。

### 2.3 双路径指标（冻结）

```
Δt(h) = t_arr(脊柱, h) − t_arr(ankle_r, h)
```

**符号含义**（**不可被约定翻转的证据**：`t` 是积分时间轴的正向，`F_j` 直接取自 OpenSim 时域输出）：

- **Δt > 0** ⇒ 脊柱的载荷**晚于**踝 ⇒ **自下而上**路径主导（冲击从足传上来）
- **Δt < 0** ⇒ 脊柱的载荷**早于**踝 ⇒ **自上而下**路径主导（头/躯干惯性先加载脊柱）

---

## 3. 判据（冻结）

### 3.1 主判据 · 「双路径存在」

> **在 h ∈ [1, 50] m 的扫描中，`Δt(h)` 必须变号**
> （即同时存在 Δt > 0 与 Δt < 0 的高度区间）。

**理由**：单一自下而上路径 ⇒ 冲击只能从足往上走 ⇒ **Δt 恒正**。
只有存在**第二条（头惯量）路径**时，才可能出现「脊柱先于踝」的高度区间。
**变号 = 两条路径竞争被直接观测到**——这正是 [Y25] 双路径的时间域签名。

**无自由参数**（α 已在 §2.2 冻结）。

### 3.2 正对照（**必须先跑、必须通过**）

> **纯 1D 链对照**（`pad.py` / `chain2d.py`，**无头惯量路径**）⇒ **Δt(h) 必须恒正**（或该系统下不可测）。

**理由**：若正对照也「变号」，说明变号来自**数值/定义伪影**而非物理。
**没有通过正对照的判据不算证据。**

> ⚠️ **已知风险**：1D 链可能**没有脊柱关节**（只有躯干质点）⇒ 该对照须先在实现时确认可测性；
> **若不可测，则必须改用「2 段 vs 6 段」或「有/无头颈惯性分支」的对照**，并在报告中登记替代方案的**理由与口径**（不得默默省略对照）。

### 3.3 报告项（**只报，不判**）

| 项 | 说明 |
|---|---|
| Δt(h) 全曲线 | 逐高度值 |
| α 敏感性（0.02 / 0.10） | 主判据是否随 α 翻转 |
| 关节链时序单调性 | t_arr 是否按 踝→膝→髋→脊柱 递增（自下而上路径的预期） |
| 与 [Y25] 分组的对照 | 阶跃部位 {足/胫/股/颈椎} vs 渐进部位 {腓骨/骨盆/颅骨} 能否由 Δt 的符号区间解释 |

### 3.4 失败处置（**预注册**）

| 情形 | 处置 |
|---|---|
| `Δt(h)` 不变号 | **如实报 FAIL**；结论 = 「本模型（含其顺应链）**未复现**双路径的时序签名」——**不得**通过扫 α / 换关节 / 加高度去凑 |
| 正对照未通过 | **停止**，先修对照；判据**不成立**，本度量记【不可判定】 |
| 变号但对 α 敏感 | 记【**条件 PASS**】，明确条件 |

## 4. 预注册决策点（冻结）

| # | 决策 | 冻结值 | 依据 |
|---|---|---|---|
| **T1** | 度量域 | **时间域**（不再用空间 σ(h) PCA） | `A4_重定级.md` §2 已证空间域架构不可能 |
| **T2** | 到达时刻定义 | `t_arr = 首个 \|F\| ≥ 0.05·max\|F\|` 的时刻 | 首达比峰值稳健；α 与峰值比 20:1 |
| **T3** | 双路径指标 | `Δt = t_arr(脊柱) − t_arr(ankle_r)` | 直接对应 [Y25] 两条路径 |
| **T4** | 主判据 | **Δt(h) 变号** | 单路径必恒正；变号 = 两路径竞争 |
| **T5** | 正对照 | 无头惯量路径的链 ⇒ Δt 恒正 | **判据必须先过对照**（本项目纪律） |
| **T6** | 链路与预设 | **与 `g4_load_chain_compliant.py` 逐字相同**（`PassiveStiffness.nominal_landing()`） | 不新增旋钮；**不扫不调** |
| **T7** | 关节集合 | `{ankle_r, knee_r, hip_r, 脊柱}` | 覆盖足路径→脊柱；脊柱关节名实现时冻结 |

> **冻结即锁**：跑后禁止调 α、换关节、改预设、增删高度以凑「变号」。
