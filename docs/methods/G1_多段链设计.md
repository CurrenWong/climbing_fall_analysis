## 0. 一句话目标

把 1D 双质点冲击链升级为 **6 段平面多刚体链**（= P3「二切」），使刚性侧 20 m **局部（胫骨）组织峰时**进入 [T22] 量级（V8b ≤ 5 ms），并让 P-5 头颈/躯干时序的 ~3× 残余界收窄；**同时**补上平面转动自由度，覆盖 [B25] 纵向旋转 36% + 前后向 9%。

### 2.2 观测量现状（关键事实）

- **`t_torso` 不是任何结果对象上的字段**。它 = `argmax(|accel_torso_g|)` 落在 `meta["impact_window_s"]`（`pad.py:668-692,752`）内，由**脚本侧**重复实现的 `peak_rel_ms` 计算：`scripts/rigid_vtarget_probe.py:132-145`、`scripts/p5_cond/pad_stiffness_h20.py:52`、`scripts/p5_cond/pad_stiffness_sweep.py:81`。

### 2.4 前次多段链尝试（`src/climbing/bodies.py`）与失败根因

- `bodies.py` 已实现 **6 节点竖直链**（5 段：足/踝→小腿/膝→大腿/髋→躯干/腰椎→颈/头），`DEFAULT_LINKS`（`:190-201`），含 Hill 型力-速关系与关节行程上限，`Radau` 积分（`:486-489`）。
- **结构正确，参数未标定，数值不可用**：判据 A 失败（屈膝缓冲总行程仅 **6.8 cm**，要求 20–50 cm）；判据 B 失败（躯干峰值加速度 68.6 g，**反高于**双质点的 37.2 g）。

## 4. 架构设计

### 4.1 拓扑与自由度
- **6 段 / 5 关节**（冻结）：足 → 小腿/胫骨 → 大腿 → 骨盆-躯干 → 胸廓 → 头颈；关节 = 踝、膝、髋、腰、颈。
- **软关节（compliant）串链**：每关节 2 个自由度（轴向压缩 `u_j`、平面转角 `φ_j`），加基座侧向 `x_f` ⇒ **DOF = 1 + 5×2 = 11**；全身倾斜由 `φ_踝` 表达。
- 采用**软关节**（而非刚性约束）⇒ 保持 **ODE**（scipy 可积、可测），避开 DAE。
- 复用 `bodies.py` 的**结构模式**（交错状态布局、`Link.force_n` 的轴向弹簧+行程上限+双向、Radau 积分）；**重设计**其接触模型、全部参数**值**（未标定，须按解剖重新推导，**不复用旧值**）、并**去掉**致弹跳的过硬抗拉止挡、加平面转动。

### 4.2 接触模型（渐进质量接入 —— 解决 bodies.py 弹跳）
bodies.py 失败根因：足节点（1.2 kg）撞硬接触后回弹、被过硬抗拉止挡拉回。改法：
- **逐节点、面积增长的柔顺接触**：(a) 逐段穿透激活 + (b) 分布式面积 `A(κ)`（复用 `CrashPad` 平台/致密律 + `Posture.contact_schedule`）+ (c) 软关节；(d) 质量再分配为辅助而非主机制。
- **软关节**使塌陷与接触**同时间尺度** ⇒ 力**单调上升**、质量连续接入（足→小腿→大腿→臀），无分离、无回弹。
- 接触/摩擦律取 **C¹**（复用 `sign_reg`），无粘滞不连续 ⇒ 确定性、**种子无关**。
- **不调参**：接触刚度**来源**预先冻结（刚地面 = 既有 `hard_surface(k_n=1e7)` + 人体软组织柔顺层；垫 = `CrashPad` + `A(κ)`）；关节刚度按解剖（远端骨主导、近端肌主导）取自文档。跑后**如实** PASS/FAIL。

### 4.3 峰时下限物理（关键结论）
- 局部峰时 **`t_local ≈ d_crush / v`**（恒定局部压溃距离）——由 [T22] Table 3（5/10/20 m → 11.9/6.5/4.6 ms，v=9.9/14.0/19.8 m/s）反推 **`t·v ≈ 0.09–0.12 m`** 近常数。
- **局部（胫骨）观测量可达**：`d_crush≈0.09 m` @19.8 m/s ⇒ ≈ **4.5 ms**，**无需应力波**。
- **躯干/整体观测量不可达**：被塌陷半周期（`~π√(m_up/k_eff) ≥ 10 ms`）钉死，**加多少段都降不下来**。⇒ V8b 必须测**局部**量（这是本设计最重要的转向）。
- [T22] 4.6 ms 是**接触压溃主导**（非波动主导）：1D 波动杆会亚毫秒（L≈0.38 m、c≈3500 m/s）⇒ **过冲**。波动杆仅作**预注册备选**，预计过快（见 §7 决策 6）。

### 4.4 积分器
- **不碰 RK45 默认路径**（字节锁）。
- 新链用 scipy **Radau**（`bodies.py` 已验证，隐式、抗刚）+ `_first_significant_peak`（防自适应步噪声翻转判定）。若复现性抖动，升级为**定步半隐式 / Newmark-β**（网格确定 `t_peak`），仍在新模块内。

## 5. 局部组织峰观测量

- 逐段：轴向关节力 `F_j(t)` → `σ_j = F_j/A_j` → `ε_j = σ_j/E_j`（对齐既有 `ε=F/(k·L)`、`σ=M·c/I+F/A` 口径）。
- **V8b 主观测量 = `ε_胫骨` 在 `meta["impact_window_s"]` 内的首个显著局部极大**（复用 `head_branch._first_significant_peak`，已解决无阻尼多峰的 argmax 非确定性问题）。
- 早段胫骨力 ≈ GRF ⇒ 可辩护为"胫骨载荷峰"，与 [T22] Table 3 胫骨列同源。
- 逐段峰**全报**（分布），但**主判据冻结为胫骨段**。
