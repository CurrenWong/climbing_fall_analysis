## 1. 说明

## 6. 已知实现层勘误

### 6.1 泡沫本构 docstring 笔误

**位置**：`src/climbing/pad.py` `CrashPad` 类 docstring。

**笔误**：docstring 把密实化项写作 $s_d(\xi/\xi_d)^n$（分母为 $\xi_d$）。

**代码实际**：`src/climbing/pad.py:117` 使用 `xi / self.xi_dense_max`，即分母是 **`xi_dense_max` = 0.85**（论文符号 $\xi_{\max}$），**不是** `xi_plateau`（$\xi_{pl}=0.15$）。

**论文采用**：分母 $\xi_{\max}=0.85$，以代码为准。

### 6.2 V6 grid 高度超出包线

V6 固定 (h, β) 3×3 网格位于 `tests/test_pad2d.py::_v6_grid()`，高度 h ∈ {5, 10, 20} m 已**超出**论文 §2.1 H6 包线（2~5 m）；V6 仅用于锁定 [T22] Table 4 的**定性结构**，其绝对骨折率不可作为论文的定量结论。

### 6.3 ankef_supination 模块上界式声明

踝损伤上界式 1D 性质已在该模块 docstring 中**显式声明**（见论文 H2）。本模块中所有绝对量（$\sigma$/MPa、骨利用率）仅供"是否越阈"的相对判定，**不可与整体结构全骨 FE 数值直接对比**。
