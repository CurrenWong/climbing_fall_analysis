## 3. 论文对齐结论（[Y25]）

**判据**：论文表 1 **子区域强度**（两端 70 / 骨颈 80 / 跟骨 150 / 骨干 200+ / 骨盆 180 / 脊柱 150 / 颅骨 160 MPa）。

| 结论 | 对齐？ |
|---|---|
| **7 m 临界高度**；下肢先折；**阶跃机制** | ✅ **核心对齐** |
| 颅骨 / 骨盆**渐进**；**骨干不折**；**5 群集 / 3 阶段** | ✗ 单骨结构性局限 |

**对齐基线**（冻结）：**纯轴向 + 两端强度 → 腓 7 m / 足 8 m / 胫 8 m / 股 19 m**。
**关键修正**：此前误用**骨干**强度（200/160/220）——论文骨折点是**两端（70）/骨颈（80）**；改用后 7 m 阈值自然复现。
**已修 3 个既有 bug**：① 状态时间；② 降载折算丢失；③ 退化网格诊断。

## 4. 临床 / 流行病学锚定

### [Heck2024 / Müller2022]（急诊 430 人 / 447 伤）
- 机制 **跌倒 67.8%**；区域 **下肢 61.1%** > 上肢；**踝 36.7%**、膝 16.8%、肘 12.3%、脊柱 7.2%。
- 类型 **扭伤 53% / 骨折 22.8% / 脱位 11.9%**；**踝：扭伤 71.3% / 骨折 27.4%**。
- **反直觉**：**<2 m 跌倒 → 下肢伤更多（79.1% vs 58.3%）**。
### [Beurienne2025]（问卷 245 人 / 301 伤）
- 下肢 67%；**踝扭伤 #1（28%）**；85% 非自主；62% 直立起始；62% 旋转；74% 足先落地。
- **7 运动学**（前 3 占 42%）；结论**明确呼吁 FE 数值重建跌倒场景 + 评估垫子设计**。
### [Tochigi2006]（尸体踝韧带应变，Foot & Ankle Int.）
- 韧带集合（ATFL/CFL/PTFL + 三角）；正常步态 ATFL 应变 ≤6.2%；**"taut" 阈值 1%**；
- **核心**：peri-ankle 韧带是**次级约束**，**只在极端位置才绷紧** → 支持"扭伤 = 极端位置事件"。
### 失效参数（librarian 文献）
- ATFL：极限载荷 **≈200 N**、失效应变 **≈14%**、割线刚度 14 N/mm；
- **关节级**：ATFL 首次失败 **内翻力矩 21–34 N·m（无预载）/ 77 N·m（2 kN 预载）**、内翻角 **33–40°**。

**共同机制（两篇临床论文）**：**脚沉入垫 → 踝旋后/内翻 → 达垫子模量后载荷上升 → 韧带 / 骨失效**。

## 6. 场景与判据 R1–R6

| # | 主题 | 关键结论 |
|---|---|---|
| **R1** | 踝旋后 / 内翻载荷 | 纯轴向腓骨 **7 m** 安全 → 加旋后（15–30°）**真实高度 2–4.5 m 即越阈** |
| **R2** | 真实场景矩阵（7 运动学） | 下肢旗标 **100%**（vs 临床 61–67%，过度）；踝桶 **2/4 场景、腓骨最先**；R5 用姿态分布与临床同向 |
| **R4** | 垫子刚度 × 旋后权衡 | **无内部最优 → k\*→刚性极限**；**软垫轴向收益(−23.6%) ≪ 旋后侧弯** → **两轴张力** |
| **R6** | 踝韧带扭伤判据 | **β≥10° 两口径下 ATFL 均扭伤**；**补上临床 #1 踝扭伤 71%**（骨口径仅骨折 27%） |

| R5 | "低坠→更多下肢" | 见 R2 §6（姿态分布效应，非单次物理） |

## 7. 综合结论（关键洞察）

1. **三条线索收敛到「腓骨 / 外踝」**：[Y25] 腓骨最敏感（OR 1.682）；场景矩阵里**腓骨最先越阈**；临床**踝伤 #1**；R1 的**旋后机制**把腓骨远端压到真实高度内。→ **腓骨/外踝 = 抱石落地的关键部位**。
2. **骨 + 韧带两条主线补全**：R1（骨：踝骨折 27%）+ R6（韧带：踝扭伤 71%）= 临床踝伤全貌。
3. **垫子是两轴张力**：S1/轴向说"软垫更安全"，加上旋后（R4）则**反转**——**软垫护"压"、伤"扭"**。
4. **单脚落地最危险**：载荷 ×2 → 首折减半（抱石最常见姿势）。
5. **屈腿吸能是"主动"机制**：被动刚度**拦得住飞、换不来弯** → 需要主动肌肉，当前不建模（诚实边界）。
6. **3D 载荷改变失效"位置"**（跖面 → 关节面棱边），不只是大小。

**危险度排序（相对）**：**单脚 ≫ 3D 斜向/力矩 > 直立双足 > 软垫**。

## 8. 诚实边界

- **单骨模型结构性局限**：绝对高度不可移植（D5）；颅/骨盆渐进、骨干、5 群集**无法复现**；模型**无上肢/软组织**通路。
- **数值口径**：多种判据为**上界式 1D**（旋后 β_c<2°、韧带 ε>10³%、R4 侧向 risk O(10)）→ **只看相对与是否越阈，绝对值不可引用**。
- **参数来源**：失效阈值来自尸体文献（非本仓库实测）；`r_lig` / β(k) / 被动刚度 / 泡沫本构均为 **assumed / modeled**。
- **预载外推不确定**：抱石冲击 ~21 kN 远超文献 0–2 kN。
- **临床数据**：问卷/急诊有选择偏倚与回忆偏倚；只作定性对照。
