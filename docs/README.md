# docs/

抱石落地骨与韧带损伤建模项目的设计文档、阶段报告、论文稿与文献笔记。

## 子目录

| 目录 | 作用 |
| --- | --- |
| `paper/` | 成品论文初稿、评审与汇总报告（含脚踝损伤建模总结）。`论文v2_数学建模版.md` 与 `论文v2_出处索引.md` 当前在 `docs/` 根目录，由后台任务写入后做最终迁移。 |
| `methods/` | 仿真方案、方法学说明与建模交接（OpenSim→FEBio 复现、非垂直扩展、脚踝 FE 与韧带判据等）。 |
| `reports/` | 阶段进度、最终结论、对齐分析与文献解析报告。`S5_QUOTABLE.md` 是 S5 取数的唯一权威入口，正文结论必须引用它。 |
| `s5-contact/` | S5 脚-垫接触收敛系列的 17 篇文档（契约、UDG、网格验证、波 3 至 5 矩阵等），成套阅读。 |
| `notes/` | TODO 清单与 `阶段总结.md`（由并行任务维护）。 |

## 入口文档（推荐阅读顺序）

1. [`reports/最终结论_2026-10-07.md`](reports/最终结论_2026-10-07.md)：当前研究的最终结论与可信边界。
2. [`论文v2_数学建模版.md`](论文v2_数学建模版.md)：论文 v2 稿（数学建模版，仍在根目录待最终迁移）。
3. [`reports/P2_踝结论_2026-10-07.md`](reports/P2_踝结论_2026-10-07.md)：脚踝子任务 P2 的阶段结论。
4. [`methods/方案更新_v2.md`](methods/方案更新_v2.md)：方案 v2（结构性诊断与重构路线）。
5. [`reports/总体进度.md`](reports/总体进度.md)：总体进度总览。

## 第三方模型与文献

`model/`（AM50、THUMS、足踝 FE 模型等）与 `paper/`（吴恺论文、Anderson 双论文、FEBio 用户手册等）目录下的第三方资料**不随本仓库分发**，因各自许可约束。复现所需的获取方式、版本与放置约定请见仓库根目录的 `README.md`。
