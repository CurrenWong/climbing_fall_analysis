## 0. 一句话

在 FEBio 里让**足（跟骨 / 足底）与垫发生真实接触 + 摩擦**，替掉当前**规定式跖面 BC**（`fixed` / `roller` / `spring`）。这是"接触物理"层面的升级，也是唯一剩下的、方案标 **"大 · 仅必要时做"** 的一期。

---

## 1. 现状（我们到哪了）

跖面 BC 目前只有 **4 种规定式**（`src/climbing/coupling/plantar_bc.py::BC_KINDS`）：

| kind | 含义 |
|---|---|
| `fixed` | 三向零位移（`BCZeroDisplacement x=y=z=1`，**默认**、逐位回归） |
| `roller` | 只约束法向（`BCNormalDisplacement`），切向自由 + 2 个销 |
| `roller_free` | 诊断变体：全局 Y 固定 + 极软切向弹簧 |
| `spring` | Winkler 弹性地基：每跖面节点向 3 正交锚点连线性弹簧（`k` N/mm） |

- **全是规定式**（prescribed），**无**：垫体、接触对、摩擦、接触搜索。
- **A7**（跖面三向全固定 → 固定端边缘奇异）是"规定式"的必然产物；S4 的弹性支撑已**部分缓解**。
- 载荷端（L3/L4）已能送 **3D wrench**（力 + 力矩，S4），FE 加载已支持 `use_rigid` / `PressureLoad` / `RigidMomentLoad`。

---

## 2. 做完后能买到什么（收益）

1. **最完整的接触表达**：真实接触面积、接触压力分布、CoP、摩擦切向力（`F_t ≤ μ·F_n`）。
2. **顺带修 A7**：接触天然给出**分布反力**，取代固定端 → 去掉边缘奇异（这是当前 `~2–3 m` 与 `[Y25] 7–9 m` 差距的 **BC 根因**）。
3. 与 S1/S2/S4 的**矢量载荷**自然衔接（接触同时给法向 + 切向）。

---

## 3. 两个版本

### 3.1 最小版（**推荐先做**）
- 垫 = **刚性面**（`RigidWall` / 刚性 body）+ **Coulomb 摩擦**（μ），只接**足底 surface**。
- **不建泡沫实体** → **不依赖泡沫本构标定**。
- **收益**：修 A7（分布反力）+ 引入**摩擦切向力**。
- **成本**：中。

### 3.2 完整版（后续）
- 垫 = 可变形**超弹泡沫实体**（Neo-Hookean / Ogden）+ 接触 + 摩擦。
- **收益**：真实接触面积 / 压力分布 / CoP / 垫子变形-吸能。
- **成本**：大（需泡沫本构 + 标定）。

## 5. 验证策略（方案 §7）

| 项 | 做法 |
|---|---|
| **轴向回归（硬门槛）** | 默认（`plantar_bc="fixed"`）逐位复现；接触仅 opt-in |
| **极限自检** | `μ=0` + 垫极刚 → 应趋近 `spring k→∞` / rigid-support 结果 |
| **接触守恒** | 接触力 = 施加载荷；穿透量有界 |
| **摩擦锥** | 任何时刻 `|F_t| ≤ μ·F_n`，不越界 |
| **A7 检验** | 对比 `fixed` vs `contact` 的 gauge 峰值与边缘奇异是否消失 |
| **敏感性** | μ、垫刚度、接触 penalty 扫描 → 输出单调/有界 |

## 7. 风险

1. **`pad.py` 1D → 3D 是接触物理重写**（方案 §6 风险①）：接触面积 / 法向 / 摩擦都藏在 1D 里，不是加参数。
2. **FEBio contact 收敛**（接触 + 大变形 + 超弹）是主要坑。
3. **参数无标定**（泡沫、μ）→ 验证难（方案 §6 风险③），非垂直场景的验证本就比轴向难。
