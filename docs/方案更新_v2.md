# 一、一句话诊断

当前模型是一个**一维、竖向、纯压缩**的冲击模型。**四篇文献从四个不同角度**
指向同一个结论：

| | 证据 | 结论 |
|---|---|---|
| **[B25]** 法国问卷 n=245 | 踝扭伤 28%，踝 40% | 踝是第一大部位 |
| **[H24]** 德国急诊科 n=430 | 踝扭伤 26.1%，踝 36.7%，踝伤中 71.3% 为扭伤 | **独立人群，同样结论** |
| **[T22]** THUMS 踝关节专题 | 5 种踝姿 × 3 角度 × 3 高度 | 大角度→滑动→**韧带伤**；小角度→卡住→**骨折** |
| **[Y25]** THUMS 全身 | 足部最早骨折（7–9 m） | 压缩路径确实是第一条失效的 |

| 问题 | 答案 |
|---|---|
| **最主要的伤** | 踝关节**扭伤**（ED 26.1% / 问卷 28%） |
| **机制** | 踝**旋后/旋前**（转动 + 韧带），且由**护垫下沉量**驱动 |
| **我们的模型能算吗** | ❌ **完全不能** |

> **当前模型结构上无法产生"扭伤"。**
> 而扭伤是抱石摔伤里最高发的一类（36% 为扭伤，其中踝扭伤单项 26–28%）。
> 这不是参数不准的问题，是**自由度不够**的问题——没有转动的模型算不出转动损伤。
>
> 更要紧的是：**两个独立人群、两种方法学得出同一结论**，
> 排除了"某个研究的偏倚"这个解释。这是我们模型必须能解释的首要目标。

## 2.1c [T22] 踝关节损伤机制 —— P2 的核心依据

**[T22] 是目前唯一把"踝姿 + 角度 + 高度"系统扫描的文献**，仿真矩阵：

| 维度 | 取值 |
|---|---|
| 坠落高度 | 5 / 10 / 20 m |
| 踝关节姿势 | 自然、**内翻(inversion)**、**外翻(eversion)**、跖屈(plantar-flexion)、背屈(dorsi-flexion) |
| 姿势角度 | 10° / 20° / 30° |
| 实现方式 | **倾斜地面**来造出不同足踝姿势（很巧的做法） |
| 质量/身高 | 77 kg / 175 cm（与 [Y25] 同源 THUMS） |

### ★ 核心机制：滑动 vs 卡住，决定"骨折"还是"韧带伤"

[T22] 引用 Untaroiu 的结论，并在自己的仿真里复现：

> **重轴向载荷 + 小角度 → 骨折**（主要在踝关节卡住、不发生滑动时）
> **轻载荷 + 大角度 → 韧带断裂**（大角度导致足在垫面上**滑动**，力被卸掉）

最有说服力的证据是 [T22] Table 4（跖屈姿势下各高度的骨折部位）：

| 高度 | 10° | 20° | 30° |
|---|---|---|---|
| **5 m** | 胫腓骨中下段骨折 | 腓骨/胫骨下 1/3 骨折 | **足持续滑动，无骨折** |
| 10 m | 外踝 + 胫骨远端压缩骨折 | + 内踝撕脱 | 外踝 + 内踝撕脱 |
| 20 m | 外踝 + 胫骨远端压缩骨折 | 胫骨远端压缩骨折 + 内踝撕脱 | 同左 |

> **5 m / 30° 时"无骨折"，而 5 m / 10° 反而骨折** ——
> 高度更低、角度更大的那个**更轻**，因为它滑开了。
> 这直接说明：**"落地姿势角度"是一个与"高度"同等重要的自变量。**

### 其他可用的定量结论

**① 载荷越大，峰值来得越早（不是越大）**

[T22] Table 3（自然姿势）：

| 高度 | 胫骨远端峰值应变 | 峰值时刻 | 外侧韧带应变 | 峰值时刻 |
|---|---|---|---|---|
| 5 m | 1.69e-2 | 11.9 ms | 0.858 | 4.1 ms |
| 10 m | 1.75e-2 | 6.5 ms | 0.487 | 2.8 ms |
| 20 m | 1.69e-2 | 4.6 ms | **1.147** | **1.8 ms** |

原文：*"As the fall height increases, the stress and strain peaks of ligaments do not
increase accordingly, but **the peaks appear in advance**."*

**② 天然姿势下的损伤链（可用来验证模型机制）**

```
距骨向外、向后、向上移动
   ↓
胫骨远端 + 外踝 压缩 → 骨折
   ↓ 同时
距骨外移 → 牵拉前内侧韧带组（前胫距、胫舟韧带）
          → 推胫骨向内 → 胫腓韧带应力上升
   ↓ 同时
胫腓骨相对下移 → 后胫腓韧带应力集中
```

**③ 内翻比外翻"轻"**：内翻姿势下胫骨远端与距骨的等效塑性应变更**小**
——即内翻造成的损伤可能比外翻轻。这与直觉相反，值得在模型里核实。

**④ 背屈的独特机制**：胫骨远端**前外侧**关节面先被压缩骨折，
随后经胫腓韧带牵拉 + 跟骨挤压造成外踝骨折。

## 2.3 [Y25] 三条可验证的定量结论

**① 双路径传导**（0.0125 s 为分界）

- 路径 A（自下而上）：足 → 胫骨/腓骨 → 股骨 → 骨盆
- 路径 B（自上而下）：颅骨 + 颈椎因**惯性**继续下压 → 胸椎 → 腰椎
- **两路径在脊柱汇集**，导致脊柱在冲击**后期**才出现应力集中

**② 阶跃响应 vs 渐进响应**

| 类型 | 部位 | 含义 |
|---|---|---|
| **阶跃**（Logistic 拟合失败，完全分离） | 足、胫骨两端、股骨颈、脊柱、颈椎 | **全或无**，低于临界高度绝对安全 |
| **渐进**（Logistic 成功） | 腓骨两端 OR=1.682、颅骨 OR=1.576、骨盆 OR=1.236 | 风险随高度平滑上升 |

> 阶跃部位"Logistic 拟合失败"**不是实验失败，是物理发现**——它们是完全的
> 能量吸收/传导路径，表现为纯阈值效应。我们模型目前输出的是**连续平滑值**，
> 与真实行为不符。

**③ 三阶段高度划分**

| 阶段 | 高度 | 核心损伤 |
|---|---|---|
| 局部耗散 | **< 7 m** | **无骨折**，下肢缓冲足够 |
| 轴向传导 | 7–16 m | 足骨折 → 胫腓骨两端、胸椎偶发 |
| 全身复合 | > 16 m | 股骨颈、颅骨、骨盆，直至全身 |

细分为 5 群集：1–6（无骨折）/ 7–9（足）/ 10–16（足+颈椎+胫腓两端+胸椎）/
17–34（+股骨颈、颅骨/骨盆偶发）/ 35–50（全身）。

> **这是一根现成的标尺。** 我们可以在"直立双足 + 刚性地面"条件下直接对表。

# 四、更新方案

## P0 · 骨骼阈值改成"分部位 + 分类型"（已实现 ✅）

**做什么**：把每根骨单一阈值，换成 [Y25] Table 1 的**解剖部位级**阈值，
并用**解剖学截面面积**把 MPa 换算成力阈值。

**为什么先做这条**：数据现成、改动局部、且直接消掉 L4 和（部分）L6。

**关键设计**：

```python
# 阈值 = 强度(MPa) × 截面面积(mm²) → N     （1 MPa = 1 N/mm²）
# load_fraction = 整条通路的总力中，单根骨承担的比例
BONE_SITES = {
    #                  σ_t   σ_c   A(mm²)  load_frac
    "calcaneus":      (100, 150,   900,    0.50),   # 单侧跟骨 ≈ 半个 f_pad
    "tibia_distal":   (30,   70,   450,    0.45),   # 单侧胫骨 ≈ 小腿载荷 90%
    "fibula_ends":    (30,   70,    80,    0.05),   # 腓骨只分担小腿 ~10%
    "femoral_neck":   (40,   80,   500,    0.50),
    "pelvis":         (100, 180,  1200,    1.00),
    "lumbar_spine":   (70,  150,   900,    1.00),
}
```

**实现中发现的第二个错误（已修）**：一开始我把 `f_flex` **同时**喂给胫骨和腓骨。
但解剖上腓骨在完整小腿中只承担约 **10%** 的轴向载荷（其余走胫骨）。
不修正的后果：1 m 落在软垫上就误判腓骨骨折 **2.25×**。
这个错误是**回归测试抓出来的**，不是目视发现的。

### P0 实测结果

`python scripts/validate_vs_fem.py`（77 kg / 直立双足 / 刚性地面）：

| 部位 | 阈值 (kN) | 本模型临界高度 | [Y25] 预期 | 判定 |
|---|---|---|---|---|
| 胫骨远端 | 31.5 | **13 m** | 10–16 m | ✅ |
| 股骨颈 | 40.0 | **18 m** | 17–34 m | ✅ |
| 胫骨骨干 | 70.0 | >40 m | >50 m 不断 | ✅ |
| 跟骨（足部） | 135.0 | >40 m | 7–9 m | ❌ 偏晚 |
| 腓骨两端 | 5.6 | 33 m | 7–9 m 偶发 | ❌ 偏晚 |
| 骨盆 | 216.0 | >40 m | 17–50 m | ❌ 偏晚 |
| 腰椎椎体 | 135.0 | >40 m | 17–50 m | ❌ 偏晚 |

**命中 3/7。** 关键是**未中的 4 个不是随机分布的**：

- **组 A（载荷路径接近均匀柱体）→ 全部命中**
  胫骨远端、股骨颈、胫骨骨干。材料强度 × 截面 的假设成立。
- **组 B（非均匀 / 整体结构失效）→ 系统性偏晚**
  跟骨（足弓非均布 + 小梁骨）、骨盆（环结构）、腰椎（终板 + 椎间盘）。
  **材料强度描述的是"组织"，不是"结构"。** 跟骨高估 17–34×。
- **待查：腓骨两端**（33 m vs 预期 7–9 m）。腓骨属长骨却未命中，
  两个互斥可能：(a) `load_fraction=0.05` 偏低；(b) 两端 70 MPa 偏高。
  **不调参凑答案，标为待查。**

### P0 的结论

✅ 组 A 可以直接用 [Y25] 的材料强度路线
❌ 组 B 必须换成**整体骨失效数据**——而且这类数据是存在的：
   跟骨就有经验证的**接触力-骨折概率曲线**（Voo HIPC，
   由 Barnes 等 IRCOBI 2019 用全身 PMHS 验证）
⚠️ 不能用单一折减系数统一修正（组 A 不需折减，组 B 需要 6–34×）

**副产品：修掉一个静默 bug。** 验证脚本暴露出 `t_max` 固定 2.0 s，
而 20 m 自由落体需 2.019 s —— **h ≥ 19.6 m 时积分在撞击前就结束，
静默返回 `peak_force = 0 kN`**（越高的坠落反而越"安全"）。
已改为自适应 `max(2.0, √(2h/g) + 1.0)`，并加守卫：全程未接触时抛错。
补了 9 个回归测试锁死，其中 5 个是分部位阈值的物理不变量。

> **这条 bug 是 P0 最大的额外收获** —— 它说明"对标文献"不只是校准数值，
> 更会**逼出那些只有在极端参数下才暴露的静默失效**。

## P1 · 场景库改为数据驱动（高价值、低成本）

**做什么**：按 [B25] 的真实频次重写场景库维度。

```
场景 = 墙型 × 高度 × 起始姿势 × 旋转 × 落地姿势
```

| 维度 | 取值与权重（来自 [B25]） |
|---|---|
| 墙型 | 垂直 .45 / 倾斜 .29 / slab .12 / 屋檐 .07 / 角 .05 |
| 高度 | 顶 .47 / 中 .31 / 底 .20 |
| 起始姿势 | 竖直 .62 / 后仰 .19 / 前倾 .08 / 其他 |
| 旋转 | 纵向 .36 / AP .09 / 后横 .04 / 前横 .03 / 多重 .08 / 无 .39 |
| 落地 | 脚站 .44 / 脚+倾斜 .43 / 头先 .10 / 背 .01 / 臀 .02 |

**产出**：把"哪种姿势最危险"升级成**"按真实频次加权，最常导致损伤的是哪条通路"**。

**验证判据**：
> 用真实权重跑 1000 次蒙特卡洛，输出**损伤部位分布**，
> 与 [B25] 实测对比：下肢应占 **~67%**、踝应为**第一大部位（~40%）**、
> 头/颈应占 **~3%**。误差目标：各部位占比落在实测 95% CI 内。

## P2 · 加入踝关节转动 + 扭转型损伤（最高价值）

**做什么**：这是补 L1/L2/L3 的核心。新增**踝关节自由度**与**韧带损伤判据**。

**参考**：
- **[T22]**（核心）已给出完整的参数化模板：踝姿（内翻/外翻/跖屈/背屈/自然）×
  角度（10/20/30°）× 高度（5/10/20 m），见 §2.1c
- [B25] 引用的 ref 29（护垫下沉 ↔ 踝旋后）

**机制链（护垫 → 踝旋后 → 韧带）**：

```
足部落到软垫
   ↓
垫面局部下沉 δ（foot indentation）
   ↓
足在垫面内非对称下陷 → 足部绕纵轴**旋后/supination 角 φ**
   ↓
踝外侧韧带被拉长：ΔL ≈ r_踝 · φ
   ↓
韧带应变 ε_lig = ΔL / L0(韧带)
   ↓
扭伤分级（ATFL / CFL 的失效应变 ~10-15%）
```

**关键耦合项**——这是全模型新增的核心物理：

```
φ̈ = [ M_垫(δ, 足着地偏心) − M_韧带(φ) − M_肌(φ, φ̇) ] / I_足
```

- `M_垫`：垫面非对称支承力矩，**随 δ 增大而增大** ⇒ 软垫 → 旋后更多 ⇒ 韧带更危险
- 这正好能定量检验 [B25] 的建议："**提高垫刚度可防止过度旋后**，
  但高能量场景下可能无效甚至更糟"

### ★ 必须重现 [T22] 的"滑动 ↔ 卡住"转变

[T22] 最关键的发现是**非单调**：5 m / 30° 无骨折，而 5 m / 10° 骨折。
原因是**大角度让足在垫面上滑动，把能量卸掉了**。

这意味着模型必须包含**足-垫界面的滑动自由度**，否则会：

- ❌ 把所有姿势都算成"卡住" → 全面高估骨折风险
- ❌ 错失"角度增大反而变安全"这个反直觉区间

**⚠️ 这条建议本身有个内在矛盾**（与 [B25] 相同）：
刚度↑ ⇒ 旋后↓（好），但传递力↑（坏）、且更容易卡住不滑动（坏）。
**我们的模型正好是能同时算这三个量的工具**。

**验证判据**（V6，现已有明确靶子）：
> 扫描「高度 × 角度」二维网格，应复现 [T22] Table 4 的定性结构：
> ① 低高度 + 大角度 → 无骨折（滑动）
> ② 低高度 + 小角度 → 骨折
> ③ 高高度 → 无论角度都骨折
> ④ 存在一个"角度—高度"的转变曲线

## P3 · 二维运动学（补转动）

**做什么**：把 1D（z）扩到 2D（x, z, θ），至少覆盖 [B25] 的**纵向旋转 36%**
和**前后向旋转 9%**。

**建模选择**：

| 方案 | 能力 | 成本 |
|---|---|---|
| 平面多刚体（2D，5–7 段） | 纵向 + 前后向旋转、倾斜落地 | 中 |
| 3D 多刚体（MuJoCo / Pinocchio） | 全类型旋转、真实接触 | 高 |
| 保持 1D + 等效旋转罚项 | 只能做灵敏度分析 | 低 |

**建议**：先做 2D 平面（覆盖 45% 的旋转类型），3D 留作 Phase C。
**理由**：脱位集中在上肢（肘），而肘损伤需要完整的"后仰→旋转→上肢撑垫"，
这是 3D 的冠状面 + 矢状面耦合，2D 只能做到部分。

## P4 · 双路径与惯性分支（补 L9）

**做什么**：让头颈成为**惯性分支**，与足部路径在脊柱汇集。

**物理要点**：[Y25] 发现颅骨/颈椎在 **t < 0.0125 s** 就出现应力——这是
**惯性**导致的（足部骤停，头继续下压），不是应力波从足传上来。
在刚体链里，这要求**脊柱-头段有足够刚度**，否则头部响应会被延迟。

**验证判据**：
> 头部应力峰值出现时刻应 **≤ 0.0125 s**（与足部冲击几乎同时），
> 而非延迟到载荷传导之后。

# 六、明确不做 / 风险

**不做**：

- ❌ 不做全身有限元（[Y25] 已做，我们重复没有增量）
- ❌ 不追求绝对损伤概率（需要个体化参数，无数据支撑）
- ❌ 不用 ML 拟合文献数据（样本量和异质性都不够）

**风险**：

| 风险 | 说明 |
|---|---|
| 阈值敏感性 | [Y25] 自己指出："阈值稍有改变，骨折结果就会改变" |
| 双参数未知 | `M_垫` 和踝韧带参数都缺直接实验数据，只能取文献量级 |
| 转动数据缺口 | [B25] 只有旋转**类型**占比，没有角速度量级 |
| 截面面积不确定 | MPa→N 换算依赖截面面积，个体差异可达 ±30% |
| 滑动判据未知 | [T22] 证明"滑动 ↔ 卡住"决定损伤类型，但**摩擦系数**取 0.75（刚性地面）。护垫上的摩擦系数未知，而这正是我们关心的场景 |
| [H24] 的偏倚 | 急诊科人群偏重症，不能直接当作损伤频率 |

**已知的方法论底线**（沿用 v1 经验 `阶段总结.md` §3）：
每种新机制都要有**正交不变量**把关，不能只靠"跑通了看着合理"。

**新增的不变量（P2/P3 必须补）**：

1. 角度 → 0 时，结果应收敛回纯压缩模型
2. 摩擦系数 → ∞（不滑动）与 → 0（自由滑动）两端行为应可解释
3. 内翻 vs 外翻的**相对**关系（[T22] 说内翻更轻）应稳定
4. 峰值时刻必须随高度**单调提前**（[T22] Table 3）

# 七、优先级与依赖

```
P0 分部位阈值 ──┐ (已实现)
P1 场景权重  ──┼──> V1/V2 对表 [Y25]  ← 第一个真实验证锚点
                │
P2 踝转动+滑动 ─┴──> V6/V9 对照 [T22]  ← 最高科学价值，靶子已明确
   （依赖 P3 的转动自由度）
P3 二维运动学 ──────> V5 损伤分布对表 [B25]/[H24]；V8 峰值时刻
P4 惯性分支   ──────> V3 头部时序
```

**建议顺序**：P0 ✅ → P1 → V1/V2 对表 → **P3（先要转动能力）→ P2（踝）** → P4。

**理由**：
- P0/P1 便宜且立刻产生**真实的对标数字**
- **P2 的靶子最明确**（[T22] 给了完整参数矩阵与预期定性结构），
  但它**依赖 P3 的转动自由度**——没有转动就没法定义踝姿角
- 所以调整为先 P3 后 P2（原计划把 P2 排在 P3 之前，现在改为 P3 先行）
- P3 的收益是双向的：既支撑 P2，又独立满足 V5（[B25]/[H24] 的损伤分布对表）
