# 踝韧带扭伤判据方案（R6）

> 目标：给骨骨折管线补上**踝韧带扭伤判据**——临床 **#1 踝伤（占踝伤 71%，[Heck2024]）**，目前骨模型只覆盖踝**骨折 27%**。
> 机制：对接 **R1 的踝旋后/内翻**（`ankle_supination`，给出内翻力矩 `M_inv`）。
> 参考论文：`paper/MinerU_markdown_2006FAIankleligaments_2106701085136199680.md`（Tochigi 等 2006，*Foot & Ankle International*）。

---

## 1. 参考论文 [Tochigi2006] 给了什么 / 缺什么

**给了**（尸体踝 n=11，行走支撑期动态加载 600 N）：
- **韧带集合**：ATFL（前距腓）、CFL（跟腓）、PTFL（后距腓）+ 浅三角韧带（ADL/MDL/PDL）。
- **应变尺度**（动态弧 15° 跖屈→10° 背屈，Table 1）：
  | 韧带 | 应变范围(%) |
  |---|---:|
  | ATFL | 0.2–**6.2** |
  | CFL | 0.2–**2.1** |
  | PTFL | 0.3–**5.8** |
  | ADL | 5.0–**15.2** |
  | MDL | 0.6–**9.0** |
  | PDL | 0.1–**16.4** |
- **"taut" 阈值 = 1.0% 应变**（>1% 视为受力/绷紧）。
- **核心结论**：peri-ankle 韧带是**次级约束**，**只在极端位置（30° 跖/背屈）才绷紧**；支撑期运动主要靠**关节面几何**控制。

**缺**：
- ❌ **无失效阈值**（全文无 failure strain / ultimate load）。
- ❌ 是**矢状面（跖/背屈）**，而踝扭伤机制是**冠状面（内翻/旋后）**。

**⇒ 用途**：用它锚定「韧带集合 + 应变尺度 + taut 阈值 + '扭伤=极端位置事件'前提」；**失效阈值另补文献**（librarian）。

## 2. 判据设计（骨-韧带串联）

已有 R1：内翻力矩 `M_inv = F_lat · d`（`ankle_supination.inversion_moment_nmm`）。

新增（opt-in）：
```
F_lig = M_inv / r_lig                    # 韧带到内翻轴的力臂 r_lig
ε_lig = F_lig / (k_lig · L_lig)          # 或 F = k_lig·ε 线性；或非线性
criterion: ε_lig ≥ ε_fail  →  扭伤(sprain)
```
- **主韧带 = ATFL**（内翻首选受伤），次 = CFL。
- `r_lig / A_lig / k_lig / L_lig / ε_fail` ← 文献（librarian 结果）。

## 3. 输出
- 各 (h, β) 下 ATFL 的力 / 应变 / risk；**扭伤临界角 β_sprain(h)/高度**。
- 与临床对照：踝扭伤 = 踝伤 **71%**（Heck）、**#1**（fspor）。

## 4. 与 [Tochigi2006] 的接口
- 用其**正常应变上限**（ATFL ~6%）作"**非生理**"参照线。
- 用其**韧带集合**命名与优先级。
- 用其 **taut>1%** 作"开始受力"下限。

## 5. 诚实边界
- [Tochigi2006] 是**矢状面**研究 → 「内翻→ATFL 应变」的力臂/关系需**另锚定**（标注来源）。
- **失效阈值来自其他文献**（非本论文）。
- 1D 线弹性 + 单韧带为主：**上界式**；只看相对/是否越阈。

## 6. 执行结果（✅ 完成，bg_cd75d981）
- 新模块 `src/climbing/coupling/ankle_ligament.py`（opt-in）+ 脚本 `scripts/opensim_fe/ankle_ligament_criterion.py` + 报告 `results/opensim_fe/ANKLE_LIGAMENT_CRITERION_REPORT.md` + 测试。
- **默认回归 0.00e+00**；主 **19/1**、非垂直 S1+S2+S5+R4+韧带 **124/3**。
- **结论**：**β≥10° 时 ATFL 扭伤在两口径下都成立**（保守 M_fail=21 N·m & 高承载 77 N·m）；β=5° 仅保守口径越阈；β=0 安全。
- **临床对照**：补上骨模型（仅踝骨折 27%）漏掉的 **#1 踝扭伤 71%** → 定性一致。
- 上界式：力/应变口径把全部 `M_inv` 归单韧带（ε 达 10³%）→ **只用关节级主口径**；`r_lig` assumed；预载外推不确定（两口径并报）。

## 7. 韧带参数（librarian 取，bg_58a30b03）

| 参数 | ATFL | CFL | 来源 |
|---|---|---|---|
| 极限载荷 | **≈200 N**（140–350） | **≈340 N**（300–370） | St.Pierre 1983; Chapman 2019; Siegler 1988 |
| 失效应变 | **≈14%**（11–15） | **≈13%**（9–13） | Siegler 1988; Chapman 2019 |
| 割线刚度 | **14±4 N/mm** | 12±4 N/mm | 近期共识 |
| 静息长度 | 18–25 mm | 25–32 mm | Siegler 1988; Golanó |
| CSA | 13 mm²（高变异） | 10 mm² | Siegler 1988 |
| 弹性模量 | ≈260 MPa | ≈510 MPa | Siegler 1988 |
| **关节级内翻失败力矩** | **21–34 N·m（无预载）**；2 kN 预载 → **77 N·m** | ATFL 之后 | Funk 2002; Parenteau 1998 |
| **关节级内翻失败角** | **33–40°** | ~27°（组合修复） | Funk 2002; d'Hooghe 2019 |

- **建议口径**：**关节级内翻力矩判据（21–34 N·m）为主**（避开了韧带力臂 r_lig）；**力/应变判据为辅**（r_lig 需假设）。
- **关键 caveat**：**内翻承载随轴向预载显著上升**（Funk：0→2 kN 时 21→77 N·m）；抱石冲击 ~21 kN 轴向，**预载效应外推不确定** → 报告需同时给"无预载（保守）"与"预载（乐观）"两口径。
- **力/应变判据**：`F_lig = M_inv/r_lig`，`ε≈F_lig/(k_lig·L_lig)`；`r_lig` assumed（~20–25 mm）。
- ⚠️ 用户列的 Woo 1983 是 **ACL（膝）**，不用于踝；Siegler 1988 才是踝韧带的初级数值源。
