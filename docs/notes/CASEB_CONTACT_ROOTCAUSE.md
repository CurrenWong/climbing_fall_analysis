## 1. 🔴 根因一：手写 `<Surface>` 被静默丢弃（单变量证据，哨兵 = nnz）

| Surface 写法 | 首轮 nnz | 判定 |
|---|---|---|
| 手写 `<Surface><quad4>…</quad4></Surface>` | 378 | ❌ **接触从未装配** |
| **`<PartList>` + `@part_list:`** | **612** | ✅ 装配 |

真 Case B 几何同样成立：**2109 → 2766**。

### 为什么骗过了此前所有检查
- `model.log` 的 `MESH INFO` 段**只打印** materials / domains / nodes / solid elements，
  **从不打印 surface** ⇒ 日志看不出面是空的
- `CONTACT INTERFACE DATA` 段**照常打印全部参数**（含 `sliding-elastic` 的 WARNING）
  ⇒ **"参数被解析" ≠ "面被接受"**
- 因此 `rc=0` + `NORMAL TERMINATION` + 参数打印，**三条加起来都不构成"接触已生效"**

### 修法（手册 §3.14「A note on auto-contact」）
```xml
<PartList name='primParts'>platen</PartList>
<PartList name='secParts'>slab</PartList>
<SurfacePair name='pair'>
  <primary>@part_list:primParts</primary>
  <secondary>@part_list:secParts</secondary>
</SurfacePair>
```
FEBio 从 part 自行提取表面，绕开手搓 facet 的全部坑。

### 判别命令（唯一可信判据）
```powershell
# 正则必须带 \s*：日志里冒号前有空格，写 \.+: 会读空 ⇒ 误判"无数据"
Select-String -Path <case>\model.log -Pattern 'nonzeroes in stiffness matrix'
# 无接触基线 378（2 立方体最小算例）⇒ PartList 后 612
```

## 2. 🔴 根因二：`ΣRz≠0` 是 **FEBio 反力输出的规则**，不是物理失败、也不是我的读数器 bug

### 受控三变体实验（唯一变量 = 底面 BC 的类型）

### 结论（**这三条同时成立才自洽**）
1. **FEBio 的 `reaction forces` 输出不包含 `zero displacement` DOF 的反力** —— 只报 `prescribed` DOF。
   ⇒ 从「固定面」读反力**恒得 0**，与物理无关。
2. **`ΣRz=0` 这个判据本身的前提用错了**：它只对「全部约束都是 `prescribed`」的模型成立。
   用 `zero displacement` 固定时 `ΣRz` 必然等于 prescribed 面那一份。
3. **我的读数器读得对**（h5 原始数据就是如此；位移索引 node i ↔ index i−1 已验正确）。
   ⇒ 上一版写的「检查器可能有映射问题」**作废**。

## 4. ✅ 已定案：`p_top` 的 **−88.25 N** = **PENALTY 接触的记账伪影**，不是传递力

### 判据实验：罚刚度扫描（`auto_penalty=0` ⇒ `<penalty>` 就是**真实**接触刚度 K）

| K | `ΣRz(p_top)` | **界面 `ΣRz(s_top)`** | 互穿 (mm) |
|---|---|---|---|
| 1e-3 | −0.49 | +0.005 | 0.04998 |
| 0.03 | −14.70 | +0.149 | 0.04951 |
| 1.0 | −491.2 | +3.80 | 0.03753 |
| 100 | −49 485 | +15.18 | 0.001415 |
| **1e4** | **−4 949 985** | **+15.65** | 0.000014 |
| **焊合体（无接触）** | **+15.96** | — | 0 |
| 基线（auto=1, scale=0.03） | −88.25 | +0.852 | 0.047197 |

脚本：`temp/ankle_fe/step1b_penalty_sweep.py`（实跑验证）

### 三条同时成立的结论
1. **界面 `ΣRz` 才是真实传递力** —— K→∞ 时收敛到 **15.65 N**，与**焊合体**的 **15.96 N** 吻合。
   这是本篇的**正对照**：把接触换成焊合，力回到物理量级。
2. **`p_top` 的 prescribed-DOF 反力不是力** —— 它随罚刚度从 −0.49 单调涨到 **−4.95e6**
   （≈ `1e4 × K × 互穿`），而真实力收敛到 ~15.7 N。
   ⇒ **PENALTY 接触在场时，`prescribed displacement` 面的反力是记账伪影，绝不能当传递力。**
   （软罚区间 `p_top / 界面力 ≈ 98~99`，与接触面积 100 mm² 同阶 —— 疑为罚参数量纲按面积放大，未细究。）
3. **基线 Case B 的罚刚度软了 ~18×** —— 界面力 0.852 N vs 正确值 15.65 N。
   ⇒ 基线根本不在收敛的接触区间，此前算不出 `k_contact` 是**必然**的。

### 顺带定案：Case A 的 27.078 N 可信
Case A **无接触**；无接触时 prescribed 面反力**是**真实力（焊合对照 v3 给出物理量级 15.96 N，
与 1D 估计 12 N + 端部约束抬高相符）。⇒ Case A 的 `k_meas=390.1 vs 解析 400` **不受本伪影影响**。

### ⛔ 方法论（写进 LRN-20261010-003）
**有 PENALTY 接触时，读力的位置只有一处：接触界面两侧节点的 `ΣRz`。**
`zero displacement` 面恒 0（§2），`prescribed` 面被罚刚度污染（本节）。

## 7. 检查器自身的坑（8 个，"判据没对门"）

1. hex8 形状函数 `∂N/∂ζ` 的 N4/N8 **符号写反** → detJ 全负、误判"网格坏了"
2. **Newell 面积公式参数顺序反**（`cross(roll(P),P)` 应为 `cross(P,roll(P))`）
   → 假报"面积 840 mm²、法向带 x 分量"，**差点据此改坏本来完全正确的 deck**（实际 100 mm²、`[0,0,1]`）
3. 2-流形判据写错（要求所有边用 2 次）→ 开放面片边界边**必然**是 1 次
4. `np.roll(P,-1,axis=1)` 滚的是**坐标分量**不是顶点 → 法向恒为 0
5. 反力读取的 state 探测用了废码 `["x"] and [...]`
6. **正则漏空格**：`nonzeroes in stiffness matrix \.+: ` 实为 `\s*\.+\s*:\s*`
   → nnz / steps 全读空，导致多轮"看起来没数据"
7. **`ΣRz≠0` 用错了前提**（见 §2）—— 把「zero displacement 不报反力」当成"物理失衡"
8. **BC 解析正则漏 `z_dof`**：写 `<([xy]?_?dof)>` 匹配不到 `z_dof`
   → 曾据此误判「s_bot 只约束 x,y」

> **教训**：发现矛盾时**先怀疑自己的公式/判据**，再怀疑被测对象。
> 「面积 840 但 z 极差为 0」「ΣRz≠0」这类**物理上不可能**的组合，第一嫌疑是检查器。

### 与 §11 的张力（已解释）
§11 的 Case B patch test 说"该档位接触软 ~40%"，但这里踝线的力只动 5%。

⇒ **不要把"接触自身软 X%"直接搬到"整体结果错 X%"。**

## 13. 选项1：tibiotalar 罚标定 —— 基线的**总偏差 = −4.95%**（2026-10-10 收尾）

脚本 `temp/ankle_fe/opt1_penalty_calibration.py`（锁死配置，DISP=+1.0；单变量只改 tibiotalar）

**方法**：总柔度 `C(K) = C_o + C_contact(K)`，`C_contact ∝ 1/K`
⇒ 拟合 `1/k = C_o + a/K`，外推 `K→∞` 得刚性极限。**残差 1.4e-12 ⇒ 模型成立。**

| K（AUGLAG, auto=0, 真实刚度） | F (N) | Δ vs 基线 | 收敛 | k/k_rigid |
|---|---|---|---|---|
| 基线（auto=1, scale=1） | 418.0971 | — | rc=0 | **0.9505 → −4.95%** |
| K=1 | 435.6117 | +4.19% | NORMAL | 0.9904 → −0.96% |
| K=5 | 439.1954 | +5.05% | NORMAL | 0.9985 → −0.15% |
| K=10 | 439.3735 | +5.09% | NORMAL | 0.9989 → −0.11% |
| K=20 | 439.5244 | +5.12% | NORMAL | 0.9993 → −0.07% |
| K=50 / K=100 | — | — | **rc=1（不收敛）** | — |

**⇒ `k_rigid (K→∞) = 439.851 N/mm`**

### 四条结论
1. **接触刚度饱和极快**：K=1 已到刚性极限的 **99.0%**，K=5 到 **99.85%**
   ⇒ 踝线**不需要大罚**，`K=5` 就够。
2. ✅ **基线的总偏差 = −4.95%** —— 与 §12 的 DISP 扫描（+5.02%±0.4pp）**互相印证**。
   ⇒ **我上一轮担心的"可能高达 12%"被直接测量否掉**（因为 K=10 距刚性极限只差 0.11%，
   所以"scale=1 → K=10"那 +5% 基本就是全程）。
3. ⚠️ **削硬有量程代价**：DISP=+1.6 时 K=2/5/10 的失败点 = 施加位移
   **1.214 / 1.142 / 1.100 mm**（越硬越早死），而基线可达 1.6 mm
   ⇒ **精度与量程不可兼得**。
4. **K≥50 两条路都不收敛** ⇒ 实用上限 **K≈20**。

### 可操作结论（给踝线部署）
| 方案 | 偏差 | 量程 |
|---|---|---|
| **(a) 维持基线** `PENALTY+auto=1+scale=1` + **乘 ×1.05 修正** | 修正后 ~0 | ≥1.6 mm |
| **(b) 换 `AUGLAG+auto=0+penalty=5`** | −0.15% | **≤1.1 mm** |

⇒ **若工作范围 ≤1.1 mm 就用 (b)（几乎免费消掉 5%）；否则用 (a) 加常数修正。**
