## ⚠️ 归档 论文初稿 时的一个**必须知道的坑**

初稿与 v2 **是两套不同结构的稿子，章节号不能互相替换**：

| | **初稿（已归档）** | **论文 v2（权威）** |
|---|---|---|
| 标题 | 软垫上为何仍会骨折？——室内抱石落地骨与韧带损伤的**数值建模** | 室内抱石软垫落地骨与韧带损伤的**多层级一维-二阶上界式建模** |
| 第 2 章 | `2 方法`（2.1 总体思路 … 2.7 转动/踝/头颈扩展） | `2 问题描述与数学模型`（2.1 坐标系与假设 … 2.6 头-颈惯性分支） |
| 第 3 章 | `3 结果`（3.1–**3.8**） | `3 求解过程`（3.1–**3.4**） |
| 第 4/5/6 章 | `4 讨论`（4.1–4.5）／`5 结论` | `4 结果`／`5 讨论`／`6 结论` |

⇒ **同号章节内容完全不同**，例如：
- 初稿 `§2.1` = **总体思路** ↔ v2 `§2.1` = **问题定义、坐标系与基本假设**
- 初稿 `§4.2` = **为什么"低能量"也会三踝/距骨骨折** ↔ v2 `§4.2` = **软垫的收益与代价**
- 初稿有 `§3.6`（为什么三踝与距骨仍会发生）↔ **v2 根本没有 §3.5/§3.6**

⇒ **`results/opensim_fe/figures/FIGURE_CAPTIONS.md` 里约 10 处 `论文初稿 §x.y` 的引用，
必须继续指向本归档件，不能顺手改写成 v2 的同号章节** —— 否则图注会指到错误内容。

**判断规则**：引用**路径**时跟着权威走（v2）；引用 **§ 章节号**时认准它写的是哪一稿。
