## 一、为什么是这个形态

图文的核心竞争力是**数据密度**（一堆百分比、OR 值、三种场景），视频的竞争力是**一眼看懂对比**。所以不做"文章朗读"，做成**数据解说 + 对比动画**：

- 不出现真人出镜（无法拍摄）→ 用**数据动画**承担信息、**AI 生成画面**承担氛围
- 单条只讲**一个反直觉结论**：摔法分两条路，一条伤脚踝、一条伤肘肩
- 结尾指向公众号文章，形成"视频引流 → 图文消化"的闭环

  -show_entries format=duration -of csv=p=0 'D:\Project\climbing_fall_analysis\video\calib\A_快_科普.wav'
```

**脚本**：`video\shots_calc.py`（音节计数 + 逐镜时长推算，含中文数字读法展开）。改 VO 文案后重跑即可刷新本节数据。

    "stream": "false",

    "work_dir": "D:\\Project\\climbing_fall_analysis\\video\\temp",
    "skill_dir": "C:\\Users\\curre\\.copaw\\workspaces\\J6c4mu\\skills\\mimo-tts"
  }

```

> 用 `--out` 指定完整路径，**不要用 `--out-dir`**：并行合成多镜时自动时间戳命名会撞名互相覆盖（已踩过）。

**MiMo 已知坑（实测，勿踩）**：

- `optimize=true` **仅 design 模型有效**；`preset` 一律传 `"false"`
- `stream=true` 会强制改成 `pcm16` 输出；preset 之外的模型流式没上线，传了也没用
- 脚本会自动 fallback 读注册表 `HKCU\Environment` 拿 `MIMO_API_KEY`——`set | findstr MIMO` 查不到**不代表 key 不存在**
- cmd 里带 `&` 会炸，PowerShell 必须显式 `powershell -NoProfile -Command "& '路径' ..."`
- 单段文本较长时可能触发"响应提前结束"，此时把该镜拆成两段分别合成再拼
