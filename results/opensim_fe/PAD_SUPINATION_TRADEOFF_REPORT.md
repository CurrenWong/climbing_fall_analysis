## 0. 一句话结论

- **在本模型的中央几何参数（L_roll=40 mm）下，不存在内部最优刚度 k\***：`total_risk(k)` 对 k **单调递减**——垫子越硬，总腓骨风险越低，k* 落在**刚性极限 k→∞**。
- **两难确实存在，但方向不对称**：软垫（k≈1e3 N/mm，S1 实测 R_min=0.764，仅 −23.6%）省下的**轴向**风险，远小于它因脚沉入垫（δ=F/k）引起的额外旋后 β 所带来的**侧向弯曲**风险（σ_bend ∝ β·F_peak；见 §3.1 与 §3.4 的定量门槛）。
- **k* 不随高度移动**（本模型下始终 k→∞）；但**安全余量随高度收缩**：刚性极限下 total_risk 从 h=2 m 的 0.659 升到 h=4.5 m 的 0.779——高的落点即使“最硬垫子”也逼近 / 越过阈值（正对应 [Beurienne2025] “high impact energy scenarios 中 rigidity 可能 ineffective”）。
- **安全域**：在 (h, k) 平面上，阈值边界 k_th(h)（total_risk=1）约为 h=2 m → k≳9.78e+04 N/mm、h=3 m → k≳1.25e+05 N/mm、h=3.5 m → k≳1.52e+05 N/mm、h=4.5 m → k≳2.37e+05 N/mm。**越软越危险，越硬越安全**（本模型口径）。
- **灵敏度稳健**：L_roll∈{25, 40, 60} mm 三档下，结论均为“无内部极小、k* 落在硬端”（`robust_no_interior_optimum = True`）。

> ⚠️ β(k) 是 **modeled**（无实验 β(k) 数据）。绝对值不可信，只看 **相对与阈值是否跨越**。详见 §5 诚实边界。

## 1. β(k) 几何模型（**modeled**）

机制原文（[Heck2024] §5.2.3）：

> The soft surface initially allows the foot to sink in, accompanied by a **supination movement of the ankle joint**. Once the modulus of elasticity of the soft-floor mat is reached, the weight forces on the supinated joint increase until ligamentous structures or bones give way.

把这句话做成可计算的几何：

```
δ(k) = F_peak(k) / k                                    # mm，Winkler 凹陷深度
β(k) = clip( β_0 + arctan(δ(k) / L_roll), 0, β_max )    # deg
F_peak(k) = F_peak_rigid · R_FE(k)                      # S1 实测折减比
```

| 参数 | 中央值 | 灵敏度区间 | 性质 | 依据 |
|---|---:|---|---|---|
| L_roll（roll 几何杠杆） | **40 mm** | 25 / 60 mm | **modeled** | 足部横向半宽量级（跟骨 ~35 mm、前足 ~50 mm） |
| β_0（基线旋后角） | **0°** | 0° | **assumed** | 默认 0° = “无垫子 = 无几何旋后”基线，只建模垫子引起的额外旋转 |
| β_max（几何饱和角） | **45°** | 30 / 60° | **assumed** | 脚可旋转上限；>45° 通常已扭伤 / 脱位 |

**退化（硬门槛）**：

- `k→∞`（刚性）：`δ→0`、`β→β_0=0`、`F_lat=M_inv=0`、`lateral_risk=0`、
  `total_risk = axial_risk`（**与今天逐位一致**）。
- `k→0+`（极软）：`δ→∞`、`β→β_max`（饱和）。

## 2. 耦合公式与总风险定义

```
axial_risk(k)   = axial_risk_rigid · R_FE(k)                  # R1 纯轴向 × S1 折减比
                  （axial_risk_rigid = R1 刚性地面纯轴向腓骨风险，√k→∞ 时逐位复现）
F_lat(k)        = F_peak(k) · sin(β(k))                        # β 重新指向横向（R1）
M_inv(k)        = F_lat(k) · d                                 # d=30 mm (assumed)
σ_bend          = M_inv · c / I
τ_shear         = F_lat / A
σ_lat           = σ_bend + τ_shear        # 主口径：保守线性叠加
lateral_risk(k) = σ_lat / σ_c             # σ_c = 70 MPa [Y25] fibula_ends
total_risk(k)   = axial_risk(k) + lateral_risk(k)             # 保守
```

| 几何 / 参数 | 值 | 性质 | 来源 |
|---|---:|---|---|
| A_section | 101.94 mm² | **measured** | `bc_robust_metric_route1.json::rows[fibula_r]`（THUMS CORT hex） |
| I（等效圆） | 826.9 mm⁴ | **modeled** | `risk_1d_bending.json::sections_equivalent_circle.fibula_r` |
| c（等效圆） | 5.6963 mm | **modeled** | 同上 |
| d（CoP→距下轴力臂） | 30 mm | **assumed** | R1 默认（后足横向半宽量级） |
| σ_c（弯曲极限） | 70 MPa | **assumed** | [Y25] fibula_ends **压缩**强度；拉伸侧仅 30 MPa（本口径低估拉伸侧） |
| mult_fibula | 0.232345 | **measured**（载荷分配） | `risk_1d_loadshare.json` |

**判读**（中央口径）：

- **无内部最优**：`total_risk(k)` 在全部 h 上单调递减（软→硬）。
- **k* = 刚性极限**（k→∞）在全部 h 上取到；即“最硬垫子 = 最小总风险”。
- **安全余量随高度收缩**：刚性极限下 total_risk 由 0.659（h=2 m）升到 0.779（h=4.5 m）。

### 3.3 验证 [Beurienne2025] 的两难方向

| 主张 | 本模型结果 | 一致？ |
|---|---|:---:|
| “垫子越硬 → 防过度旋后 → 降低韧带 / 骨力” | 是：k↑ ⇒ δ↓ ⇒ β↓ ⇒ σ_lat↓ | ✅ |
| “对高冲击能量场景可能无效甚至更糟” | 部分是：k↑ 仍降总风险，但刚性极限下高 h 的 total_risk 逼近 / 越过 1（高能量下无垫可救） | ⚠️ 方向一致、量级不同 |
| “垫子越软 → 脚沉入 → 旋后” | 是：k↓ ⇒ δ=F/k↑ ⇒ β↑ | ✅ |

> 关键差异：本模型里 **软垫对轴向下调（S1 实测 R_min=0.764，仅 −23.6%）远远抵不过它对 β 的上调**（δ=F/k 随 k 反比增长，β 随 δ 近似线性，侧向弯曲 σ_bend ∝ β·F_peak）。所以“软垫更安全”的直觉在**旋后这条轴上不成立**。

### 3.4 内部极小存在性的定量门槛（为何软端必输）

对一个“候选软端 k”，使其总风险低于刚性端所需的**轴向折减比例**为：

```
total(soft) < total(rigid)  ⟺  1 − R > lateral_risk(k) / axial_risk_rigid
```

## 6. 假设与诚实边界

1. S1 的 R_FE(k) 是**实测**（FE 探针，跟骨局部 gauge）；把整条载荷链按同一比例折减是**建模**（1D 线弹性 ⇒ 载荷/应力成比例）。
2. β(k) 是**几何建模**，无实验 β(k) 数据：presented as MODELED，其绝对值不可引用；本报告只在**相对 / 阈值是否跨越**上使用它，并用 L_roll∈{25,40,60} mm 灵敏度扫描。
3. total_risk = axial + lateral（保守线性叠加）；若两轴不同时达到峰值则该口径高估。
4. σ_c=70 MPa 是 [Y25] fibula_ends **压缩**材料强度，用作弯曲极限是近似；弯曲拉伸侧 [Y25] 仅 30 MPa → 本口径低估拉伸侧风险（结论只会更强）。
5. 截面用腓骨中段皮质代理远端 / 外踝（无独立远端截面）；外踝略粗 → 偏保守。
6. d=30 mm 为 assumed（模型无 CoP）。灵敏度见 R1 报告（{15,30,45} mm）——在 R1 中已证明结论对 d 不敏感。
7. 本模块只读复用既有产物，**不调用 FEBio**，**不重跑 OpenSim 正动力学**，不覆盖任何既有文件；所有既有模块的签名 / 默认返回值逐位未动。
8. 临床 #1 踝伤是**韧带扭伤（71%）**；本骨模型只能对应**踝骨折（27%）**。
