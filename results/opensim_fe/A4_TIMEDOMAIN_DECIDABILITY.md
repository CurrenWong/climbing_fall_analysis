# A4 时间域度量 · 未闭合项 #2 —— 「Δt < 0 是否物理可能？」

> **日期**：2026-10-13 ｜ **性质**：判据**可判定性**检查（自我怀疑的验证）
> **触发**：`results/opensim_fe/A4_TIMEDOMAIN_REPORT.md` §4 —— 「防重蹈空间域 A4 覆辙」的必做项。
> **目的**：在花 ~3 h 跑满 50 点之前，先确认**本判据是否在测一件模型做不到的事**。

---

## 0. 结论（先说）

> **Δt < 0 在本模型架构下结构性不可能。**
> ⇒ **`A4_时间域双路径_预注册.md` §3.1 的主判据（Δt 变号）同样是【架构不可判定】**
> —— 与空间域 PCA（`A4_重定级.md`）**同类**：判据在测一件本模型做不到的事，**记 FAIL 会误导**。
>
> **附带（更重要）：这个操作性定义本身可能与 [Y25] 的「双路径」不是一回事**（§3）。

---

## 1. 因果链证明（Δt < 0 不可能）

**模型**：`ground_reaction(h) → run_dead_drop(passive=…) → joint_reaction(joint=…)`。

| 步 | 事实 |
|---|---|
| 1 | **唯一时变外力 = 足底的 GRF**（`PrescribedForce` 施加在足体上）；其余外力（重力）**恒定**、不产生「到达」事件 |
| 2 | `lumbar` 关节反力 = **躯干+上肢子树**（`_LUMBAR.bodies = torso + 8 块臂骨`）的自由体平衡 —— **该子树不含足** ⇒ **无 GRF 直接作用** |
| 3 | ⇒ 腰椎载荷**只能**经「足 → 踝 → 膝 → 髋 → 腰椎」这条约束链传入 |
| 4 | GRF 事件**之前**，全身自由落体 ⇒ 子树与本体同加速度 ⇒ 惯性项与重力项相消 ⇒ **腰椎力 ≈ 0** |
| 5 | ⇒ **腰椎的加载时刻必然 ≥ 踝的加载时刻** ⇒ **Δt ≥ 0 恒成立** |

**⇒ 结论**：`Δt < 0`（脊柱先于踝）要求存在一条**绕过足部**的载荷通路 —— **模型中不存在**。

**这不是经验发现，是模型架构的定理。** 用它做判据 = **测一件模型做不到的事**。

## 3. ⚠️ 更深一层：操作性定义可能**本身就选错了**

回看 [Y25] 双路径的**本项目原始表述**（`docs/methods/OpenSim_FE复现方案.md:211-214`）：

> **[Y25] 的「阶跃 vs 渐进」对架构的含义**：
> - **阶跃部位**（足、胫骨两端、股骨颈、脊柱、颈椎）→ 应力由**外载荷**主导 → 单骨 FE 足够；
> - **渐进部位**（腓骨两端、骨盆、颅骨）→ 应力由**传导动力学**主导 → **必须有多体**（OpenSim）参与。

| | [Y25] 的「双路径」 | 我的 `Δt` |
|---|---|---|
| 是什么 | **每个部位的应力由哪种机制主导** | **两个关节的到达时刻差** |
| 类型 | **载荷分解**（外载荷分量 vs 传导分量） | **时序排序** |
| 分组对象 | **部位**（9 个 → 阶跃/渐进两组） | **关节对**（ankle, lumbar） |

⇒ **两者不是同一个量。** [Y25] 要的是「**每个部位的主导机制**」，
我测的是「**踝与腰椎谁先到**」——后者是前者的**一个必要但不充分的侧面**，
而且在死落架构下**恒为同一符号**（§1），**根本不含分组信息**。

**⇒ 度量选错了**（这也解释了为什么它给不出分组）。

---

## 4. 正确的替代定义（修正提案，**不夹带执行**）

**目标**：复现 [Y25] 的「**外载荷主导 vs 传导主导**」二分。

**定义（每个部位一个标量，无自由参数）**：

```
τ_part = t_peak(部位载荷/应力) − t_peak(GRF)
```

- **阶跃部位**（外载荷主导）⇒ **τ ≈ 0**（与 GRF 同步）
- **渐进部位**（传导主导）⇒ **τ > 0**（延迟 / 振铃）

**判据**：9 个部位的 τ **分成两组且有间隙**，且分组与 [Y25] 的阶跃/渐进清单一致。

**等价表述**（更贴近原话）：把部位载荷分解为
`F(t) = F_quasi-static(GRF(t)) + F_dynamic(惯性/传导)`，
以两者的**能量或峰值占比**作分组变量。

## 5. ⛔ 修正提案的**已知阻塞**（必须登记）

| 阻塞 | 说明 |
|---|---|
| **渐进部位没有时域信号** | 本流水线的时域输出只有**关节**反力 `{subtalar, ankle, knee, hip, lumbar}`。而**渐进部位（腓骨/骨盆/颅骨）**的应力只有空间域 `σ(h) ∝ load(h)`（冻结矩阵），**无时间分辨率** |
| ⇒ 影响 | **恰好是待分组的三个渐进部位缺数据** ⇒ 该判据**当前不可测**，除非新建「**时域关节载荷 → 部位 FE**」链（等于把 FE 层做成瞬态，是**大件**） |
| 备选 | 用**关节级** τ 作代理（关节 = 载荷通路上的节点）：`{ankle, knee, hip, lumbar}` 的 τ 是否随高度产生分化——**但这不是 [Y25] 的部位分组**，只能作**指示性**报告 |
