### 1.2 Route-FE ends/shaft 分区规则（精确可复现）

1. 载荷轴 = 主承力域节点坐标 bbox **最长轴**（与 `risk_1d_bending.py` θ 定义一致）。
2. 单元形心 `c_e` = 其节点坐标均值；沿轴投影 `t_e = c_e·axis`。
3. `L = t_max − t_min`；**ends** = `t ≤ t_min + 25%·L` 或 `t ≥ t_max − 25%·L`（两端各外 25%，共 50% 跨度）；**shaft** = 中间 50%。
4. 子区域统计量 = 该子区域内单元 von Mises **p95**；再按 σ(h)=σ_solve·load(h)/fe_solve 严格线弹性缩放到各高度。

## 6. 假设与诚实边界

1. σ_c 取自 src/climbing/bone.py MATERIAL_STRENGTH_MPA（[Y25] Table 1 压缩）—— 材料强度，非整体骨失效载荷；绝对值不可信，相对排序可用。
2. Route-1D σ_total 来自 risk_1d_bending.json（梁弯曲上界估计）；同一条 σ(h) 用于两端与骨干，仅阈值不同（任务指定）。
3. Route-FE 收缩：主域 p95；ends/shaft 仅对 3 长骨按几何位置切分，其余用整域。
4. FE 应力按严格线弹性线性缩放；未重跑 FEBio/OpenSim。
5. 论文的双传导路径(d)是**事件内时序**，50×9 高度矩阵不含时序 → 不可直接计算，仅定性对照。

- **(d) 双传导路径**：论文描述的是**单次坠落事件内的应力时序**（足部/颅骨先，两路汇于脊柱）。我们的 9×50 高度矩阵**不含事件内时序**，无法计算路径先后 —— 仅能定性说「低高度先下肢、高高度全身」，与「上下两路汇于脊柱」不矛盾。
- **(e) 5 类/3 阶段**：重映射后低高度即出现多部位骨折，矩阵过早饱和，Jaccard 聚类类数少于论文 5 类 —— 属**真实不对齐**，非计算失败。
- **骨干被高估**：弯曲 1D 的 σ_total 是**全骨上界**（等效圆 + 全骨长 + 简单支承），论文的骨干不骨折在本口径下无法成立；FE 的 p95 又被边界条件伪影污染（`BC_ROBUST_METRIC_REPORT.md`）。
