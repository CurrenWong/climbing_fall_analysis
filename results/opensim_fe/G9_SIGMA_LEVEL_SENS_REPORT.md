## 3. 读法

- **`vm_median` 是 G3 现冻结口径**，此处仅作基准，**不覆盖**。
- `abs_szz_median` 在 §11.6 已证伪（同载荷两解差 23%、2× 载荷只升 1.15×）。
- `abs_szz_p95` / `szz_free_mean_vol` 可复现，但 p95 **不满足 DoD-1 的线性要求**（2× 载荷时 p95 升 11.2× —— 分位数随【受载区扩大】而跳），故不作 σ(h) 的水平。
- `szz_elem_mean_all` 是**未加权**全体均值（含固定区 0 值）⇒ 被稀释约 1.7×，**不作口径**，只用于暴露加权错误。
- `szz_free_mean_vol` = 自由区体积加权轴向均值（压缩为负）⇒ 按定义 = `−F/A_eff` ⇒ 与 `F_over_Aeff` 互为交叉验证。
- `F_over_Aeff` 由**实测截面**与**平衡**锚定，A_eff 各解重现；水平可被载流独立验证。
- OR 由 `load(h)` 形状 + 交叉高度决定 ⇒ 换统计量改的是 **util 的绝对水平**；口径选择须避免把腓骨推成 `all_zero` 或 `all_one`。
