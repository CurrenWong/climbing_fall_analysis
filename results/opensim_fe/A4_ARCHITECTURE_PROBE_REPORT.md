# A4 架构探针

> **性质**：**只读诊断**（不改判据、不改数据、不建新本构）。
> **触发**：Step 3-A 拟「建真渐进失效本构」以解 A4 的 rank-1 天花板。
> **本报告先做可行性验证**——若架构上不可能，建本构就是白做。
> **脚本**：`scripts/opensim_fe/a4_diagnose_live_vars.py`（读冻结件 `fracture_matrix_bc2.json` / `s4_alignment_bc2.json`）。

---

## 0. 一句话结论

> **A4 的 rank-1 不是「本构不够强」，而是「σ(h) 后处理层工作原理上无法表示 [Y25] 的传导双路径」。**
> **即使把全部部件设成完美塑性平台（E_t=0）并扫遍所有屈服阈值，PC2 最高只到 11.42%，仍低于每一个候选 null（13.8% / 18.5% / 20.1% / 24.2%）。**
> ⇒ **任何后处理本构都不可能修好 A4**；Step 3-A 的原计划（建新本构）**应终止**。

---

## 2. 真结构：严格 rank-1 是**真的**

逐部件相对极差（= σ 极差 / σ 均值）：

| 部件 | σ 均值 (MPa) | 相对极差 |
|---|---|---|
| 足部 | 221.1 | **136.94%** |
| 胫骨 | 52.58 | **136.72%** |
| 腓骨 | 588.3 | **136.72%** |
| 股骨 | 36.32 | **130.07%** |
| 骨盆 | 109.1 | **130.07%** |
| 腰椎 | 326.6 | **131.50%** |
| 胸椎 | 1052 | **131.50%** |
| 颈椎 | 324.8 | **131.50%** |
| 颅骨 | 361.1 | **131.50%** |

**九个部件的相对极差只落在 4 个值上（130.07 / 131.50 / 136.72 / 136.94%）**
⇒ **σ_i(h) = c_i · load(h)**（同一个 h-函数，只差常数因子）⇒ **严格 rank-1**。

- 协方差秩（数值）= **4**（那 3 个非主方向是浮点残差，PC3 = 0.00045%）
- PC1 = **99.975%**、PC2 = **0.0242%**
- 这**不是尺度问题**（H2 已证伪）、**不是死变量问题**（H1 已证伪）——**是严格线弹性的数学必然**：
  `paper_alignment.py:589` 的 `σ_vm(h) = σ_vm_ref · load(h)/load_ref` 对所有部件都是**同一个 load(h)** 的线性函数。

## 3. 为什么两轮损伤本构都只到 0.88% / 0.93%

| 轮次 | PC2 | 相对基线 |
|---|---|---|
| 基线（严格线弹性） | 0.0242% | — |
| 降阶双线性（`G4_DAMAGE_REPORT.md`） | **0.8791%** | ×36.3 |
| ＋载荷链顺应性（`G4_LOADCHAIN_REPORT.md`） | **0.93%** | ×38 |

**根因（两层）**：

1. **参数层**：卡内**皮质骨**软化比 `E_t/E ≈ 0.51–0.90`（`G4_DAMAGE_REPORT.md:30`）⇒ 只给**膝拐**、几乎不改变形状；
   仅足部/颈椎有 `E_t = 0`（真平台），但**足部首屈服在 h=24 m**、颈椎被 `σ_y=80 < σ_c=150` 封顶成**常值**。
2. **架构层（决定性）**：见 §4——**即使参数层做到极致（全平台）仍然做不到**。

> ⚠️ **附带发现（第二轮的真实损伤）**：损伤律把 **腰椎/胸椎/颈椎封顶成常值 ⇒ 方差=0 ⇒ 有效变量 9→6**。
> 也就是说那一轮**不但没造出 rank-2，还破坏了 3 个变量**。这解释了为何它离 null 那么远。

## 4. 能力探针（决定性的存在性测试）

**问**：σ(h) 后处理层**有没有能力**造出 PC2 > null？（这是**架构容量**问题，与参数取值无关。）

**做法**：把**全部**部件沿卡内**最强软化端**映射——`E_t = 0`（完美塑性平台，`σ = min(σ_lin, σ_y)`）——**扫遍**统一屈服阈值 σ_y。
平台是「形状分化」的**上限**：任何真实的双线性律都夹在「无软化」与「完美平台」之间。
**若连平台都做不到 ⇒ 任何本构都做不到。**

| σ_y (MPa) | PC1 | PC2 | null₂ (Horn PA, 95%) | 判定 |
|---:|---:|---:|---:|---|
| 50 | 93.07% | 5.01% | 30.88% | FAIL |
| 100 | 89.40% | 8.18% | 21.80% | FAIL |
| **150** | **86.26%** | **11.42%** ← 最好 | **20.06%** | **FAIL** |
| 200 | 87.11% | 10.19% | 20.06% | FAIL |
| 300 | 92.91% | 5.52% | 18.56% | FAIL |
| 500 | 94.11% | 4.99% | 18.56% | FAIL |
| ∞（无损伤基线） | 99.98% | 0.024% | 18.56% | FAIL |

（σ_y = 25 时 PC2 = 2.48%、null₂ = 48.05%；σ_y ≤ 10 时活变量 < 2 不可检验。）

**⇒ 全程扫描下 max(PC2 / null₂) = 0.569 < 1** —— **任何屈服阈值都不可达**。

**对比 `G4_DAMAGE_REPORT.md` 用过的其他 null**：平行分析（6 变量）**13.81%**、断棍 **24.17%**。
**11.42% 低于全部候选 null** ⇒ **结论对 null 口径稳健**。

---

## 5. 机理：为什么架构上做不到

1. **自由度只有 1 个**：所有部件都是 `σ_i(h) = g_i(load(h))`，即整条轨迹由**单一标量** `load(h)` 参数化。
   轨迹是 σ 空间里的一条**一维曲线**；其中心化协方差能否 rank-2，取决于**切向 `g'(load)` 在载荷区间内转不转**。
2. **载荷区间太窄**：σ 的相对极差仅 ~130% ⇒ `load` 只变 ~2.3× ⇒ `g'` 的**旋转量小**。
3. **软化太弱**：皮质骨 `E_t/E ≈ 0.82–0.90` ⇒ 转一点点；即使人为给到完美平台（0），也因前两条而不足。
4. **本质**：**[Y25] 的「双路径」是「自下而上 vs 自上而下」的传导动力学属性**——
   这正是本项目自己写下的判断：

   > `docs/methods/OpenSim_FE复现方案.md:214`：「双路径本身也是**耦合**属性，不是单纯 FE 能给的。」
   > `docs/methods/G4_损伤演化设计.md` §7：「空间 50×9 矩阵**无法表示**（`paper_alignment` 已注记）。」

   ⇒ **用空间 σ(h) 矩阵的 PCA 去检验一个时间域传导属性，是操作性定义与目标不匹配**，不是本构强度问题。

## 6. 对 Step 3-A 的影响（结论与建议）

| 项 | 处置 |
|---|---|
| **原计划「建真渐进失效本构」** | ⛔ **应终止**——§4 证明架构上不可能，建了也只会得到 PC2 ≲ 11% |
| **A4 的定性** | 从「❌ 结构性 FAIL」精确化为 **【架构不可判定·后处理层无法表示传导双路径】**（**与 V8b 同类**：模型类别不足，非模型算错） |
| **正确路径（已在冻结件里）** | **`G4_损伤演化设计.md` §7 时间域双路径度量**——在**顺应链**中测「足路径信号」与「头惯量路径信号」到达脊柱的**到达时差**。这是 [Y25] §d 的物理正确表达，且冻结设计**已文档化**，只是被一个**从未满足的 gate**（「PC2 超 null 但 LP 失败」）挡住。 |
| **不回溯改判** | `S4_ALIGNMENT_BC2_REPORT.md` 的 A4 = FAIL 结案**有效**，本报告只**更正归因**（不是抢救）。 |
| **需用户拍板** | (a) A4 是否按「架构不可判定」重定级（同 V8b 待遇）；(b) 是否开 §7 时间域度量作为 A4 的**替代操作性定义**。 |
