1. **默认回归（硬门槛）: PASS** —— 默认路径与改前缓存 `s1_h5_opensim.json` 最大相对误差 **0.00e+00**；显式 `roll_deg=0` 与默认 GRF 数组**逐位一致** = True；旋后模型在 β=0 时 `F_lat=M_inv=0` = True。

## 3. 机制与模型

[Heck2024] §5.2.3：软垫先让脚**下沉**，伴随踝**旋后（内翻）**；一旦达到垫子弹性模量，**作用在旋后关节上的体重力上升**，直至韧带或骨失效。即：

```
脚沉入垫  →  踝旋后（β 内翻）  →  达垫子模量后载荷上升  →  韧带 / 骨失效
```

坐标系（OpenSim 全局系，y 向上）：x=前后（≈距下轴投影），y=竖直，**z=左右（冠状面）；旋后/内翻轴 = x**。给定峰值 3D GRF `F⃗=(F_x,F_y,F_z)`、旋后角 `β`、CoP→距下轴力臂 `d`：

```
F_lat = F_y·sinβ + F_z·cosβ            # 冠状面横向力
M_inv = F_lat · d                       # 绕距下/踝 x 轴的内翻力矩
σ_bend = M_inv · c / I                  # 弯曲
τ_shear = F_lat / A_section             # 剪切
σ_lat  = σ_bend + τ_shear               # 线性叠加（主口径）
σ_vm   = sqrt(σ_bend² + 3·τ_shear²)     # von Mises（交叉校核）
risk   = σ_lat / σ_c,   σ_c = 70 MPa    # [Y25] fibula_ends
```

**退化**：β=0 且地面水平（F_z=0）⇒ `F_lat=M_inv=0` ⇒ 旧轴向行为**逐位不变**。

## 10. 假设（ASSUMPTIONS）与诚实边界

1. 旋后角 β 是**载荷模型的输入**（不是 OpenSim 里解锁的 subtalar 自由度）；模型仍为刚性锁死腿（方案 S3 未做）。
2. F_lat 由 3D GRF 矢量按旋后角解析；默认 β=0 且地面水平时 F_lat=M_inv=0，逐位复现旧轴向行为。
3. d = CoP→距下轴力臂默认 assumed 30 mm（后足横向半宽量级）；无实测 CoP（pad.py 无 CoP），故为 assumed；敏感性覆盖 {15,30,45} mm。
4. 截面用腓骨**中段皮质**代理**远端/外踝**（无独立远端截面）；外踝略粗 → 偏保守。
5. σ_c=70 MPa 是 [Y25] fibula_ends **压缩**材料强度，用作弯曲极限是近似；弯曲拉伸侧更弱（σ_t=30）→ 本口径**低估**拉伸侧风险，结论只会更强。
6. 1D 梁（Euler-Bernoulli）线性叠加，忽略剪切修正、应力集中、韧带/腱卸载、接触摩擦与能量吸收 —— 上界式筛选，绝对值不可信，只看相对与是否越阈。
7. 本脚本只读复用既有产物，不调用 FEBio，不覆盖既有产物。

**结构边界**：

- 临床第一大踝伤是**韧带扭伤（71%）**；本骨模型只能对应**踝骨折（27%）**（[Heck2024]）。补韧带判据是后续工作。
- 旋后角是**输入参数**而非 OpenSim 里解锁的 `subtalar_angle_r`（仍是刚性锁死腿，方案 S3）。
- `σ_c=70` 为**压缩**材料强度；弯曲拉伸侧 [Y25] 仅 **30 MPa** → 本口径**低估**拉伸侧。
- 中段截面代理远端 / 外踝 → 偏保守；力臂 assumed → 敏感性已给。
