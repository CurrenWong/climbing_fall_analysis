## 0. 结论（一句话）【**已作废 —— 见文首撤回块**】

**股骨的 A2 缺口不是「载荷路径」，而是「口径层级错配」：
`σ_c` 是**材料点**级强度（`bone.py:73-74` 代码明写），却与**部位级 `median`** 比较。
按层级配对（材料级 σ_c ↔ 局部极值）后，股骨在 `p95` / `max` 下**本就是阶跃型**。
⇒ 但**不得**直接采用 —— 先用同一层级论证解释「为什么其他部位不能同时改」。**

## 1. 决定性证据（**代码级，非推理**）

`src/climbing/bone.py:73-74`：

```python
#: [Y25] 表 1 原始值：材料级拉伸/压缩强度 (MPa)。
#: **这是材料强度，不是整体骨失效载荷。** 见模块 docstring。
MATERIAL_STRENGTH_MPA: dict[str, tuple[float, float]] = { ... }
```

`bone.py:35-37`（模块 docstring）进一步确认：

> 「[Y25] Table 1 给的是**材料强度（MPa）**，用于和有限元 von Mises 应力对比。
> 把它 × 截面面积换算成整体骨失效载荷是**近似**，且对部分部位会显著高估
> （足、骨盆、脊柱尤甚）—— 因为整体骨的失效还涉及足弓、小梁骨、弯曲与应力集中。」

**⇒ `σ_c` 的层级 = 材料点（局部失效应变对应的强度）。**

### 层级对照表

| 量 | 层级 | 来源 |
|---|---|---|
| **`σ_c`** | **材料点（局部）** | `bone.py:73-74`（[Y25] Table 1） |
| `median`（**现行口径**） | **整块 / 整域** | `fracture_matrix.py`（`STATS`） |
| `p95` / `max` | 同一域内的**局部极值** | 同上 |

**⇒ 与材料级 `σ_c` **配套**的统计量是**极值**（`p95`/`max`），不是 `median`。**

## 3. ⚠️ 但**不能**直接采用 —— 两个必须先解的问题

### 3.1 【已更正】「打崩其他部位」的机制 —— 我原先的假设**被 F-1 证伪**

> **⚠️ 更正（2026-10-13，F-1 代码核对后）**：本小节原稿写「被打崩的胫骨/腰椎/颈椎在 `REGIONS` 里
> 都有『两端』子区域、σ_c 远低于骨干 ⇒ 存在又一层级错配」。**该说法错误，已替换：**

`paper_alignment.py:86-99` 的 `REGIONS` 实测（**逐字**）：

| 部位 | 子区域 | 阈值键 |
|---|---|---|
| 足部 | `跟骨(整体)` | `calcaneus` |
| **胫骨** | `胫骨两端` + `胫骨骨干` | `tibia_ends` / `tibia_shaft` |
| **腓骨** | `腓骨两端` + `腓骨骨干` | `fibula_ends` / `fibula_shaft` |
| **股骨** | `股骨颈` + `股骨骨干` | `femoral_neck` / `femur_shaft` |
| 骨盆 / 腰椎 / 胸椎 / 颈椎 / 颅骨 | **单一「整体」子区域** | `pelvis` / `spine` ×3 / `skull` |

`LONG_BONES = {"tibia_r", "fibula_r", "femur_r"}` —— **只有 3 根长骨是两段，其余 6 个部位是单阈值。**

**⇒ 所以腰椎/颈椎没有「两端子区域」，不存在「整域极值 × 两端低阈值」这回事。**
**⇒ `p95`/`max` 打崩腰椎/颈椎的机制是：整域极值本就 > 其单阈值（150）⇒ h=1 即超阈 ⇒ `all_one`。**
**⇒ 即：**域与阈值的配对在两种口径下都正确**；被打崩的原因是**
**「整域极值 ≥ 单阈值」这个纯数值事实，不是配对错误。**

**⇒ 本小节的更正把问题**收紧**了（见 §3.3）。**

### 3.3 更正后的真问题（**比原假设更尖锐**）

§1 的层级论证（`σ_c` 是材料点强度 ⇒ 应配局部极值）**仍然成立**，但更正后可以看到它的**代价与边界**：

* 把**每个域**的统计量都换成 extremes ⇒ **所有部位都趋向 `all_one`**（极值 ≫ 中位数）
  ⇒ 这解释了 `A2_AGGREGATION_RULING` 交叉检查里「命中 4/6 → 1/6 → 0/6」。
* **⇒ 症结不是「域/阈值配对错」，而是「阈值是按 `median` 标定的」**：
  `σ_c` 取自 [Y25] Table 1 的**材料强度**，与它天然配套的是**局部应力**；
  但**具体取哪个局部量**（单元极值 / `p95` / 体积加权 / 表层单元）**是一个可判定但未定的问题**。
* **⇒ 因此本件不得给出「改用 `p95`」这种结论**：那需要**同时**重新标定阈值，
  而**扫阈值 = 凑靶（红线）**。

**⇒ F 的真问题（更正后）**：
> **「材料级 σ_c」应当配 FE 解里的哪一个局部应力量（而非整域 median）？
> 该选择必须由独立论证给出，且须说明其他 8 部位会怎样。**

### 3.2 必须由独立论证定，不得由「刚好让股骨过」定

**红线**（`A2_AGGREGATION_RULING.md` §5-3、`FE_BC_STAB.md` §4-ter.3）：
