# A1 聚类边界复核 —— 「Δ=2.0 卡边界」是口径产物还是真差异？

> **▶ 关联件（2026-10-15 新增）**：`A1_BOUNDARY_WINDOW_REPORT.md`。
> 本件定了「#1 = 口径产物、#2 = 真差异（口径挪不动）」；关联件在其上补了两个本件未答的问题：
> **(a)** 混 BC（股骨换 P5 接触）对 A1 **逐位无影响**（修股骨不移动 A1 边界）；
> **(b)** #2 **不是结构不可达** —— 胸椎首折 `h* ∈ [16,18] m` 时 #2 落 (14,18) ✅，
> 但**窗口很窄**且 h*=33（照搬股骨修法）会使 Δ₂ 从 4.0 **恶化到 16.0**。
> ⚠️ 本件 §0/§3 的**判定与数字不变**（关联件只加「窗口存在」这一层，不覆盖任何结论）。

> **日期**：2026-10-13 ｜ **性质**：只读复核（不改判据、不改数据、不回溯改判）
> **脚本**：`scripts/opensim_fe/a1_boundary_convention.py`（读 `results/opensim_fe/s4_alignment_bc2.json`）
> **背景**：`S4_ALIGNMENT_BC2_REPORT.md` §0/§1 报 A1 = FAIL，边界 `[5.0, 12.0]`、`Δ=[2.0, 4.0]`。
> 其中 **Δ₁ = 2.0 恰好等于判据阈值**（判据为 **|Δ| < 2.0**，严格小于）⇒ 触发本次复核。

## 0. 结论（先说）

| 边界 | 目标（[Y25]） | 实测相变区间 | Δ 随约定范围 | 判定 |
|---|---|---|---|---|
| **#1** | 7 m | **[5, 6] m** | **1.0 – 2.0** | ⚠️ **口径产物**（换约定即 PASS） |
| **#2** | 16 m | **[12, 13] m** | **3.0 – 4.0** | 🔴 **真差异**（口径挪不动） |

⇒ **A1 的 FAIL 判定不变**（边界 #2 是真差异），**但归因应更正**：

> 原归因（隐式）：「两个边界都差」。
> **更正为**：**只有一个边界真差（高位相边界 #2）；低位边界 #1 的 Δ=2.0 是「取相内最后一格」这一报边界约定造成的系统性偏差**，其真实相变位置（5–6 m）落在判据容差内。

## 1. 根因：边界值的报法

`s4_alignment_bc2.py:207-215`（**未改**）：

```python
b1 = float(phases[0]["range_m"][1])          # ← 取「相内最后一格」
b2 = float(phases[1]["range_m"][1])
d1 = abs(b1 - A1_TARGETS[0]); d2 = abs(b2 - A1_TARGETS[1])
ok = (d1 < A1_TOL and d2 < A1_TOL)           # A1_TOL = 2.0
```

聚类在 **1 m 整数高度网格**上做（`heights = [1,2,3,4,5]`…），相变真实位置**只能在区间内被定位**：

| 相 | 实测高度范围 |
|---|---|
| P1 轴向传导 | 1–5 m |
| P2 全身复合 | 6–12 m |
| P3 全身复合 | 13–50 m |

⇒ 相变 #1 在 **[5,6] m**、相变 #2 在 **[12,13] m**，**精度 ±0.5 m**。
脚本取区间**左端点**（= 相内最后一格），这是三种约定里**最保守**的一种（最大化 Δ）。

## 2. 三口径并列（实测）

```
=== 边界 #1  目标 7.0 m   相变区间 [5, 6] m ===
  末格 (冻结口径, 脚本现用)   报  5.0 m   Δ = 2.0   -> FAIL
  相变中点                    报  5.5 m   Δ = 1.5   -> PASS
  次相首格                    报  6.0 m   Δ = 1.0   -> PASS

=== 边界 #2  目标 16.0 m   相变区间 [12, 13] m ===
  末格 (冻结口径, 脚本现用)   报 12.0 m   Δ = 4.0   -> FAIL
  相变中点                    报 12.5 m   Δ = 3.5   -> FAIL
  次相首格                    报 13.0 m   Δ = 3.0   -> FAIL

=== 汇总 ===
  约定「末格」    ⇒ Δ = [2.0, 4.0] ⇒ A1 = FAIL
  约定「中点」    ⇒ Δ = [1.5, 3.5] ⇒ A1 = FAIL
  约定「次相首格」⇒ Δ = [1.0, 3.0] ⇒ A1 = FAIL
```

**读法**：

- **边界 #1**：Δ 跨越判据阈值 ⇒ **判定对约定敏感** ⇒ 卡在 2.0 是**口径效应**，不是相变位置的差异。
- **边界 #2**：Δ ∈ [3.0, 4.0]，**任何约定都 ≥ 3.0 > 2.0**，超出 1 m 网格能解释的范围 ⇒ **真差异**。
- **A1 总体**：三种约定下**都是 FAIL** ⇒ **判定不因本次复核改变**（这正是「不回溯改判」的依据）。

## 3. 真差异指向哪里

边界 #2（我们 12–13 m vs [Y25] 16 m）与 **A2 的漏判部位同源**：
A2 实测 **3/5**，漏的两个恰是**股骨**与**胸椎**，行为均为**「常值 1」（低高度即饱和）**。
低位饱和 ⇒ 相变提前发生 ⇒ 与边界 #2 提前到 12–13 m **方向一致**。

**已知归因**（B1.4 诊断 + `S4_ALIGNMENT_BC2_REPORT`）：BC 带代理 ≠ 解剖端
（femur 探针实测：fix 带内 Dirichlet **零应变**、中段弯曲热点 **492 MPa**）。
⇒ **A1 的真正瓶颈是 BC 语义失配，不是判据口径**；本次复核只是把「口径噪声」从归因里剥离出来。

## 4. 处置（不夹带执行）

1. **判定不回溯**：A1 保持 **FAIL**（`S4_ALIGNMENT_BC2_REPORT.md` 结案声明有效，不启动抢救）。
2. **归因更正**（本报告）：失败点是**单边界真差异（#2）**，非「两边界皆差」。
3. **口径写入下次预注册**（若重启 A1）：**边界须声明取法**，或在离散网格上取**相变中点**并同时报区间；
