- ✅ **胸椎 T6 是最佳候选**：两端 cap 都充分（469.93 / 696.18 mm²，面片 100/180）

- ✅ **颈椎 C5 完全对称**（顶/底 cap 面积与面片数逐值相同，ratio = 1.000）。

- 🔴 **颅骨 `parietal_r` 解剖上无对应关节面**〔**常识级判断，未核原始文献**〕：

  ⇒ **P5 式 BC 在当前代表骨上无解剖对应**。改代表骨 = 改冻结几何输入

  多端、且骶髂以**剪切/滑移**为主；P5 式的「刚性压板法向接触」无法表达。

## 2. 缺陷 B · 中轴载荷分配（**硬证据**）

### 2.1 机制（代码审计）

`fracture_matrix.py:135-148` 已有分配机制：

```python
def effective_ref_load(part, joint_load_n):
    return float(joint_load_n) * float(part.load_fraction)
```

但 `build_parts()` **对全部 9 部位均不设 `load_fraction`** ⇒ 取 dataclass 默认值
`1.0`（`fracture_matrix.py:128`）。该字段**仅在 CLI `--load_fraction` 传入时**才被
覆盖（`fracture_matrix.py:1065-1075`）。

**实跑确认**：`fracture_matrix_bc2.json` 的 `meta` **无 `load_fraction` 项**
（而 `fracture_matrix.py:1134` 明确只在非 1.0 时记录）⇒ **BC2 全 9 部位 = 1.0**。

而 `loads_n` **只有 4 个 joint** ⇒：

### 2.2 物理缺陷

真实载荷路径是**逐级串联递减** —— 一个椎体只承「其头侧以上」的质量，而颅骨之上
为空。模型却让每块骨**独立承担该段的总反力** ⇒ 系统性**高估**。

### 2.3 定量（锚点：仓库既有 `risk_1d_loadshare.json` 逐椎质量，Ivancic 2006 /
Pearsall 1996 经 Vette 2015 Table 3 —— **未新增外部数据**）

以 L3 为基准（`lumbar` 反力即对应 L3 层）：

| bone | 承「头侧以上」 | 份额 | 现用 N | 物理可辩护 N | **高估倍数** |
|---|---:|---:|---:|---:|---:|
| `L3` | 32.60 % | 1.0000 | 22087.6 | 22087.6 | 1.00× |
| `T6` | 19.90 % | 0.6104 | 22087.6 | 13482.9 | **1.64×** |
| `C5` | 6.00 % | 0.1840 | 22087.6 | 4065.2 | **5.43×** |
| `parietal_r` | 4.70 % | 0.1442 | 22087.6 | 3184.4 | **6.94×** |

> 链条：L3 = {L4,L5,T1–T12,C1–C7,head}；T6 = {T7–T12,C1–C7,head}；
> C5 = {C6,C7,head}；颅骨 = {head}。

## 3. 缺陷 A vs 缺陷 B 的归因分解（**解析推定**，非 FE 实测）

胸椎是唯一**同时有实测 σ** 的中轴遗留部位，可直接对账：

```
实测   σ_h_at_ref(T6) = 426.04 MPa   阈 = 150 MPa   ⇒ 超阈 2.84×  ⇒ all_one
仅修 B（载荷 ×0.6104） ⇒ σ ≈ 260.1 MPa              ⇒ 仍超阈 1.73×  ⇒ 仍 all_one
```

| 解释 | 能否单独解释胸椎 `all_one` |
|---|---|
| 缺陷 A（端部 BC，已知） | **不能单独定量**（需 FE 重解） |
| 缺陷 B（载荷分配，本件发现） | **不能**（2.84× → 1.73× 仍过阈） |
| A + B 叠加 | **一致**（同向：均高估 σ） |

> ⇒ **胸椎 `all_one` 的主因仍是缺陷 A（端部 BC）** —— **P2 原定义方向正确，未被
> 本件的发现推翻**。缺陷 B 是**叠加的第二个高估源**，不是替代解释。

> ⚠️ **依赖声明**：σ 的载荷缩放用「弹性区 σ ∝ load」推定，依据是 BC2 已验线性度
> （ends 2.76%/s、shaft 0.53%/s）。**未做 FE 重解，故不判定归因权重**。

## 4. 对 P2 范围的影响

### 4.1 范围扩大
P2 必须由**一件**扩为**两件**：

| 缺陷 | 内容 | 治谁 | 主证据 |
|---|---|---|---|
| **A** | 端部 BC（刚性夹持带 + 顶端带载荷 → 解剖关节面分布载荷） | 胸椎 | P2 原定义；P4-a′/P4-c/P5.0/b1 链 |
| **B** | 中轴载荷分配（4 骨共享单反力 → 逐级串联递减） | 颈椎 / 颅骨 | 本件 §2 |

### 4.2 ⚠️ 回落风险（本件最重要的风险提示）
缺陷 B 的修复方向是**降低**颈椎 / 颅骨的 σ（分别 ÷5.43× / ÷6.94×）。
这两部位**当前在 A2 里是命中的** ⇒ **修 B 极可能把它们翻成不命中**。

⇒ **A2 逐部位 5/6（混 BC，2026-10-14）不是稳定上限**，存在**回落**到更低的风险。

### 4.3 顺序约束（⚠️ 纪律）
缺陷 B 与 A1/A2 的既有失败模式**方向相反** —— 它让「命中」变**少**。

⇒ **必须 A、B 一起跑完再入账**。若按「先修 BC（A）后修载荷（B）」分两次入账，
中间那次（只修 A）会得出**过度乐观**的 A2 计数（因为还没暴露 B 的回落）。
⇒ 这与 10-14 那次「混 BC 4/5 PASS」是同一类风险的更隐蔽版本：
**那一版也只修了股骨一个部位，其余 8 部位仍带缺陷 A + 缺陷 B。**
