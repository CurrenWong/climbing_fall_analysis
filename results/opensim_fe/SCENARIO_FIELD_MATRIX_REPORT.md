## 0. 一句话结论

- 已把现场运动学映射到**只用现有 opt-in 旋钮**的场景网格（7 个声明场景，其中 **4 个实际跑载荷链**）；头先/臀先着地**不可**由足端载荷链表示，已明确标注 PROXY。
- 模型侧下肢旗标份额 = **100.0%**（临床 Heck/Müller：下肢 61–67%）。
- 场景级：2/4 个运行场景至少旗标一个部位；各临床桶的‘被旗标场景数’见 §5。
- R5（较低坠落→更多下肢）：**骨折旗标**聚合趋势 = flat（4 个高度档内无可比下降信号）；**姿态分布投影**趋势 = **decreasing**，与临床 <2 m 79.1% → >2 m 58.3% **同向**（见 §6）。

## 2. 载荷分配（与 `risk_1d_loadshare.py` 一致）

```
risk(h)     = F_bone(h) / (A_section × σ_c_stored)          # 1D 名义压缩
sigma(h)    = risk(h) × σ_c_stored = F_bone(h) / A_section  # 纯轴向应力
F_bone(h)   = force_multiplier(bone) × F_joint(h)
弱子区域旗标 ⇔ sigma(h) ≥ σ_c(弱子区域)
```

## 6. R5 —— 「较低坠落 → 更多下肢损伤」的落地姿态分布论证

**临床锚点（Heck/Müller 2024 §4.3.3，measured）**：低坠落(<2 m) 下肢损伤占 **79.1%**（n=34），高坠落(>2 m) 降至 **58.3%**（n=35），Pearson χ² p=0.027。

**本矩阵结论**：按高度重算后，下肢旗标份额随高度的趋势 = **flat**（modeled 份额序列：['—', '—', '100%', '100%']）。

| h (m) | 下肢旗标数 | 其他部位旗标数 | 下肢份额 |
|---:|---:|---:|---:|
| 2 | 0 | 0 | — |
| 3 | 0 | 0 | — |
| 3.5 | 1 | 0 | 100.0% |
| 4.5 | 4 | 0 | 100.0% |

**（b）落地姿态分布投影（survey-informed，论证 R5 的机制）**

设高度 h 的‘旋转发生概率’ α(h) 随高度线性上升（低高度行程短、来不及旋转），α 上界取现场总体旋转比例 59.5%；旋转者按 K2:K3 = 14:11 分（K2→下肢、K3→上肢）：

| h (m) | 旋转概率 α(h) | 投影下肢份额 |
|---:|---:|---:|
| 2 | 45.0% | **80.2%** |
| 3 | 50.8% | **77.6%** |
| 3.5 | 53.7% | **76.4%** |
| 4.5 | 59.5% | **73.8%** |

投影趋势 = **decreasing**；临床实测（<2 m 79.1% → >2 m 58.3%，p=0.027）同为下降 —— **方向一致**，但模型下降更缓（机制上：现场统计的旋转概率在高高度上升更快）。这即为 R5 的**落地姿态分布随高度**解释。

**论证**：R5（Heck/Müller 2024 §4.3.3：较低坠落 → 更多下肢损伤）**不是**单次跌倒的物理，而是**落地姿态随高度分布变化**：低高度行程短、身体来不及旋转，绝大多数为‘直立/双足先落’(K1–K3)，轴向冲击经下肢传导 → 下肢损伤占比高；高度增加后才有足够时间发生纵轴/前后旋转 (K4–K7)，出现单足、前扑(上肢)、头先、臀先等着地，把载荷从下肢转移到踝/膝以外的部位（骨盆/脊柱/颅骨/上肢），下肢份额随之下降。本矩阵用同一套载荷链在 4 个高度上重算，可验证‘姿态改变 → 载荷改道’这一机制（单足/不对称把冲量集中到一侧、抬高该侧下肢 1D 风险；后仰倾斜把竖直分量 ×cosθ 降低）；当叠加现场运动学的**高度分布**后，即得‘低高度以下肢为主、高度增加下肢份额下降’的 R5 结论。

**measured vs modeled**：measured：现场 7 种运动学与临床分布（论文）；modeled：本矩阵的姿态→旋钮映射、每高度旗标计算、份额聚合。

> 要点：(a) 用**当前纯轴向骨折旗标**聚合时，4 个高度档内下肢份额恒为 100%（唯一跨阈值的是单足不对称场景），**不能**定量复现 R5 的下降 —— 因为 (i) 1D 名义压缩对下肢过度旗标，(ii) 模型无上肢/软组织，K3 上肢损伤根本无法旗标；(b) 作为**姿态分布论证**，用现场运动学损伤倾向 + 高度依赖的旋转概率投影，则得到与 R5 同向的下降。诚实地把 (a) 的限制与 (b) 的论证分开陈述。

## 7. 假设与诚实边界

1. 载荷分配沿用 risk_1d_loadshare.py：胫/腓并联 k=E·A/L 分流；L3/T6/C5/parietal 用 mass-above 比；calcaneus/femur/pelvis = 1.0。场景只改驱动关节力 F_joint，不改分流规则。

6. 临床对照口径不同（模型为‘弱子区域风险 cell’，临床为损伤百分比），仅作方向性对照。
