## 3. 机制与模型

**trimalleolar 三踝骨折** —— 临床 #1 踝骨折机制 —— 主导不是内翻，而是 **external rotation / SER (Lauge-Hansen)**：脚以胫骨长轴为轴**向外旋转** → 距骨在踝穴（mortise）内旋转 → 距骨外侧楔形面把**腓骨远端（外踝）**沿横截面**扭转**（torsion about fibular long axis）+ **前后方向**弯曲 → **斜形 / 螺旋骨折**（oblique / spiral fibular fracture）。

[Hirsch & Lewis, 1960s] 的关键实验发现：**踝能承受很大竖直压缩**，但**很小旋转力矩即失效**。这是本模型只敢称「上界」的物理原因：腓骨对绕自身长轴的扭转 + 弯曲极敏感，远比纯轴向敏感得多。

坐标系（OpenSim 全局系，y 向上）：x=前后 / y=竖直 / z=左右。外旋角 `θ` 是绕 **y 轴** 的足部旋转（向外为正）。给定峰值 3D GRF `F⃗=(F_x, F_y, F_z)`、外旋角 `θ`、CoP→胫骨长轴水平偏距 `d`：

```
T_ext = F_y · d · sinθ                  # 绕腓骨长轴（y 轴）的扭矩
J     = 2 · I                             # 等效圆极惯性矩
τ     = T_ext · c / J                     # 扭转剪应力
σ_vm  = √3 · τ                            # 纯扭转 von Mises（保守略去 AP 弯曲复合）
risk  = σ_vm / σ_c,  σ_c = 70 MPa         # [Y25] fibula_ends
```

**退化**：θ=0 ⇒ `T_ext=0` ⇒ 旧轴向行为**逐位不变**。

- 真实中段截面比等效圆**更细**（I=681.8 vs 826.9 mm⁴）→ risk 更高；等效圆是**乐观**口径。
- 这与 [Hirsch & Lewis, 1960s] 的实验结论**完全一致**：踝对绕长轴的旋转力矩极敏感，几何参数的合理变动不会改变这一结论。

## 9. R1 vs S6 的关系（旋后 vs 外旋）

| 维度 | R1（Phase-S5 旋后 / 内翻） | S6（本报告 外旋 / SER） |
|---|---|---|
| 解剖面 | 冠状面（左右向） | 横截面（水平面） |
| 旋转轴 | 距下 / 踝 **x 轴** | 胫骨 **y 轴**（腓骨长轴） |
| 几何量 | `F_lat = F_y · sinβ + F_z · cosβ`，`M_inv = F_lat · d` | `T_ext = F_y · d · sinθ` |
| 腓骨承载 | 弯曲（`M_inv · c / I`）+ 剪切（`F_lat / A`） | 扭转（`T_ext · c / J`）+ von Mises |
| 主导骨折类型 | 腓骨远端斜形 / 横形 | 腓骨远端**螺旋形 / 斜形** |
| 临床机制 | 旋后 / 内翻 | **外旋 / SER（trimalleolar 支配机制）** |
| 阈值跨越（≤4.5 m） | β ≥ 15° ⇒ 全部越阈 | θ ≥ 10° ⇒ 全部越阈 |

> **两者互补**：R1 覆盖腓骨远端**冠状面**机制；S6 覆盖腓骨远端**横截面**机制。**临床 trimalleolar 三踝骨折的外踝臂** —— 即 Lauge-Hansen SER —— 由 S6 直接覆盖。**内踝（medial malleolus）与后踝（posterior malleolus）** 由论文综述覆盖，不在本代码模型范围内。

## 10. 假设（ASSUMPTIONS）与诚实边界

1. 外旋角 θ 是**载荷模型的输入**（不是 OpenSim 里解锁的 subtalar 自由度）；模型仍为刚性锁死腿（方案 S3 未做）。
2. T_ext 由 3D GRF 矢量按外旋角解析；默认 θ=0 且地面水平时 T_ext=0，逐位复现旧轴向行为。
3. d = CoP→胫骨长轴水平偏距默认 assumed 30 mm（足部半宽 50–70 mm 的中点偏内）；无实测 CoP（pad.py 无 CoP），故为 assumed；敏感性覆盖 {15,30,45} mm。
4. 截面用腓骨**中段皮质**代理**远端/外踝**（无独立远端截面）；外踝略粗 → 偏保守。
5. σ_c=70 MPa 是 [Y25] fibula_ends **压缩**材料强度，用作扭转极限是近似；实际骨剪切 / 扭转强度 ~50–60 MPa（典型文献范围），故本口径**略偏乐观**——结论只会更强。
6. 1D 梁 / 圆柱扭转（Euler-Bernoulli + Bredt 薄壁）线性叠加，忽略剪切修正、应力集中、韧带/腱卸载、接触摩擦与能量吸收 —— 上界式筛选，绝对值不可信，只看相对与是否越阈。
7. 本脚本只读复用既有产物，不调用 FEBio，不覆盖既有产物。
8. **本模型只覆盖外踝（lateral malleolus）臂** —— 内踝（medial malleolus）与后踝（posterior malleolus）由论文综述覆盖，不在本代码模型范围。

**结构边界**：

- 临床第一大踝伤是**韧带扭伤（71%）**；本骨模型只能对应**踝骨折（27%）**（[Heck2024]）。补韧带判据是后续工作（S5 已补冠状面韧带判据）。
- 外旋角是**输入参数**而非 OpenSim 里解锁的 `subtalar_angle_r`（仍是刚性锁死腿，方案 S3）。
- `σ_c=70` 为**压缩**材料强度；扭转 / 弯曲拉伸侧强度通常更低（[Y25] 仅 **30 MPa**） → 本口径**低估**拉伸侧风险，结论只会更强。
- 中段截面代理远端 / 外踝 → 偏保守；杠杆 assumed → 敏感性已给。
