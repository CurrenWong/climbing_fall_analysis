## 0. 结论（先说）

**根因已定位：压板的 z 注册基准取自一个「不在接触面上」的节点，导致 T6 全程零接触；
叠加「固定面被替换成 cap 上 3 个只约束 x/y 的节点」，模型在 z 向完全没有约束 —— 这是
一个纯刚体模态。**

| 项 | 定位 |
|---|---|
| **主根因** | `z_wall = a_max + GAP_MM`，而 `a_max` 来自**顶带节点集**；T6 的 `a_max` 节点（**1-based #282**）**不属于**任何被 `axdiv > 0.5` 保留的 cap 面片 ⇒ 压板悬空 **1.2342 mm** ⇒ **接合面片 0/36，t=0 与 t=1 全零** |
| **放大因素** | `bone_feb.py:867-869` 明载 `fix_nodes_override` **替换**（不是追加）`bottom_fix`；`p2_head_contact` 传的是 **cap 上 3 个节点**，且 `_anchor_xy_patch` 又把 `<z_dof>` 置 0 ⇒ **底端完全自由、cap 只约束 x/y** |
| **失效机制** | 骨仅由上 3 点横向固定，**z 向唯一支承本应是接触，而接触从未激活** ⇒ 刚体模态 ⇒ 刚度阵奇异 ⇒ 负 Jacobian |
| **教科书依据** | FEBio User Manual **§8.3.1.5 刚体模态**：「刚体模态下解不唯一，FEBio **极可能报负 Jacobian**。解法＝找出并加约束消除它」；**§8.1.1**：「若在**第一个时间步之前**就报负 Jacobian，很可能是单元节点顺序不对」（本例与之并列的**同类**「求解前即病态」故障） |

⇒ **这不是物理问题，是一个几何注册 bug。** 结论：**有可行路径**（见 §4），但**须你批准重开 P2 才跑**。

## 1. 为什么这是真根因，而不是第 6 条被证伪的假设

> **▶ 后续（同日）**：本件的修法 1 已 **实跑验证** —— 见 `P2_V1_REGFIX_REPORT.md`。
> 单变量重跑 T6 能力门 **0/4 → 3/4 PASS**（h=10/20/30 收敛且接触承载 ~1.00000，h=50 仍不收敛）。
> ⚠️ 本件 §3 的**修法 2 已作废**（会破坏 `bear_frac` 判据），见该节。

`P2_BC_SCOPE_INVENTORY.md` §5ter 记录的三条硬事实，之前被解读为「差别只在接触注入、根因未定位」。本件给出**机制**：

| 硬事实（原文） | 本件的机制解释 |
|---|---|
| ① 「1220.8 N 即 FAIL（1888–2515 负 Jacobian，**首步 t=0.1 就倒置**）」 | 「≈全部单元、首步倒置」**不是**局部压溃签名，而是**全局刚体模态**签名（手册 §8.3.1.5）。局部压溃只会倒置接触区附近的少数单元 |
| ② 「**与载荷无关**，四档诊断负载同模式全失败」 | 因为**四档只改 penalty**（`penalty_for(f_ref)`），**不改压板位移**（`PLATE_DISP_MM = 0.5` 是模块常量）。而真正的驱动已经是「z 向无约束」⇒ 载荷无关**本就应当**如此 ✓ |
| ③ 「BC2 同网格能收敛 10000 N ⇒ 网格可用，差别只在接触注入」 | BC2 **不使用** `fix_nodes_override`，用**真实底端带 + 全约束** ⇒ 无刚体模态 ✓ **网格确实没问题，本件与之一致** |

**★ 且它一次性解释了 §5ter 全部 5 条证伪**（原表述只列「未定位」）：

| # | 原假设 | 本件为何它必然被证伪 |
|---|---|---|
| ① | cap 选到 L/R 内部贴合面 | 与失效无关：cap 面选得对，**错的是压板注册** |
| ② | 压板埋进骨内 4 mm | 方向**相反**：压板不是埋进去，而是**悬空 1.2342 mm** |
| ③ | 接触面积/压强过大 | 接触面积为 **0**，「压强」无从谈起；且 penalty 缩放不改变结果 |
| ④ | 松质骨与皮质壳不连通 | 与失效无关（节点交集 705 全含，本件不反驳） |
| ⑤ | 壳作为接触载体 | `with_shell` 会**改变 band 的单元集** ⇒ 改变 `a_max` ⇒ 改变压板 z；两变体失败**同因**（见 §3 第二层） |

## 2. 证据链（含正对照）

**探针**（零 FE、只读，复用官方口径 `p2_head_contact.cap_geom` + `p5_head_contact.plate_geom_from_mesh`）：

| 量 | **股骨（正对照，P5.0 已 PASS）** | **T6（实录配置 `include_shell=True`）** | T6（`no-shell` 对照） |
|---|---|---|---|
| `a_max` | 233.9502 | 331.7565 | 331.7565 |
| `a_max` 所在节点（1-based） | 4546 | **282** | 282 |
| **`a_max` 是否落在保留 cap 面片上** | **是** ✅ | **否** ❌ | 是 |
| cap 面最高点比 `a_max` 低 | 0.0000 mm | **1.2342 mm** | 0.0000 mm |
| cap 面片数 / 面积 | 178 / 4039.3 mm² | 36 / **159.1 mm²** | 100 / 469.9 mm² |
| **t=0 接合面积** | **385.5 mm²（9.54%）** | **0.0 mm²（0.00%）** ❌ | 38.8 mm²（8.26%） |
| **t=1 接合面积** | 464.5 mm²（11.50%） | **0.0 mm²（0.00%）** ❌ | 38.8 mm²（8.26%） |

**读法**：

- **正对照（股骨）** 的 `a_max` 落在 cap 面上 ⇒ t=0 即接合 385.5 mm² ⇒ 接触提供 z 锚位 ⇒ **收敛**（P5.0 实测 100.0001% 承载）。
- **T6 实录配置** 的 `a_max` **不在** cap 面上 ⇒ `z_wall = a_max − 0.3` 悬在 cap 之上；即便压板再压 0.5 mm（板面最高只到 `a_max − 0.8 = 330.9565`），仍比 cap 最高点（`330.5223`）高 **0.43 mm** ⇒ **全程零接触**。
- **⇒ `p5_head_contact.py:50-54` 注释自己写明的前提——「t=0 时骨轴向完全自由，**必须由接触提供 z 锚位**」——在 T6 上从未成立。**

**自检闸门**（`scripts/opensim_fe/contact_registration_audit.py`，可复用，**自带正对照**）：

```
femur_r  include_shell=True   a_max∈cap=True  | A_engaged(t0)>0=True  | 占比合理=True   ⇒ PASS
T6       include_shell=True   a_max∈cap=False | A_engaged(t0)>0=False | 占比合理=False  ⇒ FAIL
T6       include_shell=False  a_max∈cap=True  | A_engaged(t0)>0=True  | 占比合理=True   ⇒ PASS
```

⚠️ **一条被正对照否掉的断言（如实记录）**：曾把「接合斑偏心度」列为第 4 条断言，但**已 PASS 的股骨实测偏心 30.5 mm**（其 cap 带 4039 mm²，压在穹顶顶点，天然远离带质心）⇒ 该指标**不能**区分好/坏 ⇒ 按「**检查器须有已知正对照，没跑过对照的判据不算证据**」的规矩**废弃为断言**，仅作诊断量输出。

## 3. 修法（三条，**修 bug，不是调参**）

⚠️ **性质声明**：以下均为**几何注册缺陷的修正**，**不是**为凑 A1/A2 判据而调参。判据、阈值、冻结输入一律不动。

### 修法 1（必需，最小改动）—— 压板注册到**保留的 cap 面片自身**的最高点

```python
# 现在（p5_head_contact.plate_geom_from_mesh:114）—— 错：基准取自顶带节点集
z_wall = geom["a_max"] + GAP_MM

# 应改为 —— 对：基准取自**真正参与接触的**面片集合
z_top_cap = max(node_z over geom["cap"] facetsnodes)     # ← 新增量
z_wall = z_top_cap + GAP_MM
```

- T6 上二者差 **1.2342 mm**（股骨上差 0.0000 mm —— **所以股骨从未暴露此 bug**）。
- **修后预览**（零 FE，已实测）：T6 接合面积 **32.0 mm² = cap 的 20.12%**，**优于股骨的 9.54%** ⇒ 锚位充裕。

### 修法 2（~~建议，消除脆弱性~~）—— ⛔ **已作废（2026-10-15，跑 V1 时发现）**

**原提案**：不替换固定面，恢复底端 z 约束。

**作废理由**：底端一旦固定，**底端反力即分掉载荷** ⇒ 接触力 `C = F − R ≠ F` ⇒
**`bear_frac ≈ 1` 这个 P5 核心判据当场失效**。P5 的设计**必须**让骨轴向自由、由接触供 z 锚位。
⇒ **注册修正（修法 1）不是「更干净的单变量」，而是唯一正确的修法。**
（详见 `P2_V1_REGFIX_REPORT.md` §4 自错记录 #2。）

### 修法 3（制度化，防复发）—— 把本件变成**求解前闸门**

- 已实现：`scripts/opensim_fe/contact_registration_audit.py`，3 条断言 + 正对照。
- 建议接入 `p2_head_contact.run_bone()`：**求解前调用；FAIL 直接抛错**，不烧算力。
- **本次故障本可在零求解成本下被拦住** —— 这是「**先验产物再看报错**」纪律的直接兑现。

## 5. 诚实边界（**不得**当作已验证结论引用）

1. **本件未跑任何 FE。** 根因是**几何层面已确证**（零接触 + z 无约束，两条都是**实测**），
   但「修法 1/2 后 FEA 能收敛」是**推论，未验证**。**不得**引用为「T6 已可交付」。
2. **`no-shell` 变体仍未被解释。** 它**通过**了 3 条断言（注册正确、接合 38.8 mm² ≈ 股骨占比），
   却在 P2 实录中同样失败 ⇒ **存在第二层原因，本件未定位**。
   线索（**假设，未验证**）：其绝对接合面积仅为股骨的 **1/10**（38.8 vs 385.5 mm²），
   penalty 接触刚度 ∝ 面积 ⇒ z 支承弱；且该斑偏心 6.6 mm ⇒ 可能倾覆。
   ⚠️ 偏心度指标**已被正对照否掉**（§2），故此处不作论据，只作线索登记。
3. **P2 结案结论的效力**：`P2_BC_SCOPE_INVENTORY.md` §6「当前几何下不可交付」
   **在修法被实际验证之前仍然成立**。本件是**新增证据 + 待验证修法**，**不是**对结案的翻案。
4. **A1 / A2 判定不受本件影响**：A2 仍 4/5（混 BC）、统计维度仍 2/4、胸椎仍唯一遗留。
