# V1 落地载荷路径 —— 实测事实（「力怎么分担、跟骨怎么接触地面」）

> **触发**：用户问「现在落地的力，是怎么分担的呢，根骨直接接触地面吗」（2026-10-16）。
> **性质**：**取证件**（读代码 + 量网格 + 引已落盘实测）。**不改任何判定**。
> **本件新增测量**：`temp/v1_path_geom.py`、`temp/v1_plantar_split.py`（只读网格，不跑 FEBio）。

---

## §0 · 三句答案

1. **不分担 —— 载荷从距下关节面「整面均匀压进去」，从跖面「整个下表面焊死接出来」。**
2. **不是「接触地面」**：默认 BC 是 **`zero displacement` 把跖面 175 个节点三向焊死**，
   且焊的是**整根跟骨的下表面（X 跨 86.55 mm = 骨长的 96%）**，**不是**真实的跟垫/结节接触区。
3. **模型里没有跟垫、没有前足** ⇒ 现实里「跟骨 → 跟垫 → 地面」这条链路，
   在模型里被压缩成「跟骨 → 焊死」。

---

## §1 · 载荷怎么走（四级，逐级实测）

### (1) 左右脚之间 —— **各一半**

`ground_reaction(...)` 默认 `split=(0.5, 0.5)`，实测 `peak_share=(0.5, 0.5)`、`loaded_sides=('l','r')`。

| h (m) | GRF 总 (kN) | **右脚 GRF (kN)** |
|---|---:|---:|
| 2 | 45.49 | **22.75** |
| 5 | 57.07 | **28.54** |

### (2) 脚内 → 距下关节 —— **该脚 100%**

| h (m) | F_subt (kN) | **F_subt / GRF右脚** |
|---|---:|---:|
| 1–5 | 18.03 ~ 28.52 | **0.999** |
| 10 | 40.10 | 0.990 |

**机制**（`src/climbing/coupling/joint_loads.py:146` 逐字）：
> `# 动量矩率 − 重力矩（GRF 作用在关节中心，力偶为 0）`

⇒ 多体模型假定 **GRF 正好过距下关节中心** ⇒ 无力臂 ⇒ `F_subt ≡ GRF脚`。

### (3) 进骨 —— **距下关节面「整面均匀压」**

| 量 | 实测 |
|---|---|
| 面 | `subtalar_joint`，**238 三角片 / 148 节点** |
| 面积 | **2495.33 mm²** |
| 形心 | X = **−1.97** mm，Y = **+0.90** mm |
| 施加方式 | **`PressureLoad p = F/A`**（均匀） |
| h=2 m 的 p | 22723.6 N / 2495.33 mm² = **9.1064 MPa** |

### (4) 出骨 / 地面 —— **跖面「整个下表面焊死」**

| 量 | 实测 |
|---|---|
| 面 | `plantar`，**274 三角片 / 175 节点** |
| 面积 | **2953.78 mm²** |
| **X 范围** | **[−27.50, +59.05]，跨度 86.55 mm**（骨长 89.78 mm ⇒ **占 96%**） |
| Y 范围 | [−40.21, −0.74]（骨 Y 范围 [−40.21, +14.95]） |
| 默认 BC | **`BCZeroDisplacement(x=y=z=1)`** = **三向零位移（焊死）** |

**面积沿 X 的分布（后 → 前）——注意它一直铺到最前端**：

| X 区间 | 面积 (mm²) | 占比 |
|---|---:|---:|
| [−27.50, −16.68) | 333.7 | 11.3% |
| [−16.68, −5.86) | 396.7 | 13.4% |
| [−5.86, +4.96) | 351.7 | 11.9% |
| [+4.96, +15.78) | 370.8 | 12.6% |
| [+15.78, +26.60) | 374.2 | 12.7% |
| [+26.60, +37.41) | 488.2 | 16.5% |
| [+37.41, +48.23) | 480.3 | 16.3% |
| [+48.23, +59.05) | 158.3 | 5.4% |

**⇒ 真实解剖对照**：跟骨承重的是**后结节**（经 **15.4 mm 厚、E ≈ 185 kPa** 的跟垫）接触地面，
接地面积约 **1000–2000 mm²**；跟骨**前部**的下表面在足弓之上、**不与地面接触**。
**⇒ 模型焊的 2953.78 mm² 横跨整根骨，比真实接触区大 ~1.5–3×，且位置明显偏前。**

### (5) 入口与出口错开 ⇒ 偏心载荷

| | X 形心 (mm) |
|---|---:|
| 载荷**入口**（距下关节面） | **−1.97** |
| 载荷**出口**（跖面，面积加权） | **≈ +11.67** |

**⇒ 力从偏后上方进、从偏前下方出 ⇒ 跟骨承受「偏心压缩 + 弯曲」。**
（现实里这个偏心由**跟腱**平衡 —— 而 V1 的主扫描是 `a = 0`，**无跟腱**。）

## §2 · 「跟骨直接接触地面吗？」—— **不是接触，是四种约束之一（都不是物理接触）**

`plantar_bc` 可选（`src/climbing/coupling/plantar_bc.py:11-38`）：

| BC | 地面是什么 | 默认？ | 实测 `gauge_max` (MPa) @h=5 |
|---|---|---|---|
| **`fixed`** | **没有地面实体** —— 跖面 175 节点**三向零位移（焊死）** | ✅ **默认** | **186.756** |
| `roller` | 只约束**法向** + 2 个切向销 | | **186.756（与 fixed 逐位相同）** |
| `roller_free` (k=1) | 全局 Y 固定 + 极软切向弹簧 | | 217.881（**更差**） |
| `spring` | **Winkler 弹性地基**：每跖面节点向 3 个正交固定锚点各连一弹簧（k N/mm） | | 见下 |
| `contact` | 一块**全节点固定的 hex8 薄板**（**数值刚性壁**）+ Coulomb 摩擦 μ=0.6 | | 本件未跑通（见 `V1_LOADSHARE_VERIFICATION.md` §3.2） |

### `spring` 的 k 扫描（@h=5 m，F_subt = 26.383 kN）—— ⚠️ **非单调**

| k (N/mm) | 10 | 100 | **1000** | 10⁴ | 10⁵ | 10⁶ |
|---|---:|---:|---:|---:|---:|---:|
| `gauge_max` | 156.51 | 151.90 | **142.73** | 173.44 | 184.40 | 186.44 |
| 首折 (m) | — | — | **≈5.4** | — | — | 2.11 |

- `k → ∞` 代数地回到 `fixed`（k=10⁶ 残差 **0.168%**）⇒ **自检正确**
- **但在 k≈1000 有个最小值**，两端都回升 ⇒ `monotone_non_decreasing: false`
- ⇒ **这不是一个干净的「垫越软越真实、σ 越低」物理杠杆**

## §3 · 🔴 **两处对既有落账的更正（替换式）**

### 3.1 `roller ≡ fixed` 逐位相同 ⇒ **「切向锁定/固定端奇异」的旧说法不成立**

`V1_FIXABILITY_ASSESSMENT.md` §3.1 写：

> ~~「`fixed` 是**过约束**（把跖面三向锁死）⇒ 人为造出夹持边缘热点。」~~

**实测更正**：`roller`（**只约束法向、切向完全自由**）的 `gauge_max` 与 `fixed`
**逐位相同（186.7563689967737）**，`max/p99/p95/mean` 四项全同。
**⇒ 切向自由度对结果零影响** ⇒ **「三向锁死造成的切向剪力/固定端弯矩」不是机制**；
真正有关的只有**法向**那条（`spring` 扫描），且它**非单调**。

⇒ 该节应改述为：「跖面 BC 的**法向刚度**是变量（切向无关）；其影响**非单调**，
最小值在 k≈1000（−23.6%），故**不宜当作干净的物理杠杆**（见 `plantar_bc_summary.json`）。」

### 3.2 「跖面 = 跟结节接触区」的隐含假设不成立

旧叙述常把 `plantar` 当作「跟骨接地的那一块」。**实测它跨 86.55 mm = 骨长 96%，
覆盖整根骨的下表面（含跟骰关节下方的前部）**，而真实接地只在**后结节（经跟垫）**。

## §4 · **模型里缺什么**（逐条，均可查）

| 缺的东西 | 现实参数 | 模型里 |
|---|---|---|
| **跟垫（heel pad）** | 厚 **15.4 mm**、E ≈ **185 kPa**（PMC8925218；G5 已建模） | **完全没有**（`thums_feb.py` / `plantar_bc.py` / `joint_contact.py` 里搜不到「跟垫/heel pad」）。G5 的跟垫模型在 **1D 链**线上（`chain2d_tissue`），**没接进 V1 的 FE** |
| **前足**（跖骨/趾骨） | 落地时与跟部共同分担 | **没有**（单骨模型）⇒ V1 是**纯跟部着地** |
| **跟腱/跖腱膜的载荷平衡** | 跟腱 F_max ≈ **10885 N** | 有 `achilles` 面 + `TractionLoad`（`a` 参数），但**主扫描 `a=0`**；且实测 `a: 0→1` 对 gauge **几乎无影响**（26.3086→26.3084） |
| **软骨/关节软组 织** | 距下关节软骨 | 只以**均匀压力**代替（`contact` 分支用的是**刚性板**，不是软骨） |
| **皮肤/皮下软组 织** | 接地界面 | 无（焊死） |

## §5 · ⚠️ **一条读不出来的量（诚实边界）**

**「跖面 175 个节点各承担多少」在默认口径下读不出来。**
`fixed` 用的是 **`zero displacement`**，而 **FEBio 不报 `zero displacement` 节点的反力**
（`[LRN-20261010-003]` / `CASEB_CONTACT_ROOTCAUSE.md` R16 已定案）。
⇒ **要读「力在跖面上的分布」，必须换 BC**（`spring` / `contact`，或改
`prescribed displacement`）。本件**没有**做这个测量。

**⇒ 所以严格回答「力怎么分担」**：
- **能读到的是**：左右 **50/50**、脚内 **100% 过距下关节**、入口是 **9.1064 MPa 的均匀面压**
- **读不到的是**：跖面内部的反力分布（`fixed` 不报反力）
- **而且默认口径里根本不存在「接触压力场」** —— 只有**约束反力**

## §6 · 与「完整脚踝能否完成标定」的连接

用户上一个问题的 P3 是【未测·不可判定】（`V1_LOADSHARE_VERIFICATION.md` §3）。
**本件给出了它的物理入口**：完整脚踝能改的不是「距下关节分担」（那被自由体锁死，
§1(2)），**而是 §1(4) 那个「整根骨下表面焊死」的接地界面** —— 换成
**跟垫 + 结节接触区**的真实压力传递。

⇒ **这正好是已测的「跖面 BC 杠杆」所在的位置**，而它的实测表现是：
`fixed` 186.756 →（`spring` 最低 k=1000）142.73，**非单调、幅度 −23.6%**；
`contact` 分支本件未跑通。⇒ **杠杆确实在这个位置，但它是否是一条物理杠杆仍未定。**
