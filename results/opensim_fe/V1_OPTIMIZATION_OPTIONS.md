## §1 · 本轮新增：**逐项隔离**（`flip 1/1` + `hold_k=100`，h=5 m）

| 加入项 | 结果 |
|---|---|
| baseline | ✅ max=**152.491512** |
| `+pad_e_mpa=0.185`（真实跟垫模量） | ✅ **152.491512（逐位相同）** |
| `+contact_pad_thickness_mm=15.4` | ✅ **152.491512（逐位相同）** |
| `+contact_pad_fix_bottom_only=True`（板可变形） | ✅ **152.491512**（中位末位差 2e-6） |
| **`+contact_penalty=5000`** | **❌ 负J×6（首=245）** |
| **`+contact_auto_penalty=1`** | **❌ 负J×6（首=113）** |
| `+` 上列全部 | ❌ 负J×6（首=375） |

### 三条结论

1. **「把刚性地面换成真实跟垫」在这条路上**不可实现** ——
   `pad_e_mpa`（含 0.185 MPa 跟垫）**逐位无效**，**连板改成可变形（`bottom_only`）后仍逐位无效**。
   ⇒ 对应件 `V1_PLANTAR_LOAD_BEARING_FEASIBILITY.md` 的第 2/3 层，此处给出**更硬的否定**：
   **不是「k 太软不可解」，而是「板模量根本不参与」。**
2. **`penalty` 必须留在 0.1**：提到 5000 或开 `auto_penalty=1` 都会**破坏收敛**。
   ⇒ 手册 §3.14 comment 2 的正解（`ε=E·A/V≈5000`）**在本模型上不可用**。
3. **`flip` 的效果需要重新解读**：它把结果从 151.8965 改到 152.4915（+0.4%），
   说明接触**在装配层面是活的**（`penalty` 能破坏收敛、`flip` 能改数）；
   但 **`pad_e` 零影响 + `hold_k` 仍主导** ⇒ **接触并未承担主载荷**。
   ⇒ 准确表述：**「接触被部分激活（贡献一小块刚度），但主载荷仍由 hold 弹簧承担」。**

### 2.3 已排除（不必再试）

- 接触参数调参（penalty/gap/auto_penalty/板模量/板固定/外加载荷）—— 在**惰性**条件下全免疫；
  在**修正绕向后**，`penalty`/`auto_penalty` 只**破坏**收敛
- **跟垫模量**（§1：逐位 0）
- **刚性帽距下接触**（σ ×2.45 恶化）
- **手册五条处方**（A 初始接触 / B 两步法 / C False Transient / D `symmetric_stiffness` / E `auto_penalty`）
  —— 无一条让 `hold=None` 收敛

## §4 · 诚实边界

1. **本件不含任何「新杠杆让 V1 进带」的承诺** —— 已测的都没有。
2. §1 的结论（板模量逐位无效）**限于** `flip 1/1 + hold_k=100 + gap=+0.5 + penalty=0.1` 这一口径；
   换条件可能不同（但 §1 已把 `bottom_only`/厚度/模量都单独试过）。
3. **「接触被部分激活」是读数的推断**（`flip` 改数 + `penalty` 影响收敛 vs `pad_e` 零影响 + `hold_k` 主导），
   **未直接测接触力**（`pad_top` 被固定的条件下反力不可读；见 `V1_LOAD_PATH_FACTS.md` §5）。
4. **不动任何判定**：V1 仍为 ❌【口径不可复现】。
5. 本件全部为 h=5 m（§2.1 除注明外）/ a=0 / anat / `PressureLoad` 口径。
