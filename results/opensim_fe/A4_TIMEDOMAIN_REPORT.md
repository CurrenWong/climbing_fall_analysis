## 2. 关键发现（比 FAIL 本身更有信息）

> **Δt 在全高度量程内几乎恒定：+0.36 → +0.40 ms，总变动仅 0.04 ms。**

两点推论：

1. **符号结构已定**：Δt 的**幅度变动 0.04 ms 远小于其自身量级 0.38 ms**（~10%），
   而其余 43 个高度均落在已采样的区间内部 ⇒ **补满 50 点不会产生变号**。
   ⇒ **本判定对网格密度稳健**（这与「网格不够所以不算结论」不同——是**平坦性**使然，不是覆盖不足）。
2. **物理解读**：Δt ≈ 0.38 ms 是**踝→脊柱的传输延迟**，且**与坠落高度无关**
   ⇒ 它是一个**结构性**（链几何/刚度决定）的量，**不是**高度依赖的**路径竞争**结果。
   而这正是「只有一条（自下而上）路径」的特征：单路径的延迟由结构定，不随 h 变。

**⇒ 结论**：在**本模型**（含其顺应链）中，到达时刻度量**只看到一条自下而上的路径**，
未见 [Y25] 双路径中的「自上而下惯性路径」在时序上竞争。

## 4. ⚠️ 一个必须登记的自我怀疑（防重蹈 A4 空间域覆辙）

空间域 A4 的教训是：**判据架构上做不到 ⇒ 记 FAIL 会误导**。
本件必须问同一个问题：**Δt < 0 在本模型里物理上可能吗？**

- **死落（dead drop）下，脊柱载荷的唯一来源是「足被地面减速」** ⇒ 时序上**必然**是踝先、脊柱后
  ⇒ **Δt < 0 可能需要另一条物理通路**（例如躯干先撞击、或头部惯性通过颈椎下压）。
- 若如此，则本判据与空间域 PCA 同类：**架构不可判定**，而非「模型算错了」。

**⇒ 处置（不夹带结论）**：
1. 本件**主判据记 FAIL**（按预注册字面），**但不升格为「双路径不存在」的结论**；
2. **下一步必做**：§3.2 正对照 + 一项**敏感性/可能性检查**——
   「是否存在任何构造使本度量给出 Δt < 0？」若否 ⇒ 本判据亦应改记 **【架构不可判定】**。
