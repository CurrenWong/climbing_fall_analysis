## 4. 能否到达操作载荷？

- 力控制（`Dmax<1`）最高收敛载荷：**250.0 N**，距操作载荷 25266 N 差 **101.1×**。
- 位移控制最高反应力 R_peak：**1088.3 N**，距操作载荷差 **23.2×**。
- **可达上限 = 1088.3 N**；操作载荷 = 25266.2 N；**差 23.2×**。

- 对 gate (b)（1000 N = 冻结 FE 求解载荷）：可达 1088 N ≥ 1000 N → **可达**。
