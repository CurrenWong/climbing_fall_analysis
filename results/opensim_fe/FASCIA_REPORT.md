# 跖腱膜载荷通路对皮质 gauge 的影响（THUMS AM50 跟骨 · 实验 ④b）

**目标**：给单骨跟骨 FE 增加**跖腱膜（plantar fascia）**载荷通路，量化它对皮质
`gauge` 的影响。单骨模型只含跟骨、**没有前足**，跖腱膜无法做成两骨连接，故建模为
跟骨**跖腱膜附着区**（后内侧结节）上的**张力载荷** `TractionLoad`。

- 网格：`calcaneus_r_anatframe.npz`（AM50 THUMS 右跟骨，双域 CORT hex8 + SPON tet4）
- 载荷：h=5 m, a=0（无跟腱）→ F_subt = 26.383 kN，T1 冲量误差 +5.8%；距下 `PressureLoad p=F/A`，`use_rigid=False`（与 anat 扫描同口径）
- 跖腱膜方向：`fascia_dir` = (1, -0.1, 0)（≈沿足轴向前 +X，含小 −Y）
- 判据：皮质域 `calcaneus` gauge_max（体积平均正则化 R=4 mm = ℓ）> **150 MPa**（[Y25] 皮质压缩强度）；**后处理判据，无单元删除**

## 0. 跖腱膜附着区选取规则（几何、确定性）

在跖面三角片里，保留**质心**同时满足下列三条者，即**后内侧结节**（跖腱膜中央束起点）：

- 后段：x < 跖面 bbox 的 35% 分位（X 前为正）
- 下部：y < 跖面 bbox 的 35% 分位（Y 上为正）
- 内侧：z > 跖面 bbox 的 50% 分位（本右骨 **+Z=内侧**：帧右手系 `Z = X_anterior × Y_superior`，且解剖自洽——内侧结节突比外侧再低 ~3 mm，距下关节的 +Z 极值即内侧支撑面/载距突）

- **实际命中**：规则 `posteromedial-tuberosity (x&y&medial)`，32 个三角片 / 27 个节点，面积 **335.5 mm²**，面心 (-10.0, -36.2, 4.0) mm
- 阈值（mm）：x<3.06, y<-26.72, z>-1.05

> 若该区过小/退化，`select_fascia_attachment` 会按序回退（去内侧限制 → 放宽 x/y 分位），
> 并在 `rule` 里如实记录。本网格命中主规则，无需回退。

## 4. 结论

- **现状口径（fixed）**：F_fascia 0→5.0 kN 时，gauge_max 186.7564 → 186.7564 MPa，Δ = +0.000000 MPa（+0.000000%）。**精确为 0**（不是数值噪声）：张力载荷施加在已三向固定的跖面自由度上，被固定端反力完全吸收，结构响应逐位不变。
- **诊断（spring k=1000）**：F_fascia 0→5.0 kN 时，gauge_max 142.7285 → 143.1246 MPa，Δ = +0.3961 MPa（+0.2775%）；随 F_fascia 单调不降，斜率 ≈ 0.0792 MPa/kN。**很小但是真实、单调、与载荷线性**——在可动支承下跖腱膜张力确实进入骨内，只是量级远小于距下关节载荷。

### 诚实边界

- **跖腱膜大小是参数锚定**：本仓库多体链（下肢锁死、肌肉关闭）**没有跖腱膜力的来源**，
  因此 `fascia_n` 只能给量级扫描（0–5 kN），不是从模型算出的物理值。
- **单骨无前足**：不能在跟骨与跖骨之间建立真实的腱/弹簧两端连接；本载荷只是其
  附着区的等效张力，不含 windlass（趾背伸）机制。
- **fixed 口径下为负结论且机制清楚**：附着区落在三向全固定跖面内，载荷被反力吸收，
  故 gauge 不变；这不是「跖腱膜无用」，而是「在该 BC 下不可测」。诊断线（spring）用于
  给出一条可动支承下的对照。
- 本实验为**筛选性后处理**：σ_vm≥150 MPa 判据不触发单元删除，`gauge_max` 也不是
  临床预测。
