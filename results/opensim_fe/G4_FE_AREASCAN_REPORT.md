## 0. 预注册预测（先写后跑）

目标量 `σ_vm_max`（主域 `fib_cort`）。**固定** F、BC（bottom 30% 固定）、方向（沿骨长轴、
压缩）、网格、材料；**只变加载面积 A**。物理参照 = 名义 F/A ≈ **9.8 MPa**（§9.8，A≈102 mm²），
判据目标带 = **10–30 MPa**（§9.11）。

- **H_pressure**：σ 由接触/压载压力主导（σ ≈ C/A）⇒ 大面积处可落进 10–30 MPa；
- **H_bend**：σ 由细长骨弯曲 / BC 过渡主导 ⇒ σ ≈ C/A + **σ₀**，有面积无关的地板。

## 1. 方法

1. `facet_geom(top_frac=0.30, align_pca=True)` 取骨端外表面（`band` 面片，291 片、5077.2 mm²）；
   apex = 沿轴最高节点（**id 442**，z=101.716=a_max，即刚体压板接触的那个圆顶）；
2. 面片按「到 apex 的**测地距离**（面片图 Dijkstra、边权=边长）均值」自近及远排序 ⇒
   绕 apex 的同心补丁序列；k 片面片 = 一级，A = Σ 面片真实曲面面积；
3. 载荷 `<surface_load type="traction">`，矢量 = `−t·axis`（**轴向压缩**）、`t = F/A`
   ⇒ **轴向合力恰为 F**（traction 是按参考面积的矢量，与面片朝向无关；不像 `pressure`
   会因斜端面产生横向分量）；
4. 另设 1 个 **点载荷锚点**（单节点 1000 N 节点力 = P1-a/V0 的极端机制）；
5. 每级加 ramp（`<scale lc="1">`，0→1）+ reaction 输出；
6. 记账：`R_axis`（=静力平衡判据）、`n_loaded`、`max|u|`（空空间/发散哨兵）、
   峰值单元位置（在补丁内？在 fixed 带？沿轴何处）+ 补丁内局部峰值。

**索引约定正对照（实证，非假设）**：h5 `meshes/0/domains/<dom>` 的真实布局是
**(n_elem, 1 + n_nodes)** —— 第 0 列 = **单元 id（1-based）**，第 1..n 列 = **节点位置（0-based）**。
判据：`fib_cort` 行0 = `[1, 44,72,88,85,192,193,194,195]` ⇒ 单元 1 的节点 id =
`45,73,89,86,193,194,195,196` = Python 侧 `hex_rows[0]` **逐字相同**（脚本内 **842/842 行**
逐行正对照，失败即报错）。把该表当「8 节点 + 材料 id」会整体错位。

## 3. 判定

1. **加载面积不是杠杆**：1000 N 下 σ 对面积**不变**（388× → 1.12×），有效域内也只 2.3×
   ⇒ **压板 / 软适配层 / 远端夹持等一切界面工程都不可能把 σ 压到 10–30 MPa**。
   **§9.10 复活条件（"真接触/压板把弹性 σ_vm 从 ~147 压到 ~10 MPa"）的前提被证伪。**
2. **真根因 = BC 造成的屈曲（几何失稳）**，不是点载荷奇异：1000 N ≈ **4× P_cr** ⇒ 后屈曲折叠
   （δ→294 mm）⇒ 应力是**大变形伪影**。§9.4 的「根因 = 人工点载荷奇异」**应作废**。
3. **点载荷奇异在有效域内不存在**：单节点 100 N ⇒ σ = 9.86 MPa ≈ 名义 9.8 MPa（集中系数 ≈1.03）。
4. **该 BC 的可用域 ≈ ≤200 N**（100 N 时 σ=4.4–9.9 MPa、200 N 时 20.6 MPa、δ=8 mm）。
   在 1000 N 下任何 σ 数字（V0 1066 / 本轮 1100 / 147）都**不是**该结构的线性响应。

## 4. 对既有结论的修正（替换，不叠加）

⚠️ **未解释的 2× 差异（诚实登记，不影响结论）**：本轮 k=291（整 30% 带、traction 均布、沿轴）
@1000 N = **1071.8 MPa**，而 §9.8 的 V4（30% 带 + PCA 对齐、等分节点力）@1000 N = **551 MPa**。
两者都处于**后屈曲**（超有效域），且载荷机制不同（面均布 traction vs 等分 NodalForce），
故**未归因**。不影响本报告结论：面积杠杆的判定是在**同一机制内**做对照（traction 阶梯 vs traction 阶梯、
NodalForce 点载荷 vs traction 补丁），不依赖与 V4 的跨机制比较。

| 位置 | 原判 | 现判（本报告生效） |
|---|---|---|
| §9.4 | 根因 = **人工点载荷奇异** | 根因 = **BC 屈曲/大变形**（1000 N ≈ 4×P_cr）；点载荷在有效域内无奇异 |
| §9.10 | 复活条件 = 真接触/压板压到 ~10 MPa | **前提证伪**：σ 与加载面积无关（388×→1.12×），界面工程无杠杆 |
| §9.11/§9.12 | 27.5 MPa / 垫 FAIL 归因「大面积让骨弯曲让位」 | 方向正确但不是主因；主因是**屈曲**（本轮面积扫描在 1000 N 下 σ 与面积无关） |

## 5. 下一步（正确的复活路径，待拍板）

要想让「1000 N 下的 σ」有意义，必须先让 **P_cr ≫ 1000 N**，即解决 **BC**：

- **(i) 原位支撑**：真实腓骨在原位受**骨间膜 / 韧带 / 与胫骨的侧向约束**，单骨 283 mm 自由长度的
  悬臂 + 端部轴向载荷**不物理**；引入侧向支撑/更短自由长度可把 P_cr 抬高一个量级；
- **(ii) 载荷口径**：要么承认该 BC 只适用 ≤200 N，要么给出使 P_cr > 1000 N 的支撑方案；
- **(iii) 判据**：10–30 MPa 只有在 (i)(ii) 修好后才可再谈（有效域内 100 N 的 σ 已经落在
  4.4–9.9 MPa，即「名义 F/A」量级本身就不是 10–30 MPa 的 1000 N 版本）。

**不做（红线）**：不得用「缩面积 / 换判据 / 调参」把 σ 调进 10–30 MPa。

## 5b. B：BC 灵敏度扫描（固定带长度 = 自由长度杠杆）

**问题**：A 把杠杆定位到 BC（屈曲）。B 定量回答——**要怎样的 BC 才能让 P_cr > 1000 N？**
**方法**：固定载荷补丁（k=17，A=237.2 mm²）、顶带 0.30 不变，**只变 `bot_frac`**（⇒ 自由长度
L_free = span·(1−bf)，span=403.8 mm）；每个 bf 上扫 F ∈ {200,400,700,1000} N。
**预注册**：Euler 定标 P_cr ≈ 250 N × (0.70/(1−bf))²（锚 = bf0.30 实测拐点）。

| bf | L_free (mm) | Euler P_cr | σ/F @200 | @400 | @700 | @1000 | **σ_max @1000 (MPa)** | δ@1000 (mm) |
|---|---|---|---|---|---|---|---|---|
| 0.30 | 282.7 | 250 N | 0.103 | 0.965 | 1.143 | 1.099 | **1099.2** | −294.1 |
| 0.40 | 242.3 | 340 N | 0.096 | 0.512 | 0.992 | 0.885 | **884.6** | −237.5 |
| 0.50 | 201.9 | 490 N | 0.091 | **0.256** | 1.012 | 0.951 | **951.0** | −194.7 |
| 0.60 | 161.5 | 766 N | 0.088 | **0.102** | **0.872** | 0.941 | **940.8** | −136.1 |

- **✅ Euler 定标被独立验证**：bf=0.50 预言 P_cr≈490 ⇒ 实测 400 N 仍近线性(0.256)、700 N 后屈曲(1.012)；
  bf=0.60 预言 ≈766 ⇒ 400 N 线性(0.102)、700 N 后屈曲(0.872)。**拐点位置随 bf 移动，与 1/L² 一致。**
- **❌ 但这个杠杆太弱**：σ_max @1000 N 在全部 bf 下停在 **885–1099 MPa**（最好仅 −19%），
  因为 **1000 N 仍 ≥ P_cr(bf ≤ 0.6)**：要 P_cr > 1000 N 按 Euler 需 **bf ≈ 0.70**（自由长度仅 121 mm，
  即把骨"握持"70% 长）——对腓骨不物理。
- **⚠️ 后屈曲区结果不单调**（σ@1000：1099→885→951→941），符合"折叠模态相关、非光滑函数"的特征
  ⇒ 后屈曲区的 σ **不可当作可预测量**（δ 单调递减 −294→−136 反而符合预期）。

**B 的判定**：在「单根自由骨 + 节点带固定 + 端部载荷」这一族 BC 内，**无论怎么调固定长度都无法
让 1000 N 落在有效域**（腓骨自身 P_cr 仅数百 N 量级）⇒ **单骨路线在 1000 N 下无解**。
唯一物理上正确的剩余杠杆 = **横向支撑（骨间膜 / 与胫骨侧向约束）或关节级多骨模型**
（正是 §9.10 列的备选复活条件）—— 那是**模型范围的决策**，不是本探针能自行选定的。

## 5c. C：横向支撑（骨间膜 / 导向压头）—— **面积杠杆复活**

**问题**：B 说单骨无解，唯一剩余杠杆是横向支撑。C 定量测「支撑形式/范围 → P_cr 与 σ@1000」。
**方法**：固定 A=237.2 mm²、bf=0.30；在自由区加**刚性横向（x/y）零位移**支撑（= 上界理想化）：
`none` / `patch`（只锁载荷补丁）/ `mid` z∈[0.45,0.65] / `long` [0.35,0.80] / `full` [0.32,0.85]。
⚠️ 载荷补丁节点**始终从区间支撑中排除**；`patch` 模式下「支撑集 = 载荷集」（= 导向压头）。

- **横向支撑把屈曲模态直接掐掉**：`patch` 仅 27 个节点，就把 σ@1000 从 1099 → **31.6 MPa**、

  支撑必须覆盖更长的骨干（`long`/`full`）才够 → 符合"支撑段数↑ ⇒ P_cr↑"的直觉。
- **`long`/`full` 是钢筋式（骨间膜）支撑，但有自身代价**：峰值落在**支撑带的上边缘**
  （z_frac=0.81/0.87）⇒ 硬支撑边缘的**新边界层伪影**，把 σ 卡在 ~70–101 MPa。

- ⚠️ **两个必须声明的限定**：
  1. **小面积端的 σ 含"导向补丁边缘"伪影**：峰值 z_frac=0.99 且 `in_patch=0.5`

  ⇒ **骨干支撑形式被其自身边缘伪影支配，不如"导向加载"干净**。

**C 的判定**：
1. **屈曲伪影 100% 可治**（导向加载端或骨干支撑）⇒ §9.10 说的"残余 15× 集中 + 大面积发散"
   **本质是屈曲**，不是不可救的数值/材料问题；**P1-b 从"死"变成"条件性可行"**。
2. **面积杠杆在屈曲被抑制后复活**（σ(A) 单调，100.8→19.0 MPa）。
3. **但判据带 10–30 MPa 只在 A ≥ 237 mm² 达到**；按现实压板面积（≤~105 mm²）σ = 48–101 MPa，
   **仍高 1.6–3.4×**。
4. **残余的两条出路**（都需拍板）：(i) **软（弹簧）横向支撑**替代硬 BC —— 去掉 5c.2 里
   "导向补丁边缘"伪影，但要选支撑刚度；(ii) 接受"**导向压头 + 大面积接触（≥237 mm²）**"
   作为显式建模声明（等于压板带导向且接触面 ≥237 mm²，需确认与实验装置一致）。

## 5d. D：侧向支撑**刚度**扫描（软弹簧替代硬 BC）

**问题**：C 里硬支撑会在导向区边缘造成 σ 伪影（峰值 z_frac=0.99）。换**分布式线性弹簧**
（有限 k）能否消掉它、给出更低的"真实" σ？
**方法**：`<DiscreteSet><delem>b,g</delem>` + `<discrete_material type="linear spring"><E>k</E>`
（pyfebio `discrete` 模块语法）；每支撑节点 **2 根弹簧 → 2 个远处地面节点**
（位置 = p+(d,0,0) / p+(0,d,0)，d=**1000 mm**，全部零位移）⇒ 分别给 x/y 向刚度 k（N/mm/节点）。

> ⚠️ **偏移 d 必须 ≫ 位移**（2026-10-12 踩坑）：弹簧长度 ≈ d − ux + (uy²+uz²)/(2d)，
> 第二项 = 横向位移平方引起的张力 k·u²/(2d)。d=1e-3 mm 时 k=1e6 的弹簧变成**刚性系绳、
> 把骨轴向夹死**（vm 0.1 MPa、|u|≈0，正对照失败）；d=1000 mm 后该项 ≈0.05 N，可忽略。

**正对照（必做，已通过）**：k → ∞ 必须复现 C 的硬 BC 结果。实测 **k=1e6 ⇒ σ=31.7 MPa、
|u|=0.46 mm、峰值 z_frac=0.99**，与 C 的 `lat=patch`（**31.6 / 0.46 / 0.99**）**逐项吻合** ✓
⇒ 弹簧单元确实按预期咬合、刚度标定正确。

**刚度扫描（`lat=patch`，A=237.2 mm²，F=1000 N）**

| k (N/mm/节点) | 1e6（≈硬 BC） | 1e4 | 1e3 | 100 | 10 | **1** | **0.1** |
|---|---|---|---|---|---|---|---|
| **σ_max (MPa)** | **31.7** | 33.1 | 43.8 | 58.0 | 61.5 | **65.9** | **1098.7**（屈曲） |
| \|u\|max (mm) | 0.46 | 0.51 | 0.92 | 1.49 | 1.57 | 1.67 | **313.4** |
| 峰值 z_frac | 0.99 | 0.32 | 0.80 | 0.80 | 0.80 | 0.80 | 0.32 |

- **σ(k) 单调递减、无内部极小** ⇒ **软化支撑不会降低 σ，反而升高**（1e6→1：31.7→65.9 MPa）。
  ⇒ C 里"峰值落在导向区边缘"**不是**限制 σ 的主因；软支撑让骨多弯曲（峰值移到骨干 z≈0.80）反而更糟。
- **存在最小可用刚度**：k=0.1 N/mm/节点（合计 ~2.7 N/mm）时屈曲回归（|u|=313 mm、σ 回到 1099）；
  **k ≥ 1 N/mm/节点（合计 ~27 N/mm）即可压住屈曲**。⇒ 骨间膜只要提供 ≳27 N/mm 的侧向刚度就够用。
- **判定**：路线 (i) 的答案是**否定**——**硬（导向）支撑已是最优**，无需引入软支撑及其刚度选择；
  这条支线**至此收口**。⇒ 决策点回到 C 的结论：**硬导向 + A ≥ 237 mm²**（σ 19–31.6 MPa，达标）
  或接受"小面积压板 ⇒ 48–101 MPa（高 1.6–3.4×）"。

## 7. 附：本轮新增/修复的约定坑

1. **h5 `domains/<dom>` 布局 = (n_elem, 1+n_nodes)**：第 0 列是单元 id、其余是 **0-based** 节点位置
   （`+1` 才是 1-based 全局 id）。**判据 = 与 Python 侧单元逐行比对**（本轮 842/842 通过）。

4. 有效域内 traction 与 nodal 两种机制给出**同样**的 σ/F（k=1 的 0.093 vs point 的 0.099），
   ⇒ 二者互为正对照，说明报值不是机制伪影。
