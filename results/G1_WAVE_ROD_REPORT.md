## 2. 波动观测量定义（第一原理，跑前冻结）

**定义（在运行任何代码前确定并写入 `wave_rod.py` docstring）：**

1. **波速**：`c = sqrt(E/rho)`（一维轴向弹性杆）。用 §1 的皮质骨 `E=17 GPa`、`rho=1900` ⇒ `c ≈ 2991 m/s`。
2. **几何**：胫骨 `L ≈ 0.38 m`。
3. **观测点**：**远端胫骨**（impact 端附近，`x = dx` 的内部节点），局部组织应变 `ε(x,t) = ∂u/∂x`（压缩为负）。
4. **驱动**：**impact 端（`x=0`）由接触/GRF 驱动**（Neumann 牵引边界）。刚壁撞击的首个 GRF 幅值取 Saint-Venant 结果 `σ0 = ρ·c·v0`（`v0 = sqrt(2 g h)`）⇒ 驱动应变 `ε0 = σ0/E = v0/c`。**幅值只定标应变大小，不影响峰时。**
5. **近端（`x=L`）**：**固定端**（刚体/大质量近似）。判据：胫骨杆质量 `ρ A L ≈ 0.23 kg`，其上人体质量 `≳ 70 kg` ⇒ **阻抗比 ≈ 311 ≫ 1**（写入 `meta`）⇒ 亚毫秒波时标上近端近似不动。
6. **峰时公式（预注册）**：撞击在 `x=0` 出发的压缩波在 `x=L` 固定端**同号反射**，返回 `x=0` 处使远端应变**叠加/加倍**，用时即往返 `t_peak = 2L/c`。

**跑前预测值：** `2L/c = 2 × 0.38 / 2991.2 = 2.54e-4 s = 0.2541 ms`（**亚毫秒**）。
设计 §4.3 预期：**1D 波杆会亚毫秒过冲** ⇒ [T22] 的 4.6 ms 应是**接触压溃主导**。本件唯一职责是**干净地算出该预测并如实报告**，**不凑 4.6 / 5.0 ms**。

**观测量实现（不用 `_first_significant_peak` 的理由）**：行波前沿本身即可越过 `head_branch._first_significant_peak` 的 `0.5×max` 相对阈值（前沿即达约半个叠加峰），会把数值前沿误判为"首峰"。故本件取远端 `|ε|` 在观测窗 `[0, 3×(2L/c)]` 的**全局极大**（`np.argmax`，平顶取最早），即物理上的**应变叠加峰**，且**确定、种子无关**。

## 4. V8b 判定（如实）

**观测量**：远端胫骨局部组织应变 `ε(t)` 在观测窗内的**全局极大**时刻。

**判定（两条口径，分开陈述，避免含糊）：**

- **字面判据（设计 §6 V8b：`ε_胫骨@20m ≤ 5.0 ms` 且随高度单调不增）**：**数值上满足** —— `0.2565 ms ≤ 5.0 ms`；且峰时对高度**严格不变** ⇒ 单调不增。
- **物理判据（是否复现 [T22] 4.6 ms 量级）**：**否** —— `0.2565 ms` 比 `4.6 ms` **早约 17.9 倍**；且峰时**与高度无关**，无法再现 [T22] `11.9 / 6.5 / 4.6 ms` 的下降趋势。

> **诚实综合判定：波杆不是 V8b 的可行路径。** 它的"通过"是**退化的过冲通过**：把峰时压到亚毫秒，靠**低于**阈值而非**命中** [T22]。设计 §4.3 / §7 决策 6 已**预注册**此预期。**全程未调任何参数。**

## 5. 解释（本件的核心信息）

- **过冲 ⇒ [T22] 4.6 ms 是接触压溃主导，不是波动主导。** [T22] Table 3（5/10/20 m → 11.9/6.5/4.6 ms，v = 9.9/14.0/19.8 m/s）反推 `t·v ≈ 0.09–0.12 m` **近常数** = **固定压溃距离**（`t_local ≈ d_crush / v`）。而纯波动观测量给**常数亚毫秒**（`2L/c`，与 `v` 无关）—— 二者结构上不同：一个随高度提前（`~1/v`）、一个与高度无关。**这从"能否复现高度趋势"上直接排除了波动主导。**
- **与 6 段链的关系。** 6 段链的 5.8 ms（`results/G1_CHAIN2D_REPORT.md`）落在 [T22] `4.6 ms` 的同量级（绝对偏移 +1.2 ms），是**更接近的物理匹配**：它把观测量做成**局部关节轴向力 → 组织应变**，本质上是**压溃/接触承接的载荷峰**，而非波动峰。波杆的亚毫秒结果**反向印证**了链的 5.8 ms 更接近真实机制。
- **幅值口径（副观察，非判据）。** 波杆 `ε_peak@20m = −8.84e-3`（压缩）与链的 `ε_胫骨@20m = 1.94e-2` 同量级（差约 2 倍），说明两件至少在**局部应变量级**口径一致；差异（含符号/边界近似）不改变峰时结论。
- **诚实边界。** 波杆是**均匀、无耗散、固定近端**的一维简化：不含骨小梁/骨膜/肌肉/关节；近端用固定端近似（阻抗比 311 ≫ 1，已记录）。这些简化**不改变**"波时标 ≪ 4.6 ms"的一阶结论。
