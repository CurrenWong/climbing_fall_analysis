## 1. 已完成且**有效**的部分

### 1.1 ★★ 外部锚（实测，可用于论文）
**Ruas 2023/2024（`PMC11889023`）**：青年男性**膝伸肌离心 MVC 力矩 = 270 ± 55 N·m**
（等长 252 ± 47 N·m，≈1.07×）；经典文献离心/等长比 1.3–1.8。

### 1.2 ★★★ 一个与靶无关、且**不依赖本件模型**的力学结论
把力矩换算成下肢轴向力时的**机械优势**：`F = M/(l·sin(θ/2))`（`l = 0.425 m`）：

| θ | sin(θ/2) | 单腿轴向力换算（M = 270 N·m） |
|---|---:|---:|
| 86.3° | 0.683 | **0.93 kN** |
| 111.2° | 0.825 | 0.77 kN |
| 120.8° | 0.866 | 0.73 kN |
| 30° | 0.259 | 2.45 kN |

**⇒ 双足肌肉离心**轴向**上限 ≈ 1.5–1.9 kN（中段屈曲角），而单侧跟骨骨折阈 = **6.2 kN**（高 3–4×/单腿）。**
**⇒ ⇒ 「靠肌肉吸能把足部力压到骨折阈以下」在 1 m 及以上**力学上不可能**；
⇒ 高于肌肉上限的载荷必须走**被动力学路径**（骨性/韧带/软组织）；**
**⇒ 这也说明靶 6–9 m 的存活**不可能靠肌肉解释** —— 与项目既有结论同向。**

## 2. 失败与根因（如实）

### 2.1 失败现象
```
C1-J0 正对照：soft/self/stiff 逐位 PASS ✓
正式跑：soft/h=0.50 ⇒ pad.py:785  RuntimeError: Required step size is less than spacing
```

### 2.2 ★ 根因：**力矩臂用错**
我在 §1.2/实现里用了 **`f_ecc_max = M_ecc/(l·sin(θ/2))`** —— 其中 `l·sin(θ/2)` 是
**肢体（等效关节）的力臂**，它 **`θ→0` 时 → 0** ⇒ **轴向上限 `→∞`** ⇒ 饱和律的斜率爆掉 ⇒ **ODE 变刚** ⇒ 积分器崩。

**正确做法**：关节力矩由**肌腱**产生，其**力矩臂 `r` 是独立的解剖量**
（膝伸肌：全伸展时 ≈ 0、**30–60° 峰值 ≈ 3–4 cm**），即

```
M_ecc_max(θ) = F_mt_max · r(θ)          ⇒  F_axial(θ) = F_mt_max · r(θ) / (l·sin(θ/2))
```
`r(θ) ~ θ`（小角）**恰好抵消** `sin(θ/2)` ⇒ **轴向上限有限** ✓，且物理上正确
（近直腿时膝伸肌的力臂本来就小 ⇒ 产生不了大轴向力）。

**⇒ 这也解释了为什么 §1.2 的表在「小角（θ=30°）」给出 2.45 kN 是**高估**的 —— 那一格恰好落在 `r(θ)` 最小处。**
