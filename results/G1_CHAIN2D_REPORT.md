## 2. 架构与实现（对照冻结设计 §4）

- **拓扑**：6 段 / 5 关节（足 / 小腿-胫骨 / 大腿 / 骨盆-躯干 / 胸廓 / 头颈；踝 / 膝 / 髋 / 腰 / 颈）。✓ 决策 1。
- **自由度**：平面点质量 + 软关节弹簧（基座侧向 + 每关节轴向+转角）。实现为 6 个质心节点各带 `(x_i, z_i)`（12 个平面位置自由度）。**偏差记录 D1**：冻结设计的"11 = 基座侧向 + 5×(轴向,转角)"未单列**基座竖直接触坐标**；接触柔顺必须有一个竖直自由度，本实现显式纳入（12 = 11 + 基座竖直）。这是**保守的最小忠实实现**，未加任何自由调参旋钮。
- **接触**：逐节点柔顺接触、**逐段穿透激活**（哪个节点沉到地面以下哪个受力）+ 面积增长 `A(κ)`（复用 `Posture.contact_schedule`）+ `sign_reg` 摩擦（C¹、种子无关）。刚地面 = `hard_surface` 串联软组织层；垫 = `CrashPad`。✓ 决策 3。
- **观测量**：`ε_j = (F_j/A_j)/E_j`；V8b = 胫骨段在 `meta["impact_window_s"]` 内**首显著局部极大**（复用 `head_branch._first_significant_peak`）。✓ 决策 4。
- **积分**：scipy **Radau**（`bodies.py` 已验证、隐式、抗刚），**不碰** RK45 默认路径。✓ §4.4。

### 2.1 偏差记录（设计未解处，取最保守、文档化选择）

| # | 偏差 | 依据 / 理由 |
|---|---|---|
| D1 | 基座**竖直**接触坐标显式纳入（DOF=12 而非 11） | 冻结文未单列；接触柔顺在无竖直自由度时无法定义。最保守最小实现，无自由旋钮。 |
| D2 | 用**平面点质量 + 软关节弹簧**（`bodies.py` 结构模式的平面推广），而非显式广义坐标 `(u_j,φ_j)` 拉格朗日式 | 设计 §4.1 明示"复用 bodies.py 结构模式"。两者自由度等价；此形式数值稳健、可测。 |
| D3 | **耗散机制**（接触**回弹相**滞回阻尼 ζ=1.0 + 关节 Rayleigh 轴向阻尼 ζ=0.3） | 冻结设计只说"软关节使塌陷与接触同时间尺度 ⇒ 无回弹"，**未给耗散律**。纯保守弹性碰撞**必然**回弹（物理），故补入**物理动机的耗散**（泡沫开孔滞回 + 肌肉离心收缩）。**回弹相单向**阻尼 ⇒ 不产生撞击瞬间的 `c·v` 尖峰，不污染加载相观测量。 |
| D4 | 自由落体解析到接触瞬间起步（弹道初值）再启 Radau | 纯计算加速（`h=20` 时自由落体 ~2.02 s，否则空跑 1e5+ 刚性步）；物理等价。 |

## 5. 无回弹（设计 §4.2）—— 如实报告

## 9. 诚实结论（一段）
