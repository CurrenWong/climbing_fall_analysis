## 🔴 本轮最重要的更正：DYNAMIC 不是「真积分」，是「刚体飞走」
上轮把 False Transient 读成「行为质变：1s 秒退 -> 真积分到 t≈0.44」。**该读数作废。**

读最后收敛态的位移场（`fe_post.read_displacement`，`temp/v1_freeflight.py`）：
| 量（g-0.05_e0.185_ap1） | 值 |
| 骨节点位移 \|u\| **中位** | **7295.78 mm（7.3 米）** |
| \|u\| max / min | 7314.27 / 7279.74 mm |
| **形心位移** | **(4297.34, -3725.91, 4570.37) mm** |
| **相对形心偏差（中位）** | **27.1 mm** |
| **偏差 / 形心位移** | **0.0075** |
| 板位移 | 0.000 mm（自检：板底固定 ✓） |
=> **位移场＝平移 + 少量刚体转动（偏差仅 0.75%）=> 骨飞了 7.3 米**

这正是手册 §8.12.4 逐字预言的失败模式：
 「the model will **fly off in the unconstrained direction** (in which a **rigid body mode** now exists)」

自洽性核对：SPON 体积 77794 mm³；deck `<density>` 骨 **1e-06** / 板 **1e-09**（**差 1000×**）；
按 tonne-mm-s 体系 m = 0.0778 tonne = 77.8 kg，F(0.44×26.4kN)=11609 N => a≈149 m/s²
=> 自由飞行 ½at² ≈ 14 m，**与实测 7.3 m 同量级** => 自由飞行假设成立
=> **「t≈0.44 才失败」不是「算到 44%」，是「在这之前一直在飞」**

附带更正：v1 里「~500 个单元倒置」也是同一现象的副产品（与板穿插后的畸变），
**不是独立的「大变形单元倒置」机制**。
⚠️ 我算的 `det F` 中位 0.31 是**错的** —— xplt 节点顺序与网格顺序**未校验**
（hdf5 只有 `meshes`/`states`，无 `node_ids`）=> 纯刚体运动应给 det F=1 => 该数值作废

## 🔑 三条可复用的工具知识
1. **`rhoi`/`gamma`/`beta` 属 `<solver>`（固体求解器）**，放 `<Control>` 被 FEBio 拒
   （`tag "rhoi" : unrecognized`）；手册 §8.4.1「solid solver」措辞准确
2. **pyfebio 的 `symmetric_stiffness` 在求解器类**（`control.py:67` 默认 `"preferred"`），
   **不在 `<Control>`** => 文本插 `<Control>` 会破坏解析
3. **`det F` 读法陷阱**：xplt 节点顺序未必等于网格顺序 => 不校验顺序算 det F 会得到假值
