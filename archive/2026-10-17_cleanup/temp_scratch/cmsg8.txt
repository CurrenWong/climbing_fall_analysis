## 本轮新增 1：逐项隔离（flip 1/1 + hold_k=100, h=5 m）
| 加入项 | 结果 |
| baseline | ✅ max=**152.491512** |
| +pad_e_mpa=0.185（跟垫模量） | ✅ **152.491512（逐位相同）** |
| +contact_pad_thickness_mm=15.4 | ✅ **152.491512（逐位相同）** |
| +contact_pad_fix_bottom_only=True（板可变形） | ✅ 152.491512（中位末位差 2e-6）|
| **+contact_penalty=5000** | **✗ 负J×6（首=245）** |
| **+contact_auto_penalty=1** | **✗ 负J×6（首=113）** |
| +全部 | ✗ 负J×6（首=375）|

三条结论：
1. **「把刚性地面换成真实跟垫」在这条路上**不可实现** —— `pad_e_mpa`（含 0.185 跟垫）
   **逐位无效**，**连板改成可变形后仍逐位无效** => 对「跖面承载三层裁定」第 2/3 层给出**更硬的否定**：
   不是「k 太软不可解」，而是「**板模量根本不参与**」
2. **`penalty` 必须留在 0.1**：提到 5000 或开 auto_penalty 都**破坏收敛**
   => 手册 §3.14 comment 2 的正解（ε=E·A/V≈5000）**在本模型不可用**
3. **`flip` 的效果需重新解读**：它把 151.8965 改成 152.4915（+0.4%），说明接触在**装配层面是活的**
   （penalty 能破坏收敛、flip 能改数）；但 **pad_e 零影响 + hold_k 仍主导**
   => 准确表述：**「接触被部分激活（贡献一小块刚度），主载荷仍由 hold 弹簧承担」**
